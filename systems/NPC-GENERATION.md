# NPC 业务生成底座

2026-10-04 第一轮完成受控业务底座；第二轮已装配暮羽工具、独立精确执行权限、结果预算和双语GUI。试生成／追加保存用户路径已接通，不含角色卡导入。参见[工具与权限合同](../muyu/modules/npc-generation/README.md)。

## 分层

- `npc-system.js` 保留原界面接口，暴露纯 `inspectGeneration({ count, fingerprint })`、受控 `generateApproved(options)` 和含物理请求排空的 `isGenerating()`。旧生成入口不能与新生成重叠。
- `npc-generation.js` 使用已注册 NPC Agent 的真实 context → prompt → call → parse 管线、实际 Prompt/Provider 渲染和 NPC 业务模型连接。它只执行，不授予权限。
- `muyu/host/npc-generation.js` 提供 `readState / prepareExecution / describeExecution / execute / forgetExecutions / clearExecutions`。状态只含数量、容量、生成选项和版本；执行单页面内最多128份、任务内一份，不从历史恢复。

## 范围与输出

`trial` 生成但不初始化仓库、不写入。`save` 只追加当前聊天的新 NPC 记录，不修改已有 NPC、不裁剪、不开启功能、不操作资源库、更不创建或导入 SillyTavern 角色卡。角色卡导入必须另行设计执行权限。

请求数量与容量在本受控合同中支持1–200，实际数量取请求数与剩余容量的较小值；容量已满拒绝付费。此范围不是对原界面运行时新增强制上限。存量 NPC 与酒馆角色目录各最多512项。重名检查覆盖所有酒馆角色、已有 NPC 和本批次结果，统一去首尾空白并忽略大小写；唯一但超出数量的输出不保存。

接受 name / description / personality / scenario，按配置可含 first_mes。名称非空且不超过200字符，描述非空，各正文最多12000字符，输出总量最多32768 UTF-8字节；不补缺失字段。宿主重建 imported=false、importedAvatar=null 和创建时间，丢弃模型伪造的 ID、角色卡关联和其他元数据。空数组或全部重名是 no_result；原解析器对空响应返回 null 时，明确作为无效输出，不假装生成成功。正文不超过6000字节时传回暮羽，超出只省略工具 DTO，不删除或截短已保存 NPC。

## 当前性、取消与保存

执行单绑定目标聊天、任务、模式、数量、业务设置及模型连接、聊天／元数据引用和内容、NPC 仓库、所有角色及注册 Agent/Provider 实现。准备不渲染、不请求、不写。muyu 前缀设置不进入业务指纹，存档不会自行使执行单失效。

共享 Agent 不被修改，执行时包装阶段检查；模型只尝试一次，禁用自动重试。取消、超时或任务撤销后，真实渲染／原生请求／保存未排空仍保持 busy，不触发全局 stopGeneration，不允许晚到结果写入新聊天。试生成不是沙箱：真实 Provider 可执行用户代码、读取数据、联网及产生副作用；取消不能保证停止这些副作用或计费。

保存必须提供确认保存接口，不回退到未确认的 saveChatConditional。保存未知返回 outcome_unknown，不自动重试或整仓恢复；确认保存后若基线变化返回 partial，保留并发修改，结果正文是执行时快照。切换聊天不会刷新新聊天；通知只发给仍匹配的当前宿主，不重建编辑器草稿。
