# 插件悬浮入口合同

## 暮羽视觉主题

历史与设置呈现：历史按本机日历日期分为今天、昨天、更早、之后的日期或日期未知；不改变记录顺序、筛选或存储时间。列表显示真实会话状态与更新时间，不读取正文生成摘要。条目操作使用不撑高卡片的浮出菜单，可点击外部或按 Esc 收回；重命名、归档和删除仍需原确认流程。配置保留稳定页面 DOM、原滚动位置和自动保存契约，开关仍为原生 checkbox，强制颜色模式回退系统样式。执行过程使用已观察事件的时间线，不增加百分比进度；终止或交接时未完成的请求不标记成功，折叠与滚动状态继续保留。

暮羽配置 → 对话与显示 → 暮羽界面主题，支持跟随酒馆（默认）、暮夜、晨光；英文提供对应选项。与执行过程偏好一起存入 `muyuDisplayConfig`，切换自动保存，失败保留表单并可重试。旧偏好未包含 `theme` 时仍按原执行过程设置读取并跟随酒馆。

主题通过浮窗根节点的 `data-muyu-theme` 和局部 `--gd-muyu-*` 语义变量实现，不修改页面根节点、酒馆主题或经典插件配置。授权卡采用金色强调，但不改变权限判定、按钮范围及处理流程。桌面与手机共享配色，继续使用各自既有几何布局与键盘适配；悬浮羽毛资源不随主题替换。此次不引入语音、任务百分比进度、保存期限或展开／收回的新生命周期。

悬浮外壳不属于暮羽内核，不读取业务数据，不执行模型请求。首个内置入口为暮羽；追踪与错误监测尚未实现，没有占位按钮。

## 展开与收回动效

`transitions.js` 为独立外观适配器：展开以当前悬浮球中心为起点，420ms 缩放与淡入；内容延迟淡入，标题使用同一羽毛资源。球仍可点击、拖动并显示真实后台状态，不隐藏入口或移动实际点击目标。手机最窄屏隐藏装饰头像，不改变已验证的窗口尺寸。

收回仍立即卸载界面订阅和清理 DOM；320ms 动效仅绘制空白装饰外壳，不克隆对话、密钥、编辑器或业务按钮，不延迟业务清理与焦点归还。快速重开会取消旧动效；旧 Promise 完成回调由版本隔离，不能清理新窗口。改变视口、拖动、减少动态效果偏好变化、隐藏页面或卸载时取消动画并清理装饰外壳，不额外请求模型。系统减少动态效果时使用120ms纯透明度过渡；不支持 Web Animations API 时直接显示／收回。

ResizeObserver 使用不包含动画变换的布局尺寸，不把展开缩放当作用户 resize。动效测试包括纯函数与模拟动画回调；真实浏览器测试使用生产外壳与隔离业务挂载桩，覆盖30次快速开关、320/400/600/800/1000px、草稿保留、视口变化、减少动态效果和清理；不替代手机真机键盘验收。

## 注册

`createFloatingRegistry().register({ id, label: {zh, en}, icon, order, isAvailable?, getStatus?, subscribe?, mount })`

- 仅受信任内置模块注册；不接受用户上传代码或模型生成入口。
- id唯一，label/icon为有限长度纯文本；order小的排前面。
- isAvailable同步返回false时入口不可打开；默认可用。
- getStatus只返回idle/running/attention/error，聚合优先级依次升高。禁止传入异常正文、工具参数、密钥、聊天身份或用户输入。
- 可选getPresentation返回`{status, displayState}`，提供时替代getStatus。displayState只允许idle/completed（idle）、thinking/executing（running）、waiting（attention）、error（error）；不兼容或未知值退回该status的默认展示。外壳只接收这两个枚举，不透传其他字段。旧模块无需修改，粗粒度聚合优先级不变，已投影列表可直接聚合，避免渲染时重复获取业务快照。
- subscribe(notify)返回退订函数。通知仅要求外壳重读元数据，不传事件或业务载荷；模块停用/卸载应通知可用性变化或移除注册。
- mount(container, {lang, close})挂载视图并必须返回幂等销毁函数。销毁只清理视图、DOM事件、敏感表单和视图订阅，不取消业务任务或监测服务。
- register返回移除函数；移除当前入口会关闭其视图并退订状态监听。registry.dispose退订所有模块。

## 窗口外壳

createFloatingShell持有一个body级非模态窗口，与设置抽屉DOM无关。仅一个入口时球点击直达；多个入口时显示选择列表；重复打开聚焦既有视图。切换模块销毁旧视图，不销毁模块控制器。

窗口位置和尺寸保留当前页面内存。悬浮球通过可选getBallPosition/saveBallPosition宿主回调保存左右侧及高度比例，暮羽组合层写入插件设置muyuFloatingPosition；外壳不直接读取设置、存档或模型数据。无效位置回退默认值，保存失败不阻断界面。桌面保留原生resize、标题拖动、气泡拖动及方向键调整。

窄屏（600px以内）及900px以内的触屏使用手机布局：56px气泡收起时贴边半隐藏，展开时完整露出，点击气泡可收回面板。日常聊天小窗宽为可见区域的86%（最多340 CSS px），高为60%（最多440 CSS px），横向预留24px、纵向预留96px，优先在气泡上方展开，空间不足则放到下方或缩小，始终避开气泡；拖动气泡时面板跟随。标题只显示模块名称，禁止标题拖动和尺寸拉伸，放大/恢复按钮在不重挂内容的情况下切换更大的可见区域。触摸拖动阈值10px，鼠标5px，轻微手抖仍视为点击；位置记住靠近的一侧和相对高度。

模块可调用mount参数中的setViewExpanded(boolean)，为设置、待处理授权或会话工具临时申请较大的手机工作区；结束后恢复小窗或用户手动选择的放大状态，不重新挂载视图。桌面几何不受此参数影响，旧挂载的回调失效。手机聊天把历史入口与设置集中在窗口头，当前对话标题和管理操作移入历史页；隐藏普通空闲状态及关闭的会话工具，用输入框旁的省略号打开工具。错误、待授权、只读和全权限警告不隐藏。

悬浮配色使用局部CSS变量统一背景、分隔线、灰紫强调色与焦点色，不改变经典设置页和宿主主题。支持相对颜色语法时，从酒馆主题背景提取不透明底色，适配深浅主题；外壳仅保留6%透明度并模糊背景，不对整个窗口设置opacity。输入框、设置卡、授权卡与菜单使用实底以避免文字穿透。无毛玻璃支持或偏好减少透明效果时退回实底；危险提示保留原来的警示色。

气泡采用本地静态资源assets/muyu-floating-feather.svg，按已确认的羽毛方案保留羽毛、紫色光晕与羽芒，不把整张展示板作为图标。图标为装饰性图片，不参与指针命中，不加载远程资源、不含脚本或SMIL动画；按钮保留中英文无障碍名称和原有点击/拖动范围。电脑48px、手机56px共用，装饰光晕可溢出，不扩大点击范围。CSS负责待机轻微浮动、等待模型收缩、执行中旋转细环、等待处理淡金呼吸；失败羽毛转为下垂并保留红色角标。拖动时暂停动效，减少动态效果模式下停用动画并保留静态状态标识。

轻量状态映射：暮羽UI组合层将控制器快照映射为展示枚举，不让通用外壳解析业务事件。控制器activity仅投影全局活动任务的process.phase，避免查看其他历史会话时误用其旧记录；model.started显示等待模型，其他忙碌阶段显示执行中，整理上下文也显示等待模型。任务空闲后，pending交互/notice显示等待处理，最新failed显示任务失败，succeeded显示回答完成，其余待机。completed仅表示执行段回答结束，不代表写入、持久化或整个任务成功。气泡data-display-state与中英文无障碍名称同步更新，data-status保留原有兼容语义。

一次性完成提醒：控制器仅在真实run.settled成功时递增completionVersion，且只在结果所属的当前会话投影该非负安全整数，不外发会话或任务ID。注册层仅保留这个数字；外壳见过运行态、收到新版本并进入completed后播放一次弹起/星光，animationend清理，无JS计时器。初始化、历史切换、重复渲染、窗口重开和悬浮球隐藏期间结束的任务不补播；等待用户或失败也不庆祝。静态SVG和方案文件不包含新的业务功能，语音/任务面板等展示板示例不作为真实入口加入。

visualViewport的resize/scroll与普通窗口resize触发布局更新，并扣除safe-area-inset；键盘收起恢复高度，手机临时布局不覆盖桌面尺寸，不重新挂载模块或清除草稿。历史在窄栏继续使用独立页面。展开和贴边使用短动画，尊重prefers-reduced-motion；不引入Android宿主代码或权限。

手机软键盘试用布局：浮窗内部可编辑文本控件获得焦点，且可视高度相对同方向基线缩减超过150px及20%时，临时使用键盘上方可视区域（扣除安全区及8px边距），不再为悬浮球预留高度。小窗底部对齐、优先占剩余高度的75%，最低目标260px但不超出可用高度；已放大或工作台展开的窗口使用完整可用高度。此时隐藏球和放大按钮，顶栏保留紧凑标题、暮羽配置齿轮及收起按钮。聊天隐藏会话工具／技能选择等次要展示，空对话保留中英文单句引导（已有消息则不显示），输入框仅保留外框焦点描边；保留滚动消息区及输入／发送／停止，配置和历史搜索仍使用原独立页面。焦点离开或高度恢复后自动还原原小窗／放大偏好，不保存临时尺寸、不重挂或主动滚动消息。通过visualViewport.scale排除双指缩放，无visualViewport时使用窗口高度变化；仅焦点或普通地址栏伸缩不启用。检测是浏览器可视高度的保守启发式，不保证识别遮盖但不改变任何视口尺寸的键盘。真实手机键盘、横屏及安全区仍需人工验收。

焦点微任务仅在软键盘展示状态实际变化时触发布局更新；普通聚焦及收起后恢复入口焦点不取消开合动画。视口resize/scroll仍按原规则取消过渡并重新布局。

Escape只在窗口/菜单内生效，不抢宿主全局快捷键。关闭/收起均卸载视图，恢复触发入口焦点；没有后台任务取消副作用。语言改变重建当前视图，业务输入由模块控制器保留。

settings deps中的muyuOwner暂为组合层持有者，其floatingRegistry允许后续内置模块注册；外壳和注册表不导入muyu。以后增加第二个功能时可以将owner提升为独立插件UI服务，无需改注册合同。首版不是第三方扩展API、监测框架或任意窗口系统。

## 验收边界

暮羽头部齿轮左侧提供三段主题快捷按钮（跟随酒馆、暮夜、晨光），复用displayConfig保存与设置页联动，不修改酒馆主题、不触发模型调用或重新挂载。保存中禁用重复操作；失败仍保持原主题并提示重试。按钮带中英文名称、按下状态与键盘焦点，关闭时由模块清理；无actionsRoot的经典嵌入仍使用设置页入口。

细节动效仅作用于悬浮界面：按钮与历史条目使用160ms颜色/描边反馈，不改变尺寸；设置开关180ms滑动，菜单120ms淡入。仅展开且运行中的时间线节点旋转，待处理授权卡使用2.6s金色边缘呼吸，文字保持静止。开合涟漪由过渡适配器创建空的aria-hidden/inert装饰，关闭代理320ms结束即移除，涟漪短暂落定后清理；重开、拖动、视口变化、页面隐藏与销毁都会取消，不复制草稿或业务DOM、不增加计时器。页面隐藏时CSS循环暂停，减少动态效果/高对比模式停用这些装饰，原生焦点和状态标识保留。没有新增语音、伪进度或消息滑入动效。

聊天优先布局更新：窗口已打开时再次点击球会收回；收回仍只卸载视图。窗口头只保留名称/状态、模块动作区及收起按钮。mount额外收到actionsRoot（模块可在此放齿轮按钮）和resetLayout（恢复窗口默认尺寸）；模块销毁应清理自己的头部动作，外壳也在关闭时清空动作区。注册表仍不认识暮羽配置项。气泡层级高于窗口，重叠时也能点击收回。

暮羽的齿轮切换到独立配置页，离开配置清空未发送密钥；首次无连接显示聊天引导。聊天使用独立滚动消息区和底部输入区；统一对话入口不显示任务分类。资料授权按连接/聊天复用、在配置管理；首次发送或草稿字段确认仍使用授权卡。切换视图只关闭未提交确认卡，不撤销已授予权限。新增会话选择条和可选本地历史保存，不改变外壳生命周期。

历史工作台更新：暮羽内容区自身观察容器宽度，680px 及以上使用侧栏，窄栏使用独立历史列表页，可返回聊天；关闭浮窗仍仅销毁视图，历史和输入由控制器保留。侧栏支持范围/归档筛选、标题搜索和管理确认，原始宿主聊天不会因查看历史而切换。ResizeObserver、导入文件读取回调和视图订阅随挂载清理；这不增加插件级外壳的业务职责。

自动测试使用DOM替身，覆盖注册/卸载、状态聚合、单实例、关闭与焦点、拖动阈值、重挂、宽度约束及语言切换；不能替代真实浏览器的CSS、原生resize、触屏键盘和酒馆层叠验证。需手动检查320/400/600/800px、宿主输入不被阻断、设置重建与聊天切换。暮羽内的任务过程及历史视图由各自模块维护，外壳不负责存储正文。
