# 暮羽 Agent 模块开发规范

GroupWorld 适配：安装目录及显示名称使用 GW；开发 API、序列化标识与旧存档保持不变。添加可见产品名时引用 `utils/product-identity.js`，不要机械替换 `window.GroupDirector` 或给工具／Provider 创建新命名空间。内置 Skill 内容变更需递增 revision，不覆盖用户资源。无可选宿主端口就不发布相应工具。来源和验收记录见 [MIGRATION](MIGRATION.md)。

本规范描述接入约束，不列历史轮次或拟议 API。架构见 [架构文档](MUYU-AGENT-ARCHITECTURE.md)，范围见 [能力表](MUYU-AGENT-STATUS.md)。新增或解除暂缓的功能需先核对真实业务与宿主合同。

## 工具与模块接入

1. 用显式工厂接收最小依赖，不在 import 顶层注册监听器、联网或写存储。
2. 同时登记闭合输入／输出 Schema、handler、[能力合同](../muyu/application/capabilities.js)、双语标签和精确工具分组；缺项、重名或效果不一致应拒绝装配。
3. 在相应模块 assembly 中声明工具、候选／报告、content.module、artifact.kind、动作所有者及生命周期。声明必须被实际消费者使用，不能重复绑定同一实例。
4. 每个运行使用确定的工具和版本映射；按需发现不授予权限。未知工具默认拒绝，工具正文或模型普通文本不能触发业务调用。
5. 工具与存储、知识内容、回执版本分别维护。新增字段／枚举必须补兼容测试，不以默认值推导全部合法范围。

精确接线和 Provider 预算专用签名见 [联合装配合同](../muyu/modules/ASSEMBLY.md)。报告使用独立 read 出口，不混入写入候选；任务方案只做 read-scope review。无草稿的生成模块明确声明空产物集合。

## Schema、预算与错误

输入输出均需类型、容量、深度、未知字段及危险键检查。公开 Schema 与宿主校验表达同一合同；有界 oneOf 必须且仅命中一个分支。输出复制后交给模型，不泄露可变宿主引用。

调用前检查运行存活、目标、来源与外发权限、预算和取消；结果返回后重新检查归属。已取消时不创建请求或定时器；清理监听器和计时器，后台 Promise 不因 handler 返回而获得继续写入权。

纯准备参数错误可在确定未产生效果时返回可纠正 not_started。执行异常、超时和未知保存不得伪装成未开始；不自动重放可能产生副作用的调用。错误投影不泄露原始响应、密钥或堆栈。单位、计数与未知状态明确，不把空数组或零当作已核实事实。

模型、工具、时间、资料及外部业务调用分别计费和限额；续接不能重置累计用量。真实生成调用前预留结果预算，声明额外费用；逻辑终止与物理排空分开，适配器不得启动未跟踪的后台工作。

## 权限、目标与意图

读取、代码执行、保存定义、真实应用和付费生成分别定义效果。工具目录、Skill、测试通过、只读方案批准或历史内容均不授予写入。普通模式走对应确认；阅读全开仍要求写入批准；全权限仍核验当前意图、精确版本、目标、功能开关与预算。

真实目标由宿主绑定，不接受模型任意指定其他聊天或绝对路径。来源拒绝后不得换工具绕行；目录命中、注册项存在不证明正文、最终注入或执行。只读资料是参考内容，不能构成真实用户手势。

Provider 源码草稿、合成测试、导入及真实 render 分开；系统 Provider 不可改。源码摘要与声明可用于版本检测，但不能证明外部依赖或代码行为恒定。晚到输出可丢弃，不能据此断言副作用已取消。

## 草稿、动作与回执

- 预览绑定精确目标、版本、完整差异及相关依赖，保留未指定字段。更改草稿或基线后必须重新核验，不沿用旧批准。
- [动作装配](../muyu/actions/ASSEMBLY.md) 登记唯一 writer／范围／产物归属；真正执行前在业务队列内再次检查，不只在入队前验证。
- [回执协议](../muyu/actions/RECEIPTS.md) 同步登记精确 module／操作版本、动作 owner／kind、来源与模型／GUI 投影，补 DTO 校验和双语文案。未知格式不能回落配置 diff 或应用入口。
- 内存赋值、保存确认、并发变化与结果记录分别报告。部分完成或未知不自动重试，不全仓回滚，不覆盖其他用户编辑。
- 资产容量在预检及最终串行追加时均检查；许可不冻结容量。允许读取／删除旧超限集合，不等于允许继续新增。
- 业务结果和历史保存结果分开；导入记录、刷新或摘要不恢复私有票据、批准或执行能力。

普通配置、专用副作用字段、库应用和生成整单均沿用各自合同，不借配置档或通用整单绕过限制。memoryMaxEntries 的设置保存与当前聊天裁剪分域报告；蓝图开关及完成变量亦有专用计划。无运行消费者字段不开放无效写入。

## 资源生命周期

Run 候选在替换、失败或取消时释放；续接转移，发布后交产物持有。产物删除、内容替换和会话卸载精确释放；验证元数据更新不释放内容未变的票据。异步预览返回时若旧 Run 已清理，应释放迟到票据。

使用 draft-runs／artifact-leases 管理私有计划；普通 DTO 明确空 retain，不制造租约。dispose 只释放本模块资源，不 clear 共享仓库、注册表或技能服务。

执行模块跟踪 prepare 及接手 execute 的 Task，预算拒绝或 prepare 抛错也不能遗漏资源归属。Run 清理不退 Task 票据；Task 钩子失败继续清理其余所有者并聚合错误。Skill 停放缓存清理不能提前销毁仍在物理执行的任务。

## 展示、知识与历史

配置名称、功能区、单位及枚举复用 presentation 与 read-presentation 映射，保留原字段和值。运行状态不是 GUI 设置；长 Prompt 不复制进摘要显示值。可信展示字段也计入输出预算，普通问答优先使用界面名。

UI 只派发应用命令并订阅快照；不通过 click 转发或按钮轮询执行业务。按钮引用操作 ID，不携带重新拼出的目标或差异。状态通知不得重挂用户正在编辑的表单，旧回调在撤权、连接变化、版本升级或卸载后必须失效。

知识字段应说明类型、允许值、单位、缺省／省略语义、范围、依赖及实际应用效果。默认值不是允许范围；未知保持未知。Skill 正文独立维护，修改内置内容提升清单 revision，不把整套模块文档常驻注入。

原始历史、派生摘要、Task 指南和用户长期笔记分开。私有思考不持久化；活跃工具调用与思考映射不能无协议裁剪。任务检查点不保存授权或可执行闭包，恢复／撤回须满足 [恢复合同](../muyu/recovery/README.md)。

## 测试与维护

新增模块按风险覆盖 Schema／超限、来源拒绝、目标变化、并发、取消与迟到、重复调用、物理排空、保存失败／未知、会话切换及面板重建。写入测试比较真实前后差异，不只断言 mock 调用次数；共享仓库测试验证其他所有者资源保留。

确定性测试默认不联网、不读真实用户数据。付费模型评测独立授权与运行，记录题目、基线及失败／复测；不把合成宿主通过等同真实 ST、磁盘或 GUI 验收。界面覆盖中文／英文、键盘、窄栏和异步布局。

文档保留当前规则；测试数字和模型表现留在标明日期的历史验收中，提交／push 状态由 Git 核对。变更模块合同与实际源码同步，不再向架构入口堆叠“第一轮／下一轮”日志。
