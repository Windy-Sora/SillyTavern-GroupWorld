# 暮羽 Agent 当前能力与边界

本文汇总已接入的能力，不作为开发日志、测试成绩单或发布记录。具体参数、来源权限与保存语义以链接的模块合同及源码为准；工具是否可用还取决于宿主端口、用户设置和当前任务。本次迁入与验收见 [MIGRATION](MIGRATION.md)，测试方法见 [TESTING.md](TESTING.md)。

## 已接入的能力

对象与诊断边界：用户Persona身份、剧情角色与导演发言选择分别核对，群聊环境本身不决定问题对象；不明确且影响来源时先简短确认。普通角色卡正文与导演结构返回固定证据范围，静态“加载中”文本不证明加载状态，当前空历史不证明从未生成／保存，快照差异不证明编辑或加载历史。这些约定不新增自动读取或授权，不构成模型推断正确性的保证。

证据范围：Persona、预设家族与卡内组件的读取结果区分当前内存／宿主加载保存副本、正文覆盖范围及未覆盖的运行信息；允许字段在对象中缺失不等于不支持读取。当前清单、文字差异或局部缺失不能直接证明历史操作、最终注入或全局故障原因。共享回答规则与专项 Skill 要求开头和标题同样遵守此边界；这些提示不构成运行核验，也不保证模型推断必然正确。

能力发现补充：普通角色卡工具与 Persona 名称目录在适配器接入时提供固定的独立正文入口提示；工具组目录和 Provider 来源目录分别说明。Persona 当前内存读取不可用时，可核对同来源目录中相关保存描述的可读状态，不能替代当前值。导航不读取正文或授予权限，仍遵守来源拒绝、目标、版本与预算检查；具体契约见 [Provider 读取合同](../muyu/modules/providers/README.md)。

读取链导航：工具组目录对实际可用的档案库、NPC库、蓝图库和自定义 Prompt 提供 list/read、对应授权来源及专项 Skill 指路，不重复实现读取。保存资源与当前聊天数据分别核对；选择工具组不授予权限，不自动启用、应用或执行。缺端口时不提供不可用入口。其余存储核验、Persona／预设正文与卡内组件入口沿用各自边界。

角色卡内组件已有独立只读来源：先读卡与组件目录，再按需读取正则、酒馆助手脚本及嵌入世界书条目正文。已知旧格式只解析不迁移，目录不含正文；脚本变量仅计数，不发送变量值或脚本 data。保存副本与编辑草稿、启用标记与实际执行分别说明；不执行组件，不依赖服务插件。合同见 [Provider 读取合同](../muyu/modules/providers/README.md)。

酒馆正文读取：Persona 保存描述与当前内存描述分开；除原有 OpenAI 聊天补全入口外，文本补全、Kobold、NovelAI 采样预设及上下文、指令、系统提示词、思考格式模板已有独立白名单读取。支持保存副本／当前配置／差异及按字段分页正文；不切换或写入预设，不执行宏、正则，也不返回连接字段。宿主不支持时报告缺口，不用当前导出假冒保存资源。目录、参数、正文、最终注入与持久化各自区分。详见 [Provider 读取合同](../muyu/modules/providers/README.md)。

保存数据的管理核验与运行开关独立：可读取关闭后的暮羽笔记、当前酒馆聊天业务总结；可按后端授权核验暮羽对话存档的清单及指定记录格式，不向模型发送旧正文。浏览器、插件设置、世界书、可选服务文件分别检查，不回退、不改来源、不创建空库、不迁移或写入。不装服务插件仅影响服务文件来源。核验不恢复会话、授权或操作，不证明历史执行成功或当前保存状态。契约见 [storage-inspection](../muyu/modules/storage-inspection/README.md) 与 [archive-inspection](../muyu/modules/archive-inspection/README.md)。

## 世界书历史存储

世界书合卷：新会话复用同账户 v2 卷，放不下目标容量时创建分卷；齿轮“对话历史 → 世界书分卷设置”提供1–16 MiB目标（默认8，自动保存，后续新会话分配生效）。旧 v1 单会话书原地兼容；可在“合并旧版世界书存档”显式合并，默认保留旧书并以新卷为主，原ID、版本和删除标记保留。旧书指纹不符时报冲突；清理旧书需要独立二次确认，仅删除已合并且未改动的旧副本，未合并、损坏或分叉不删。默认旧备份不随新卷更新或删除同步。部分失败保留已完成项，可重试，不恢复授权或任务。

目标容量不是硬封顶：单会话可独占超目标卷，已有会话仍原卷增长，超过20 MiB安全上限拒绝保存并保留本页内容。调整设置不搬迁旧记录；已有v2会话跨卷整理尚未提供。整卷保存前后核对，仍无跨设备CAS保证；合并和清理前应关闭其他设备及旧页面。真实ST/手机验收仍需人工完成。

存储读写分离：读取来源单选、写入位置多选，当前来源及各处保存状态分开显示。空闲时安全切库，同 ID 的各来源记录、草稿和滚动隔离，不开启写入仍可读。各 writer 独立 revision/内容核验，部分失败可重试，不覆盖分叉、不广播删除；移除自动浏览器→服务端迁移。支持外部更新／删除检测与明确重新载入。只读导入去重：当前来源中同内容备份复用（含归档版本），编辑过的文件新增独立只读版本，不覆盖原对话或恢复权限；失败不当空库，核对期间变化拒绝过时结果。不自动清理旧重复项，不承诺跨设备并发唯一。真实手机切换/多位置保存仍待人工验收。

已提供独立世界书后端、内部格式及 ST 原生 HTTP 适配；读写选择相互独立，旧初始偏好保留。世界书可在同一酒馆账号跨设备接续，不自动搬迁旧记录。显式复制入口可从浏览器、账户设置或服务插件复制已保存历史，要求目标写入开启；原件保留，相同跳过、冲突不覆盖，部分失败可重试，不恢复授权或执行。内部存档已从常规世界书资料、编辑、绑定、GroupWorld 选择和 Provider 扫描中排除。跨设备同时编辑没有服务端 CAS 保证，恢复检查点独立使用 IndexedDB。目标酒馆/手机实测仍待验收；确定性测试不代替真实宿主验收。格式、容量及边界见 [历史存储说明](../muyu/sessions/README.md)。

确定性回归覆盖四来源重开／导入、全关写入、世界书离线／损坏／删除、服务缺席、账号设置保存失败和重启 writer 后的外部分叉。新增开关不自动回填干净记录，继续沿用显式复制。上述验收使用合成宿主，不代表已完成真实手机/多设备验收，也不增加模型调用、权限或存储协议。

可选服务工作区支持 Windows 短路径别名：目录检查后使用真实路径，仍核验越界、链接和版本。服务端更新后需重启酒馆；本次 GW 和独立服务实际验收见 [MIGRATION](MIGRATION.md)，不在能力表累计上游测试数字。

## 保留边界

- 按用户决定不接入 ST 消息编辑／删除、蓝图模型生成／续写。蓝图已有文本、结构、进度编辑仍保留。
- 档案业务生成只支持模块规定的标准 Schema 与缺失保存；NPC 生成保存不创建／导入 ST 角色卡。独立角色卡工具不能据此理解为 NPC 自动导入流程。
- 变量整仓导入、三库通用批量、任意跨编辑器整单、Provider 改名／持久版本档案／一键撤销未作为通用能力开放。
- 无有效运行消费者的 memoryTokenBudget、llmJsonSchemaHint、档案库仅姓名匹配选项不开放无效写入。
- 暮羽自身连接／密钥、预算／指令、私人存储、内部版本和 Provider 引用表不属于任意业务字段写入口；业务连接 agentConfigs 也不能由普通配置工具修改。
- Capability 编写／修改／独立直接执行、通用 Shell、任意文件系统及 ST 核心修改不在范围。可选服务工作区只允许其专用文档操作。
- 授权 Provider 代码可能产生页面副作用；没有专用消息编辑工具，不等于代码绝不可能修改消息。

## 如何核对范围

普通字段查 [配置契约](../muyu/config/README.md)、[字段注册表](../muyu/config/registry.js) 与 [覆盖检查](../muyu/config/coverage.js)。覆盖分类中的 pending 不等于待开发任务：可能是内部设置、无消费者字段或需要专用编辑器的资产。不要用旧测试时的字段数量推断当前全部配置均可写。

能力、工具与动作须同时通过 [联合装配](../muyu/modules/ASSEMBLY.md) 和 [动作装配](../muyu/actions/ASSEMBLY.md)。可选服务另有 [能力门控](../muyu/services/README.md)。配置、数值变量／脚本定义整单与生成整单各有独立合同，不能任意混用。

普通写入经预览与精确批准；阅读全开不批准修改，全权限仍检查意图、目标、版本、开关和预算。只读方案批准不授予写入。取消不证明已发出的保存被撤销，保存未知不自动重试。

## 验证范围

确定性测试验证合同和状态机，合成宿主加真实模型验证特定题目行为；两者均不能替代目标 ST 版本中的接口、持久化和真实 GUI 验收。具体记录见 [测试文档](TESTING.md) 与 [Skill 评测记录](../muyu/skills/EVALUATION.md)，其中日期及数字只代表当时基线。

后续验收应覆盖普通／拒绝／阅读全开／全权限、切聊天、连接变化、面板重建、保存未知、生成取消与物理排空、手机键盘及中英文。新增能力需另行确定范围，不从旧阶段的“下一轮”恢复已跳过任务。
