# GroupWorld — 用户使用手册

> 当前公开入口为经典界面和暮羽悬浮窗口。安装与默认配置档使用 GroupWorld；旧 API／存档名称保持兼容。只启用 GD／GW 其中一个，升级前备份。暮羽连接、权限、存储及可选服务入门见 [README](../README.md#暮羽助手)，迁入及手工验收边界见 [MIGRATION](../MIGRATION.md)。

可选服务设置现按“本地资料与工作区”“公开网页正文”“文本校验”折叠分组。先点击“检查服务能力”，每项显示是否支持、是否开启；未安装或旧版时，已保存的开启偏好仍可关闭，但不会向模型提供不可用工具。开启能力不等于批准资料外发或文件写入。工作区更新已有文档需要本地检索取得版本基线；网页正文开关独立于小地球搜索。服务不影响 GroupWorld 的记忆、导演与摘要等核心功能。

工作区文档（服务0.6.0）：暮羽齿轮→存储与记忆→可选服务，检查能力后分别启用工作区文档草稿／JSON语法校验（默认关闭）。只保存私有工作区的文本／JSON，不应用GroupWorld或酒馆配置，不安装或执行代码。普通模式查看完整前后内容后批准；阅读全开不是写权限，全权限下“只预览”也不写入。更新已有文件需本地资料检索获取旧版本。草稿5分钟失效，大内容拒绝而非截断。回执只说明当时同步与核验，未知结果不重试。更新全部七个.cjs并重启酒馆。

公开网页正文（可选，默认关闭）：更新服务到0.5.0（全部六个.cjs，含web-page.cjs）并重启。在暮羽齿轮→存储与记忆→可选服务检查能力，再开启“允许读取公开网页正文”。无需Brave Key，也不依赖小地球搜索；开启允许按需访问公开网址，网址及查询参数外发到该网站，正文外发到当前模型。不能在网址中放密钥、聊天或配置。每任务最多6次请求，返回片段计入资料预算；有限结果不等于完整文章。不访问内网，不登录、不渲染JS、不读PDF。没有服务或关闭时不影响普通聊天。Fake-IP DNS的198.18/15会被拒绝，需要真实公网解析；[部署边界](../muyu/server-plugin/README.md)。

本地资料检索（可选，默认关闭）：更新服务插件到0.4.0（全部五个.cjs，包含documents.cjs）并重启酒馆。在暮羽齿轮→存储与记忆→可选服务，先“检查服务能力”，再开启“启用本地资料检索”。下一任务可按需列目录、搜索文本和分段读文件；开启不等于资料外发授权，读取遵守现有权限／拒绝与资料预算，可能增加模型和工具调用。没有服务、旧版或关闭时不提供这些新工具，不影响普通聊天。默认目录为当前酒馆账户私有的 `.group-director/muyu/workspace`，不会自动创建；额外只读目录需服务器管理员配置，见[服务部署与目录配置](../muyu/server-plugin/README.md)。不支持任意磁盘路径、文件修改或执行代码；部分返回不代表读齐，正文是参考资料，不是指令或实际配置证明。

暮羽服务错误记录：更新服务插件到0.3.0（全部.cjs，包含diagnostics.cjs）并重启后，在齿轮→存储与记忆→可选服务检查能力，再展开“服务错误记录（最近30分钟）”。可查看／刷新、导出JSON或清空；本地查看不发给模型、不删除对话。仅从服务加载起记录当前账户的历史／搜索／存储自检失败分类，最多200条、保留30分钟，容量压力或重启可能更早清除。不含正文、密钥、路径或CMD日志。暮羽可在现有资料权限下按需读取，阅读全开沿用原策略。错误分类不证明具体根因，空记录不证明从未失败。

可选服务管理位于暮羽齿轮→存储与记忆→“可选服务 · 文件历史与联网”；对话历史和搜索配置都有“服务安装与自检…”入口。可查看安装说明、检测版本与能力；“测试历史存储（写入临时文件）”主动写入、读回并清理独立临时文件，不修改对话、不调用模型或付费搜索。通过不等于已有对话已保存，也不验证搜索密钥。旧版需更新全部 `.cjs` 文件（含 `service-status.cjs`）并重启酒馆；不安装仍可聊天、配置管理与浏览器／账户设置存储。

在暮羽悬浮球齿轮 → 资料与权限 → 授权模式，可选逐项审批、阅读全开（修改审批）或全权限。阅读全开会将按需读取的聊天／卡片／预设等资料发送给当前模型服务商；不批准修改、代码执行或业务生成。选择自动保存，旧用户仍默认逐项审批；切回逐项审批不会保留自动放行记录，但原有手动授权仍有效。全权限危险，仅当前连接有效。等待授权时先取消任务再切换；联网仍由小地球控制，旧对话外发仍遵守上下文中的独立设置。

## 界面与暮羽入口

当前公开入口使用经典界面；新版导航入口已关闭，代码保留，不能再按下面旧预览说明寻找界面切换器。

点击仪表盘的“召唤暮羽”，菜单提供：

- **打开暮羽 Agent（推荐）**：打开独立聊天窗口，用于问答、按授权读取资料、配置预览及已支持的工具操作；无需导入角色卡。关闭窗口后可从同一入口重新打开。模型连接在窗口配置中设置，可使用兼容的酒馆当前连接或独立接口。
- **导入暮羽角色卡与世界书**：先确认，再执行原有导入流程；完成后从角色列表进入暮羽聊天。与Agent窗口是不同使用方式，不自动共享会话、权限或工具能力；导入成功也不等于已确认世界书实际注入。

菜单不挤压设置布局；点击外部或按Esc收起，支持键盘上下选择。暮羽窗口内普通偏好设置修改后自动保存；文本稍有延迟，失败时保留输入并显示重试。接口／密钥仍按连接配置按钮提交，资料授权和修改确认不因自动保存而省略。

### 暮羽联网搜索（可选）

暮羽窗口齿轮配置中的联网搜索提供“获取服务插件”和“检查安装状态”。小地球在尚未确认服务可用时先打开安装引导并检测，不发送输入草稿，也不直接开启联网。

服务插件仓库：[SillyTavern Muyu Services](https://github.com/Windy-Sora/SillyTavern-Muyu-Services)。在运行酒馆的电脑／服务器安装（不是前端“安装扩展”入口），按说明开启 `enableServerPlugins` 并重启；手机局域网访问时仍在电脑操作。界面提供可复制安装命令，剪贴板不可用时可手动复制；已有旧版应更新原目录，不要重复安装。此界面不会自动安装或修改 `config.yaml`。

检查安装无需模型连接或搜索密钥，只确认本机服务可达；成功不代表 Brave 密钥有效。随后配置独立的 Brave Search API Key（不是模型密钥），再开启小地球。搜索词会发给 Brave，可能计费；仅返回链接与摘要，不抓取网页全文。不安装服务插件仍可使用聊天、配置管理和浏览器／账户设置存储。

## 1. 快速开始（5 分钟上手）

### 安装

将 `SillyTavern-GroupWorld` 文件夹放入 ST 的 `public/scripts/extensions/third-party/` 目录，重启 ST。在扩展管理面板中启用。

### 三步启动

**第一步：选模式** → 打开「导演」抽屉，选 LLM 模式（效果更好）或公式模式（零 token）。

**第二步：准备角色** → 打开「角色」抽屉，展开「角色档案」卡片 → 全部重新生成。展开「角色记忆」卡片 → 提取全部。

**第三步：开始对话** → 进入群聊，正常发送消息。角色不再抢话，按导演顺序发言。

### 更快的方式：召唤暮羽

仪表盘点击 **「召唤暮羽」→「打开暮羽 Agent（推荐）」**，即可进入猫头鹰娘助手的独立窗口。也可以选择“导入暮羽角色卡与世界书”，使用酒馆角色聊天方式。

- **不知道怎么配？** 让她解释界面或检查已接入配置，需要私人资料时申请授权。
- **想写 Provider、DSL或复杂系统？** Agent可按需查阅专业技能，区分结构化数据、模板展示与实际状态更新。代码候选、合成测试、导入和真实执行不是同一步。
- **遇到异常？** 让她核对可读取的状态与诊断；不可见的服务器日志、文件或未接入接口不能当作已检查。

暮羽优先复用已有机制给出最小方案；只要求解释或预览时，不应擅自应用改动。具体可用能力以当前工具和权限为准。

### 更快的方式：预设

仪表盘底部预设下拉框中选择 `group-world-default` → 点击「应用」——所有推荐配置即刻生效。

### 界面分层说明

| 级别 | 区域 | 什么时候用 |
|------|------|------|
| **一眼可知** | 仪表盘 | 每次打开——当前模式、上次决策、数据统计、预设切换 |
| **核心配置** | 导演 / 角色 | 第一天——选模式、写 Prompt、生成档案记忆 |
| **调优** | 连续性 | 第一周——管理账本、世界书、上下文总结 |
| **按需** | 反应 / 工具 | 按需开启——多模态、导出导入、Agent 配置、自定义 Agent、调试 |

> **建议学习路径**：点击「召唤暮羽」→「打开暮羽 Agent（推荐）」→ 描述你的需求。也可以先仪表盘了解状态 → 导演抽屉配模式 → 角色抽屉准备数据 → 开始对话。高级抽屉默认折叠，不干扰日常使用。

## 2. 仪表盘 — 导控台

打开 GroupWorld 设置面板后，第一条内容就是仪表盘。它**不属于任何抽屉，始终可见**。

### 状态指示灯

最左侧的彩色圆点：

| 指示灯 | 含义 |
|------|------|
| 🟢 绿色呼吸灯 | LLM 模式，导演正在工作 |
| 🟡 琥珀色 | 公式模式，本地评分中 |
| ⚫ 灰色 | 已关闭 |

右侧显示模式名称和语言切换。

### 上次决策

指示灯下方一行带左边框的摘要，显示导演上轮的选择：

> **LAST CALL** Alice → Bob → Charlie
> *Alice directly addressed Bob and Charlie has relevant intel*

### 数据统计

七个数值方块 + 手动刷新按钮。打开设置面板时自动刷新。**所有方块均可点击展开**，显示详细列表。

| 统计 | 点击展开内容 |
|------|-------------|
| 档案 | 角色名 + 状态（绿=就绪/橙=生成中/红=失败）；展开行查看 summary/tags/motivation |
| 记忆 | 角色名 + 条目数；展开行查看最近 5 条记忆 |
| NPC | 角色名 + 描述摘要；展开行查看完整描述/性格/背景 |
| 账本 | 最近 8 轮发言顺序 + 理由；展开行查看完整理由和剧本 |
| 总结 | 显示 `已覆盖/总消息数`；展开行查看当前总结内容，支持编辑 |
| 世界书 | 全选/取消全选 + 逐个勾选 |
| 🔄 | 手动刷新所有数据（点击时图标旋转） |

#### 行内编辑

展开面板中悬停任意字段会浮现「编辑」按钮，点击后字段变为文本框，Ctrl+Enter 或点「保存」写入数据，点「取消」放弃。编辑直接写回底层存储，与抽屉中对应编辑区保持同步。

| 面板 | 可编辑字段 |
|------|-----------|
| 总结 | summary 内容 |
| 档案 | summary |
| 记忆 | event 文本 |
| NPC | description / personality / scenario |
| 账本 | reason |

数据也会在每次展开/折叠抽屉时自动刷新。总结面板和记忆面板底部各有一组自动触发控件（启用/自动/每N条触发），与对应抽屉卡片双向同步。

### 快捷操作

四个快捷按钮，仅在对应系统启用时显示：

| 按钮 | 效果 | 显示条件 |
|------|------|----------|
| 扫描存档 | 从聊天存档恢复档案 + 刷新记忆列表 | profile 或 memory 启用 |
| 生成档案 | 为群聊所有角色生成角色档案 | profile 启用 |
| 提取记忆 | 顺序为每个角色提取新记忆（不弹确认框） | memory 启用 |
| 执行总结 | 执行上下文总结。若未启用总结系统则自动开启 | 始终（群聊中） |

### 配置档管理

仪表盘底部一行：下拉框 + 应用 + 导入 + 刷新按钮。

下拉框中的选项以分组形式组织：

| 分组 | 内容 | 点击「应用」时 |
|------|------|---------------|
| **内置配置档** | `group-world-default` 等出厂预设 | 先加载到列表，再应用设置 |
| **我的配置档** | 用户保存或导入的配置档 | 直接应用设置 |

右侧按钮：

| 按钮 | 效果 |
|------|------|
| 应用 | 应用当前选中的配置档到全局设置（需刷新页面完全生效） |
| 导入配置档 | 选择 `.zip` 文件导入外部配置档 |
| 🔄 刷新 | 手动同步下拉框中的配置档列表（保存/删除后下拉框自动刷新） |

工具抽屉的配置档卡片中也有同款下拉框，两边选项始终保持同步。

## 3. 抽屉与卡片指南

### 阅读约定

- **抽屉**：点击标题展开/折叠的整块区域（ST 原生 `inline-drawer`）
- **卡片**：抽屉内部的可折叠信息块。每个卡片有标题栏 + 展开箭头，点击展开/收起。**卡片折叠状态会被记住**，下次打开设置时保持不变

所有控件更改**即时保存**，无需手动保存按钮。

### 3.1 导演

**谁发言、按什么顺序、怎么演。** 整个插件的核心抽屉。

#### 模式选择

三个并排按钮：**关闭** / **公式** / **LLM**。互斥单选。

#### 公式参数

仅公式模式可见。控制本地评分的具体参数——Top-N、评分权重、触发器、主动性。详见[公式判断](#公式判断零-token)章节。

#### LLM 参数

仅 LLM 模式可见。包含四张子卡片：

**Director Prompt**

| 控件 | 作用 |
|------|------|
| 每轮最多发言人数 | 导演每轮允许几人说话。推荐 2-3 |
| 上下文层数 | 给导演看最近 N 条消息。推荐 10 |
| Director Prompt 模板 | **核心配置**。使用占位符注入数据。模型必须返回 JSON |
| 恢复默认 | 重置为内置 Prompt |

**连贯性 & 账本**（展开卡片）

| 控件 | 作用 |
|------|------|
| 记录导演账本 | 每次决策后保存完整 JSON 到聊天元数据 |
| 清空 | 删除当前全部账本记录 |
| 使用导演历史 | 将历史账本注入当前 Prompt，保持剧情连续性 |
| 连贯剧本模式 | 仅上一轮 / 完整历史 |
| 历史轮数 | 完整历史模式下注入多少轮 |
| 包装模板 | 控制历史 JSON 如何包裹注入 |

**世界书 & 知识库**（展开卡片）

| 控件 | 作用 |
|------|------|
| 世界书注入 | 将激活的世界书条目注入导演 Prompt |
| 包装模板 | 控制世界书文本的包裹格式 |
| 知识库 | 存放不会被渲染的参考文本。通过 `{{knowledge}}` 引用 |

**强制发言**（展开卡片）

ST 群聊原生的强制发言功能需要插件适配处理，否则会导致时间线错乱。

| 选项 | 效果 |
|------|------|
| 原生放行 | 弹窗确认后让 ST 自行处理 |
| 直接截停 | 完全阻止强制发言 |
| LLM 接管 | 调用模型为该角色生成剧本并计入账本 |

**模板 & 角色描述**（展开卡片）

| 控件 | 作用 |
|------|------|
| 递归渲染 | 占位符输出中的 `{{...}}` 继续解析 |
| 最大递归轮数 | 防无限循环。推荐 5 |
| 调试占位符 | 保留未识别占位符方便排查 |
| Provider 渲染超时 (ms) | 单个 Provider 渲染时间上限。默认 10000（10s），0=不限制。超时的 Provider 降级为空内容 |
| 角色描述控制 | 全量传入 / 切片截断（推荐 200 字符） |

#### 导演剧本 (Director Script)

勾选「启用导演剧本」后，导演为每个发言角色输出舞台指令，注入角色 prompt 指导表演。

| 控件 | 作用 |
|------|------|
| 注入位置 | Prompt 开头（弱干预）/ 对话附近（强干预） |
| 剧本风格要求 | 告诉导演希望的剧本风格 |
| 角色 Prompt 注入模版 | **角色信息的唯一总注入口**。`{{script}}` 替换为实际剧本，`{{charMemoryCurrent}}`、`{{charCritique}}`、`{{characterLore}}` 等角色级 Provider 均在此渲染。可恢复默认 |

#### 高级：JSON 输出格式

Director 要求 LLM 返回 JSON。用户可自定义 JSON schema 来控制输出字段。

| 控件 | 作用 |
|------|------|
| JSON 输出格式 | 自定义 LLM 返回的 JSON schema 模板。默认包含 speakers / reason / loreAssignments |
| `{{scriptField}}` | schema 中的占位符——开启导演剧本时展开为 scripts 字段，关闭时自动消失。可在 schema 中增删任意字段（如 emotion、pacing） |
| 恢复默认 | 重置为内置 JSON schema |

### 3.2 角色

**导演知道的角色数据。** 四个折叠卡片，每个默认只显示标题和状态标签。

#### 角色档案（卡片）

生成结构化的角色档案（特质、动机、关系），注入 Director Prompt 作为身份参考。状态标签显示就绪数量。

| 控件 | 作用 |
|------|------|
| 启用角色档案 | 总开关 |
| 扫描存档 | 从聊天存档恢复已有档案 |
| 检测变动 | 检测角色加入/退出 |
| Token 预算 | 超过时压缩非活跃角色 |
| 并发数 | 同时生成的角色数 |
| 生成 Prompt / Schema / 渲染模板 | 三个模板均可自定义并恢复默认 |
| 全部重新生成 | 一键为所有角色生成档案 |
| 档案管理卡片 | 每个角色可展开，支持编辑/重生成/删除 |

**档案库**（角色档案卡片内）

把当前群组所有就绪的角色画像存为命名的"档案包"，跨群聊复用。库条目存于全局设置，不随聊天导出。

| 控件 | 作用 |
|------|------|
| 保存当前 | 弹窗输入名称，把当前群组所有 ready 画像存为新档案包 |
| 应用 / 导入到库 / 导出 / 删除 | 对选中或指定档案包的操作 |
| 自动补缺 | 开启后，切换群聊或启动时自动匹配并应用最优档案包 |
| 设为自动 | 把某个档案包设为固定自动加载目标（fixed 模式） |
| 覆盖已有 / 允许仅按名称匹配 / 应用模板 | 匹配与应用选项 |

应用时按 hash -> avatar+name -> 仅 name 三级匹配当前群组成员；默认跳过已就绪角色（除非勾选"覆盖已有"）。每个档案包卡片显示匹配预览（可导入数 / 跳过数）。

#### 角色记忆（卡片）

从对话历史中提取角色的关键经历和情感变化。状态标签显示条目总数。

| 控件 | 作用 |
|------|------|
| 启用角色记忆 | 总开关 |
| Token 预算 | 限制记忆文本总长度 |
| 提取/渲染/压缩 Prompt + Schema | 可自定义并恢复默认 |
| 压缩保留最近 | 压缩时保留最近 N 条原文 |
| 单角色上限 | 超出自动裁剪最旧条目 |
| 仅发言角色 | 自动提取时只处理导演账本中近期发言的角色，去重后避免全量调用 |
| 记忆管理按钮 | 刷新/扫描/提取/检测失联/重置 |
| 记忆卡片 | 每个角色可展开浏览/编辑/删除单条记忆 |

#### NPC 生成（卡片）

根据对话上下文批量生成 NPC，可导入为角色卡。状态标签显示 NPC 数量。

“导入为角色卡”成功后，该 NPC 会显示已导入标记并隐藏重复导入按钮。导入等待期间对 NPC 的改名或内容编辑会被保留。若 SillyTavern 已创建角色卡、但聊天元数据保存失败，界面会明确提示“角色已创建但导入状态未保存”；此时不要再次导入同一角色卡，可在存储恢复后通过后续聊天保存刷新内存中的跟踪状态。

**NPC 库**（NPC 生成卡片内）

把当前群组 NPC 存为命名的"NPC 包"，跨群聊复用。库条目存于全局设置，不随聊天导出。

| 控件 | 作用 |
|------|------|
| 保存当前 | 弹窗输入名称，存当前 NPC 为新 NPC 包 |
| 应用 / 导入为包 / 导出 / 删除 | 对 NPC 包的操作 |
| 应用模板 | 应用时同时导入 NPC 生成 Prompt 模板 |

每个 NPC 包卡片预览导入后会新建/覆盖多少 NPC。

#### 身份锚定（卡片）

自定义提示词，统一声明档案/记忆/摘要的使用规则和优先级。通过 `{{identity}}` 手动注入到 Director Prompt 或 角色 Prompt 注入模版。不会自动注入。

### 3.3 连续性

**导演记得什么。** 包含上下文总结、故事蓝图、AI 批判、导演账本、世界书等连续性工具。

#### 上下文总结（卡片）

将聊天上下文压缩为简洁摘要，降低 token 消耗。启用后 `{{chatSummary}}` 有内容。

| 控件 | 作用 |
|------|------|
| 启用 / 复用上次 | 基础开关 |
| 自动总结 / 每 N 条触发 | 达到消息数阈值自动执行总结 |
| 总结 Prompt | 可自定义并恢复默认 |

| 操作 | 按钮 |
|------|------|
| 扫描存档总结 / 清除禁用 / 隐藏禁用 | 管理已有总结 |
| 执行 / 重新 / 回退 / 重置 | 总结生命周期 |
| 编辑总结结果 | 直接编辑文本后保存 |

仪表盘总结面板中也有一组相同的自动总结控件，两边保持同步。总结内容在面板中支持行内编辑，修改后双向同步到抽屉的文本框。

#### 故事蓝图（卡片）

用结构化大纲指导 Director，让剧情按章、节、小结等动态层级连续推进。启用后默认 Director Prompt 会注入 `{{storyBlueprintCurrent}}`。

| 控件 | 作用 |
|------|------|
| 启用 Story Blueprint Provider | 总开关。关闭时蓝图 provider 为空，Director 看不到章节信息，也不会被要求返回完成变量 |
| 蓝图完成时自动续写 | 当前蓝图全部完成后，在后台调用 LLM 续写下一段蓝图，不阻塞当前 Director 轮次 |
| 推进模式 | `leaf` 只推进最底层；`all` 深度优先推进全部节点；`level` 推进指定层级 |
| 完成变量 | 默认 `gd_story_chapter_done`。Director/ForceSpeak 把它设为 `true` 时推进一步，然后系统自动重置为 `false` |
| 生成节点数 | 生成/续写时建议 LLM 输出的叶子节点数量 |
| 新建蓝图 | 创建用户自建的空白蓝图，默认带一个可编辑的起始章节 |
| 添加章节 | 在根级追加一个空白章节，不重置已有进度 |
| 生成 / 续写 | 调用 Story Blueprint 独立 API 配置生成新蓝图或追加节点 |
| 回滚一步 / 重置进度 | 修正推进记录，适合用户删除上下文或误判完成时使用 |
| 推进节点列表 | 点击整行只在右侧查看该节点；点击定位图标才会把该行设为当前推进步骤 |
| 蓝图标题 / 节点卡片 | 点击标题、Meta 值或节点内容字段即可编辑，失焦自动保存 |
| 高级 JSON 编辑 | 直接编辑蓝图 JSON，保存前会校验必须有非空 `nodes` |
| 生成 Prompt / 续写 Prompt / Schema / Provider 模板 | 均可自定义并恢复默认，生成和续写 prompt 支持普通 Provider 渲染 |
| 导出 / 导入 | 导出或导入当前聊天的蓝图正文与进度 |

默认生成 Prompt 会带上 `{{storyBlueprintFullJson}}` 和 `{{storyBlueprintProgress}}`，让重新生成时也能参考已有蓝图和当前进度以保护连续性。如果用户明确想彻底重启，可以自行从 Prompt 中删除这两个接口。

蓝图正文和进度存储在当前聊天中；配置档只同步蓝图配置，不同步具体剧情蓝图。Story Blueprint 使用工具抽屉 Agent 配置里的 `story-blueprint` 独立 API 设置。

**故事蓝图库**（故事蓝图卡片内）

把当前故事蓝图存为命名的"蓝图包"，跨群聊复用。库条目存于全局设置，不随聊天导出。

| 控件 | 作用 |
|------|------|
| 保存当前 | 存当前蓝图为新蓝图包（可选是否含进度） |
| 应用 / 导入为包 / 导出 / 删除 | 对蓝图包的操作；应用时可选择是否恢复进度 |

#### AI 批判（卡片）

让 AI 回顾最近对话，批判导演决策质量和角色表现。启用后 `{{directorCritique}}`、`{{characterCritique}}`、`{{charCritique}}` 有内容。

| 设置项 | 说明 |
|--------|------|
| AI 批判 / 复用 | 启用批判系统，复用上次已覆盖范围 |
| 自动批判 / 每 N 条触发 | 达到消息数阈值自动执行批判 |
| 批判 Prompt | 可自定义系统提示词，留空使用内置默认 |
| JSON Schema | 自定义输出 JSON 字段结构，留空使用内置默认 |
| 执行 / 重新 / 回退 / 重置 / 刷新 | 批判生成与生命周期管理 |

**{{charCritique}} 约定范式**：不管 JSON Schema 如何自定义，每个角色的批判必须是一个 object，其中 string 值渲染为 `[key] value`，array 值渲染为 `[key]` 后跟缩进列表。

仪表盘暂未集成批判面板（后续版本会加上）。

#### 导演账本（卡片）

浏览、编辑、清空导演历史决策。状态标签显示轮数。Raw 模式切换 JSON/易读格式。生成中自动锁死。

#### 世界书（卡片）

勾选哪些 ST 世界书条目注入到导演 Prompt。刷新按钮同步变更。最大注入条目限制（推荐 15-30）。

**来源模式**（`worldBookSourceMode`）：

- **ST**（默认）：跟随 SillyTavern 当前激活的世界书（聊天绑定的世界书 + 全局勾选 + 角色世界书）。此时下方勾选列表只读
- **GroupWorld**：完全使用下方手动勾选列表（`worldBookSelection`），脱离 ST 激活状态

**勾选列表**：全选/取消全选 + 逐个勾选（GroupWorld 模式可编辑）。

**Provider 预览**：实时扫描当前激活世界书，预览 `{{gdWorldBooksConstant}}` / `{{gdWorldBooksFull}}` / `{{gdWorldBooksNames}}` 的渲染文本与字符数统计，并提供一键复制占位符按钮。

### 3.4 反应

**角色发言后触发什么。** 默认抽屉折叠。

#### 消息级反馈（卡片）

每个角色说完话后调用 PostSpeech Agent 分析情绪、触发 TTS 等。⚠ 启用后每次角色发言增加 1 次 LLM 调用。

#### 回合级反馈（卡片）

一轮群聊全部结束后调用一次。适合生成场景配图、更新世界观等批量处理。⚠ 启用后每回合结束增加 1 次 LLM 调用。

#### 已注册能力（卡片）

启用/禁用各多模态能力（emotion / tts / image）。可通过资产管理导入自定义能力。

#### 决策记录（卡片）

最近的多模态策略决策。随聊天持久化，自动去重。

### 3.5 工具

**配置档、导出导入、Agent、自定义 Agent、自定义 Prompt、变量、接口参考、脚本执行器、调试。** 默认抽屉折叠。

#### 配置档管理（卡片）

保存、导出、导入整套插件配置为 `.zip`。可创建多套配置档按需切换。导出时可选范围（按抽屉勾选）。API 密钥自动脱敏。

#### 导出 / 导入（卡片）

支持群聊（角色卡+世界书 `.zip`）、档案（`.json`）、记忆（`.json`）、NPC（`.json`）、摘要（`.json`）的导出导入。各类 JSON 数据导入按所属模块匹配角色；群聊 ZIP 使用清单中的成员与角色卡文件建立映射。

群聊 ZIP 导出只包含成功获取的已启用角色卡；若有角色卡或世界书获取失败，会提示部分导出，角色卡全部失败时不会下载无效压缩包。导入会先检查清单、角色卡和世界书，再上传资源；已有角色卡不会按原文件名强制覆盖，已知同名世界书会使用避让名称。若上传途中失败，已导入的角色或世界书不会自动删除；只有全部必需角色成功导入后才会创建群组，并显示部分成功提示供你检查已创建资源。

#### Agent 配置（卡片）

每个 LLM 调用组（Director / ForceSpeak / Profile / Summary / NPC / Memory / PostSpeech / Critique / Story Blueprint / Custom Agent）可独立设置 API 端点和密钥。支持 OpenAI 或 Anthropic 协议。可测试连接。

#### 自定义 Agent（卡片）

用户自定义 LLM Agent，每 N 条消息自动触发或手动执行。Agent 不需要编辑器的 GUI、按钮、生命周期——只需要写一段 Prompt 和可选的 JSON Schema，结果就会通过 `{{providerName}}` 占位符注入到任意 Prompt 中。所有实例共用工具抽屉「Agent 配置」中的 `custom-agent` API 配置。

| 控件 | 作用 |
|------|------|
| 名称 / providerName | 显示名 + 占位符名（`{{providerName}}`） |
| 启用 / 自动 / 间隔 | 开关 + 每 N 条消息自动触发 |
| 顺序 | 每轮结束按数字升序串行执行 |
| Prompt | 自定义提示词（支持 `{{占位符}}` DSL 路径查询） |
| Schema | 可选 JSON Schema，LLM 输出自动校验+解析 |
| 结果 | 存储于聊天元数据，通过 `{{?providerName:field}}` 引用 |

点击卡片头部展开/收起配置面板。

#### 自定义 Prompt（卡片）

创建自己的 `{{placeholder}}` Provider。命名仅限 `a-z 0-9 _`。每个 Prompt 可编辑/开关/删除。支持批量导出导入。

#### 用户扩展（卡片）

导入自定义 `.js` Provider 或 Capability 文件。必须导出 `register(deps)`。导入后立即生效，重启自动恢复。

#### 接口参考（卡片）

纯参考文档，列出系统中所有 44 个内置 Provider 占位符及其说明（中英双语）。支持搜索过滤、添加/编辑/删除自定义条目、导出导入 JSON 文件、一键恢复默认。无功能副作用——仅帮助用户快速了解可在 Prompt 中使用的 `{{placeholder}}`。

#### 变量（卡片）

管理 GroupWorld 的变量追踪系统。22 个内置模板（story_phase、party_funds、trust_user、health 等），支持全局和角色两种作用域。LLM 每轮自动维护变量值，仪表盘变量面板可实时查看/编辑/回滚/锁定。支持导入/导出变量定义与数据。

| 控件 | 作用 |
|------|------|
| 新建变量 | 创建自定义变量（id/label/scope/type/updateMode/rule） |
| 内置模板下拉 | 从 22 个预设变量中选择添加到当前群聊 |
| 变量列表 | 浏览/编辑/删除已有变量，复制 `{{?vars:...}}` 查询 token |
| 编辑器 | 修改变量定义（作用域/类型/更新方式/校验规则/默认值） |
| 维护说明预览 | 查看注入 Director Prompt 的 {{variableMaintenance}} 实际内容 |
| 导出/导入 | 导出变量定义+数据为 JSON，支持跨群聊复用 |

变量导入只有在聊天数据保存完成后才会显示成功。若保存失败，系统会撤销本次导入并保留等待保存期间完成的其他编辑；同一数组变量的并发追加也会保留，不需要用户重新录入。

> **仪表盘变量面板**：仪表盘操作栏点击「变量」按钮展开，包含索引快速定位、内置模板下拉、新建变量、导出导入。按全局/角色分组展示变量值，支持行内编辑、回滚到上次记录、锁定变量。可勾选"隐藏无更新角色变量"过滤未变化的行。

#### 脚本执行器（卡片）

在导演生命周期的三个关键时刻（决策后/消息后/回合后）注入自定义 JS 脚本。通过 `ctx` 访问决策、消息、角色、共享状态。支持类型化参数、优先级排序、跨脚本共享状态、导入/导出（含版本号）。

详见 [脚本执行器](#8-脚本执行器)。

#### 调试（卡片）

- **模板测试器**：输入模板 + 可选 Locals JSON，测试渲染结果，不触发任何生成
- **执行追踪**：查看 Agent 各阶段耗时和输出。需开启调试日志

## 4. 两种导演模式

### 公式判断（零 token）

```
角色得分 = 名字被提及 × mentionWeight（默认 30）
         + 关键词匹配 × triggerScore（默认 40）
         + 近期未发言 × recencyWeight（默认 20）
         − 连续发言 × consecutivePenalty（默认 15）
         + Talkativeness × talkativenessWeight（默认 10）
         + 随机主动性（每轮 0 ~ initiativeBaseScore）
```

得分最高的 Top-N 个角色允许发言。适合快速测试和轻量日常。

### 大模型判断

每轮额外调用一次 LLM。导演分析上下文后返回 JSON：

```json
{
  "speakers": ["Alice", "Bob"],
  "reason": "Alice was directly addressed, Bob has relevant knowledge",
  "scripts": { "Alice": "Notices Bob's hesitation...", "Bob": "Recalls the clue from earlier..." }
}
```

`speakers` 顺序 = 发言顺序。`scripts` 是可选字段（需开启导演剧本）。

## 6. DSL 路径查询语法

### 基本查询

```
{{?name:field.subfield}}          → 取嵌套字段
{{?name:array[0]}}                → 取数组第 1 项
{{?name:array[-1]}}               → 取数组最后 1 项
{{?name:[key=value].field}}       → 按 key 精确查找
```

### 实战示例

```
{{?character_profiles:Alice.summary}}
  → "一位身经百战的王国骑士，恪守荣誉准则..."

{{?character_profiles:$character.motivation}}
  → 角色 Prompt 注入模版 中自动取当前角色的 motivation

{{?npcList:[name=老格里姆].description}}
  → 查找名为"老格里姆"的 NPC 的描述

{{?directorLedger:scripts.$character}}
  → 角色 Prompt 注入模版 中取导演为当前角色分配的剧本

{{?worldBooks:allEntries[comment=地理与空间].content}}
  → 查找注释为"地理与空间"的世界书条目内容
```

### 块循环

```
{{#provider:arrayPath}}
  对每个元素渲染此块。$it 为当前索引
{{/provider}}
```

示例：
```
{{#npcList:all}}
  - {{?npcList:all[$it].name}}: {{?npcList:all[$it].description}}
{{/npcList}}
```

## 8. 脚本执行器

在群聊导演生命周期的三个关键时刻注入自定义 JS 脚本。不是 Agent，不消耗 token。

**入口**：工具抽屉 → 脚本执行器卡片（反应抽屉下方）。

### 触发点

| 触发点 | 时机 | 执行方式 | 可用上下文 |
|--------|------|----------|-----------|
| 决策后 | Director 决策完成，角色生成前 | 阻塞（10s 超时） | `ctx.decision`（speakers/names/reason/scripts，可修改） |
| 消息后 | 每个角色发言渲染后 | 即发即忘（5s 超时） | `ctx.message`、`ctx.character`、`ctx.decisionSnapshot` |
| 回合后 | 本轮所有角色发言完毕 | 即发即忘，去重（5s 超时） | `ctx.decisionSnapshot` |
| 两者 | 消息后 + 回合后 | 各自模式 | 对应阶段字段 |
| 全部 | 三个触发点 | 各自模式 | 对应阶段字段 |

### 执行上下文 (ctx)

所有脚本通过 `ctx` 访问数据：

```js
ctx.params        // 脚本参数（类型化，可渲染）
ctx.shared        // 回合共享状态（跨脚本、跨阶段传递数据）
ctx.decision      // [仅 decision] 导演决策对象，live reference 可直接修改
ctx.decisionSnapshot  // [message/round] decision 阶段快照，只读
ctx.message       // [仅 message] 当前消息对象 { name, mes, ... }
ctx.character     // [仅 message] 当前角色对象
ctx.chat          // 完整聊天数组
ctx.characters    // 群聊角色列表
ctx.group         // 当前群聊对象
ctx.settings      // 插件设置
ctx.getContext    // ST context 函数
```

### 共享状态

脚本设置「返回模式」为「写入共享状态」后，返回的 object 会合并到 `ctx.shared`，供同轮后续脚本读取：

```js
// 脚本 A (priority: 1, decision 触发)
return { x: 42 };

// 脚本 B (priority: 2, decision 触发)
console.log(ctx.shared.x); // 42
```

共享状态在每轮开始时自动重置，不持久化。

### 参数

每个脚本可定义类型化参数（string / number / boolean）。参数值通过 `ctx.params.key` 访问。开启「渲染参数」后，字符串类型参数的默认值会过一遍模板渲染（单次，不递归）。

### 执行顺序

同触发点的脚本按**优先级（priority）升序**执行。优先级可为负数。超时或出错的脚本被跳过，不影响后续脚本。

### 导入/导出

脚本可导出为 `.json` 文件（含版本号），支持跨群聊复用。导入时同名脚本弹窗确认覆盖。配置档管理同步包含脚本执行器。

### 快速示例

**打印决策信息**（decision 触发，调试用）：
```js
console.log('speakers:', ctx.decision?.speakers);
console.log('reason:', ctx.decision?.reason?.slice(0, 100));
```

**修改发言顺序**（decision 触发，交换首尾）：
```js
const sp = ctx.decision.speakers;
if (sp.length > 1) {
    [sp[0], sp[sp.length - 1]] = [sp[sp.length - 1], sp[0]];
}
```

**记录消息统计**（message 触发）：
```js
console.log(`${ctx.character?.name}: ${ctx.message?.mes?.length} chars`);
```

## 13. AI 批判

批判系统从导演和角色两个维度评价每轮对话质量，通过三个 Provider 注入到 Prompt 中。

### JSON Schema 约定

批判 JSON 必须遵循两层结构：
- `directorCritique`: object — 导演维度的评价，每个字段渲染为 `[字段名] 内容`
- `characterCritiques`: map<string, object> — key 为角色名，value 为该角色的评价

默认 Schema：
```json
{
  "directorCritique": {
    "pacing": "节奏评价",
    "spotlight": "焦点分配评价",
    "suggestions": ["建议1", "建议2"]
  },
  "characterCritiques": {
    "角色名": {
      "consistency": "一致性评价",
      "interaction": "互动表现评价",
      "suggestions": ["建议1"]
    }
  }
}
```

用户可在 JSON Schema 文本框中自定义字段名和结构，省去默认字段、新增维度均可。`{{charCritique}}` 和 `{{directorCritique}}` 完全动态渲染，适配任意 Schema。

### DSL 查询示例

```
{{?characterCritique:Alice.consistency}}          → Alice 的一致性
{{?characterCritique:Bob.suggestions[0]}}         → Bob 的第一条建议
{{#characterCritique:all}}                         → 遍历所有角色
  {{?characterCritique:all[$it].name}}
{{/characterCritique}}

{{charCritique}}                                   → 自动解析为当前角色的批判
```

## 14. 常见问题

**Q: 导演不工作了？**
A: 检查仪表盘指示灯不是灰色。LLM 模式检查工具 → Agent 配置 → Director 的 API 连接测试。

**Q: 角色档案为空？**
A: 需要先生成——角色抽屉 → 展开角色档案卡片 → 全部重新生成。

**Q: API 密钥会泄露吗？**
A: 导出配置档时 Agent API 密钥自动清空。导入后需重新填写。

**Q: 自定义 Prompt 名字被拒绝？**
A: 仅限 `a-z 0-9 _`。不能与内置 Provider（`recentMessages` 等）或 ST 宏（`user` `char` `time` 等 72 个）重名。

**Q: 怎么彻底还原配置？**
A: 仪表盘预设下拉框中选择 `group-world-default` → 点击应用。

**Q: 记忆压缩和记忆导出的关系？**
A: 压缩用 LLM 将旧记忆合并为摘要。压缩记忆带标记，导出时可选跳过。

**Q: 暮羽修改配置中途断网或刷新怎么办？**
A: 开启自动保存对话时，普通配置与整单步骤会在当前浏览器保存操作检查点。对话底部展开“操作检查点 · 本地恢复记录”。新的受支持记录可点击“本地核对并生成剩余预览”，吻合后再次点击“批准并执行这份剩余修改”；已完成步骤不重做，不向模型外发核对资料。保存已确认、无异常／变化警告的普通单份配置，还可点击“核对并预览撤回配置”，再次“确认撤回这些配置字段”。仅恢复列出的字段原值，影响所有聊天；当前值或依赖发生变化时拒绝，不覆盖后来编辑。整单、变量、脚本、记忆裁剪及特殊业务操作暂不支持撤回。未知执行／保存结果、不同聊天或缺少完整资料时请人工核对并重新提出需求。检查点不自动执行、不恢复授权，也不随服务端对话跨设备同步；关闭自动保存后新操作不记录检查点。删除记录不撤销操作，但可能阻止关联记录继续核验。

**Q: 设置项太多了，找不到某个配置？**
A: 从仪表盘的数据统计入手——档案数量不对 → 角色抽屉。账本为空 → 连续性抽屉 → 检查记录开关。卡片标题上的状态标签可以帮助快速定位问题所在。

## 暮羽排错日志

自动保存报错时，可在齿轮设置的“存储与记忆”页查看具体错误码和建议。存储暂不可用时，恢复连接／浏览器存储权限后点击“重试保存”；设置选项保存失败时，检查酒馆连接后重新切换该选项。不要先清空记录；刷新前可导出当前对话备份。自动保存偏好开启不等于每次保存已成功。

存储暂不可用不会阻止保存自动保存的开关选择；勾选后仍有错误时，表示已选择开启，不代表对话已保存。齿轮 → 存储与记忆 → 对话历史中，“读取历史来源”单选浏览器、账户设置、世界书或服务插件；“写入位置（可多选）”独立控制后续保存，全部关闭仍能读旧记录。修改自动保存偏好；空闲时可直接切换读取源，不必刷新页面，各来源保留自己的本页内容、草稿和滚动。运行或等待授权时先结束任务。切换或打开写入不会搬迁旧历史，明确选择的来源不可用时不偷偷回退。

“导入只读备份”会在当前读取来源及本页导入副本中核对内容：重复文件不新增，直接打开已有只读备份（已归档的仍保持归档）；文件内容有变化则新增独立只读版本，不覆盖原对话。不会读取其他存储位置来拼接历史，也不会恢复授权或执行任务。自动保存关闭时，新导入只留本页；请核对保存状态或导出备份。历史中以前已有的重复项不会自动删除。

重新开启某个写入位置，只影响后续保存，不会立即回填整个历史库。“重试”用于待保存或失败记录；复制旧历史请使用显式复制。某处失败不代表其他位置也失败，请按各位置状态核对。世界书请在电脑和手机间依次使用，避免同时编辑同一份对话。

“当前读取”与各写入位置的上次保存状态分别显示。部分成功不是全部成功，可重试未确认部分，已确认的相同内容不会重复写。若未开启当前读取源的写入，新内容可能只存在其他所选位置，界面会提示“当前读取位置未更新”。重命名、归档和删除只管理当前读取位置，要求开启它的写入，不会广播删除其他备份。写入前允许读取目标同 ID 记录防覆盖，但不混入历史或发送给模型。不同版本保留冲突，不自动合并；切换前仍建议导出重要内容。

切换到世界书后，可展开“复制旧历史到世界书…”，选择旧历史位置，再点“确认复制到世界书（保留原件）”。复制前先导出备份并停止其他设备编辑；当前浏览器只能读取当前浏览器中的旧记录。仅复制已保存历史，不删除原件；相同记录跳过，冲突不覆盖。失败后已完成部分保留，可检查连接或容量后重试。授权、运行任务和配置操作检查点不随之迁移，不要同时在新旧位置继续同一对话。

刷新历史或重新开启自动保存时，若发现已加载对话在存储中被更新或删除，会保留本页内容并提示，暂停这份旧记录的继续发送与自动保存。先导出需要保留的内容，再点“重新载入存储版本…”并确认；这会放弃本页未保存的对话记录修改，但保留未发送文字，不撤销已执行操作。读取失败或载入期间切换聊天不会替换当前内容；这不是后台自动同步或合并。

世界书模式无需服务插件，可在同一酒馆账号下从电脑、手机接续暮羽对话。新会话合并到禁用的 `GD-Muyu-History-v2-…` 专用存档卷，旧v1单会话书仍保留。无需启用或绑定，请勿手动编辑；删除整卷会影响卷内所有会话，改名可能导致历史不可用。每个会话最多8 MiB、总计64 MiB，内容为明文。请勿多设备同时编辑，切换设备后先刷新历史。GroupWorld 常规世界书工具和 Provider 会排除这些存档，但其他插件仍可能直接读取。配置操作检查点仍留在当前浏览器，不随对话跨设备同步。

“对话历史 → 世界书分卷设置”可调整新会话分卷目标，默认8 MiB，可选整数1–16 MiB，修改后自动保存。按整本UTF-8大小计算，新会话放不下目标时另开一卷；调小不会移动或截断已有内容。单份长会话可独占超目标卷，已有会话仍原卷增长；达到单本20 MiB安全上限时保存会被拒绝，本页内容保留，请导出备份。此设置不自动整理旧卷或合并旧书，也不改变其他存储位置。

旧版一份会话一本书的存档，可展开“合并旧版世界书存档…”，先导出备份并关闭其他设备、旧页面，再点“确认合并（保留旧书）”。需要选中世界书为读取来源并开启世界书写入。合并保留会话ID、版本及删除标记，沿用当前分卷容量；合并后读取新卷，不混合重复副本，失败可重试。旧书默认保留为静态备份，不跟随新卷的更新和删除同步，可能仍含旧正文；旧书被外部修改会报冲突，不自动选择版本。

想减少世界书列表中的旧书，另点“清理已合并的旧书…”，核对提示后再点“确认清理旧书（不可撤销）”。只删除已合并、校验通过且未改动的旧版副本，不删除新卷、普通世界书或其他位置的存档；未合并、分叉或损坏时不清理。先导出备份，关闭旧页面以免旧代码重建旧书；原生世界书列表可能需刷新。没有跨设备原子事务保证，请勿同时在其他设备写入。

使用服务插件时，默认相对数据目录现已兼容。更新服务插件后请先重启电脑上的酒馆，再刷新手机／电脑页面并重试保存；仅刷新浏览器不会加载新的服务端代码。健康检查通过不代表历史读写已通过。`HISTORY_IDENTITY_UNAVAILABLE` 表示服务端未取得有效用户目录；检查是否已重启并加载新版服务插件，不要通过清空历史处理。

暮羽任务失败时，可打开 **会话工具 → 排错日志 → 导出排错日志 JSON**，把文件提供给开发者排查。请在刷新页面或清理运行记录前导出；日志只包含当前对话尚保留的执行段、错误码、失败阶段、预算和读取进度，不是完整历史或电脑后台日志。

导出只在本地进行，不需要资料授权，不调用模型。不包含聊天／提示词正文、思考内容、角色名称、接口地址、密钥或真实会话标识。浏览器无法下载时，可展开只读日志文本手动复制。旧日志中的 `UNKNOWN_ERROR` 无法还原为具体错误。
