# 暮羽 Agent 架构

本文描述当前分层与扩展原则。能力范围见 [当前能力表](MUYU-AGENT-STATUS.md)，接入要求见 [开发规范](MUYU-AGENT-DEVELOPMENT.md)。不在此重复字段数量、测试总数或轮次待办；历史方案可从 Git 查阅。

## 分层与所有权

### GroupWorld 宿主适配

产品元数据集中在 `utils/product-identity.js`。最终模型系统指令和公开导航引用可信宿主身份，说明 GroupDirector／GD 为兼容别名，不是缺失依赖，也不等于世界书。身份说明参与请求预算，不另占任务 DTO 或引入额外模型调用。

用户界面、内置技能说明和出厂助手资料采用 GroupWorld 名称；变更的内置技能递增 revision，用户编辑的技能、Provider 和历史原文不被覆盖。`window.GroupDirector`、设置及聊天键、工具／Provider／Skill ID、资产归属、回执 schema 和历史命名空间不得随品牌改名。可选服务沿用同一服务插件，不创建 GW 专属后端或静默迁移用户数据。当前兼容验收见 [MIGRATION](MIGRATION.md)。

```text
经典入口 / 悬浮窗口 / 设置与历史
                 │ commands + snapshots
application/controller → composition
                 │
core/runtime → tools/broker → modules/*
                                  │
                               host/*
                                  │
                 GD 业务系统 / ST Extension API / 可选服务
```

| 层 | 职责与边界 |
| --- | --- |
| core / tools | 模型循环、结构化工具调用、预算、输入输出校验、取消；不导入 DOM 或业务系统 |
| application / composition | 会话、Task／Run、授权交接、证据和产物编排；注入能力与宿主端口 |
| modules | 闭合工具合同、处理器、候选／报告与生命周期；不自行批准调用 |
| host | 当前目标绑定、必要数据投影、官方 API 和原业务保存端口；不提供任意 settings 写入 |
| actions | 精确批准、执行前重核、单次消费、物理排空及历史回执 |
| context / instructions / retrieval / skills | 请求规划、历史摘要、指令、静态知识及任务指南；资料不构成权限 |
| sessions / storage / memory / recovery | 会话记录、存储后端、用户笔记与受限操作检查点；各有独立数据合同 |
| ui | 快照呈现、编辑草稿和命令派发；卸载视图不销毁任务或批准所有者 |

模型协议映射与传输分离。独立 HTTP 和酒馆当前连接复用协议适配，酒馆模式不借普通 RP 生成注入角色提示词；GUI 不直接持有宿主密钥。详见 [模型合同](../muyu/model/README.md)。

## 装配与扩展

[联合模块装配](../muyu/modules/ASSEMBLY.md) 将工具、能力、标签、分组、候选、报告、动作归属及 Run／Task 生命周期放在可信描述中。宿主未提供端口时不发布相应工具；未知、重复或不匹配的描述拒绝装配。

工具发现只改变本次可见定义，不授予读取或执行权限。稳定别名、旧工具调用及私有思考回传必须保持对应，不能为了减少上下文破坏协议配对。

[动作装配](../muyu/actions/ASSEMBLY.md) 管理 busy、失效、排空及清理；[回执合同](../muyu/actions/RECEIPTS.md) 用精确版本登记联接保存结果、来源、模型投影与 GUI。未知产物或回执不回落成配置操作。GUI 渲染、工具 handler 与真实 writer 的所有权分开。

候选发布时把私有预览资源转交产物；授权／澄清续接转移同任务资源，不提前释放。产物删除、内容替换或会话卸载只释放自身持有的资源，不能 clear 宿主共享仓库。Task 执行票据与 Provider 预算有专用生命周期，普通 Run 清理不退执行票据或重置额度。

## 身份、授权与资料

一个运行绑定会话、任务、Run、宿主目标、连接、工具集合和预算。会话可在 ST 聊天切换后继续交流，但新工具访问须重新绑定当前目标并说明范围变化；旧结果不能混入新聊天。视图收起仅取消订阅，换连接、禁用和实例销毁执行取消与清理。

[权限策略](../muyu/permissions/README.md) 区分逐项审批、阅读全开和连接内全权限。模型只提出调用；可信应用决定权限。只读方案批准仅覆盖列出的读取来源，预览不等于写入批准。全权限不新增未实现能力，不取消意图、版本、范围、开关或预算检查。

旧问答再次外发与重新读取宿主资料分别管理；历史、摘要、角色卡、世界书、Provider 输出和日志都是资料，不能恢复授权或伪造真实用户手势。撤权、版本失效、用户拒绝与无效参数应给出不同结果，不通过其他工具绕行被拒来源。

固定资料来源投影与用户 Provider render 分开。前者有闭合字段、选择器和分页合同；后者执行同页 JavaScript，可能读写、联网或计费。代码测试、导入和真实执行分别核验，合成测试不是安全证明。详见 [Provider 合同](../muyu/modules/providers/README.md) 与 [资产工作台](../muyu/modules/provider-assets/README.md)。

## 修改与结果

配置与资产复用原业务验证、队列和保存端口，不建立平行真实数据仓库。普通字段从显式目录选择；特殊开关、记忆裁剪、库应用、ST 资源及代码各走自己的合同。

```text
用户目标 → 完整预览 → 精确批准／可信全权限策略
  → 重核目标、版本与基线 → 原业务端口执行
  → 保存核验 → 不可变回执 → 独立解释或重新读取
```

只修改批准差异，不补用户未要求的开关，不以整仓快照覆盖并发更新。跨保存域允许部分完成，不宣传原子事务。配置档保存、聊天应用、生成和运行代码是不同效果。

区分未开始、内存已更新但保存未确认、确认保存、部分完成与结果未知。回执描述当时结果，不代表当前配置。取消或超时不证明外部副作用撤销；物理请求未排空时继续占用运行资源。未知写入不自动重试。

[恢复工作台](../muyu/recovery/README.md) 已支持部分配置／整单检查点、本地核对后重新批准剩余步骤及受限普通配置撤回。它不是任意 Agent 任务的断点重放，历史和检查点不保存可复用批准或执行闭包。

## 上下文、知识与存储

原始对话、模型输入、摘要、工具证据、任务指南和长期笔记分开。输入及请求体预算按最终适配后请求计量；可整理历史不等于可裁剪活跃工具／思考轨迹。连续性、摘要失效、预算和原文检索见 [上下文合同](../muyu/context/README.md)。

[Skill](../muyu/skills/README.md) 使用独立 Markdown 资源及清单，目录与正文分开。已加载任务持有完整固定版本，后续请求按需投影；管理、启用、加载及执行授权互不代替。知识说明不能证明当前配置或历史事实。

[会话](../muyu/sessions/README.md) 可使用浏览器、账户设置或服务端私有历史后端；原文、派生摘要、[用户笔记](../muyu/memory/README.md) 及操作检查点按各自合同保存。私人数据不跟随剧情配置档，导入不恢复运行或批准。

## 可选服务与界面

服务端插件提供私有历史、搜索和已声明的可选工具协议。客户端拥有工具定义、开关、权限和预算；服务响应不能注册任意工具。缺失、旧版、未启用或能力检测失败时，相关工具不可见且不可执行，基础对话保持可用。详见 [服务合同](../muyu/services/README.md)。

[界面合同](../muyu/ui/LAYOUT.md) 区分稳定消息／产物、编辑草稿、状态更新及滚动意图。授权与澄清在消息区末尾，首次定位不反复抢焦点。面板重建不恢复旧回调的批准能力，不启动业务调用。

## 后续扩展原则

新增能力先定义实际用户任务、宿主支持、数据来源、效果、保存确认及失败恢复，再接入既有装配。通用 Shell、任意磁盘访问、Capability 编写等未开放能力不能仅凭增加工具描述获得执行权。

确定性回归、合成模型实测与真实宿主验收分别记录。代码接线完成不证明模型措辞正确、目标理解充分或所有主题／手机布局已验收。历史优化轮次不作为当前待办。
