# 单角色记忆业务生成

2026-10-04。三个工具独立于记忆诊断／手工编辑，复用原GD memory Agent、Schema、ContextPool及业务模型，不替换暮羽模型连接，不增加生成Provider副本。

## 授权与入口

- `muyu.memory_generation.targets`：memoryGenerationTargets来源只外发角色名称、数量、容量、opaque selector和版本；16/page，最多512角色。纯读取不初始化仓库，不返回正文、头像、Prompt或连接密钥。
- `prepare`：要求目录提供的character／revision与mode=trial或save，私有页面执行单绑定任务、聊天、角色、业务设置／连接、Agent函数及Provider实现。准备不渲染或生成。暮羽自身muyu前缀存档／界面设置不构成业务基线变化，避免保存对话导致授权失效；其他业务设置仍核验。
- `execute`：external效果，只由source:memoryExecution:UUID精确授权。普通模式由宿主暂停原调用，用户批准同一单一次，不能常驻授权；全权限直接放行已支持效果，仍核对目标及版本。读取、只读方案、手工草稿授权均不是执行权。按需加载不是授权。
- 界面直接显示角色、试跑／保存与已有数量／容量；提示额外业务模型费用、真实Prompt／Provider渲染、可能裁剪旧条目和取消局限。试跑也是实际付费渲染，不是合成测试。原生目的地由ST管理，不保证与暮羽连接相同。

## 执行与结果

执行前预留16000 UTF-8字节结果预算，不足不请求或写入；目录／准备结果按实际字节扣除。运行仍计工具调用与任务时间，业务模型费用另行产生，不能混称为暮羽模型Token用量。单单最多一次业务模型尝试，零重试；同ID只返回历史结果。准备时确定mode，不以更改trial/save绕过单任务单角色去重。

trial只返回提取与wouldPrune，不写数据；save追加所选角色并按原上限裁剪，包括本次生成中较旧的条目。不会开启功能、批量生成、改其他角色或创建角色卡。复用原Schema和格式边界；未提取返回no_result，长结果超过6000字节省略正文并标outputOmitted，而非虚报失败。

applied_confirmed是执行时已确认保存，不证明当前状态或剧情事实；partial为保存已确认但当前基线改变；outcome_unknown不自动重试或整仓回滚。尝试标志不证明送达／计费，生成正文不可信。取消／超时阻止后续受控写入，不保证终止Provider副作用、原生计费或在途保存；实际请求未排空仍保持busy。

## 生命周期与存档

模块只在宿主有受控端口时装配，统一助手入口可用，旧只读任务不开放。Run固定版本；授权续接沿同任务同目标迁移，未绑定模块的迁移为空操作，不干扰旧聊天澄清。任务结束／取消释放执行单，dispose清空；不从会话文件恢复执行权。

历史DTO仅保留执行来源依赖和对话文本，不包含执行闭包或权限。已结束单不可通过历史重新执行；历史外发确认与新资料读取／执行许可分离。来源不进入只读方案批量许可，也不将代码执行来源当成可重新读取Provider资料。

本模块未开放批量／整单记忆生成。后续增量已单独接通[标准单角色档案生成](../profile-generation/README.md)；NPC／蓝图生成或续写仍在队列，真实ST GUI、业务连接和持久化仍需用户验收，确定性测试不调用付费接口。
