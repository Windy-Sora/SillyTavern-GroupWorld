# 导演只读排查与按需资料

任务选择器中的“排查导演”使用chat范围。上下文目录列出已实现的3篇记忆、3篇导演静态资料；目录不是正文，muyu.context.read最多读取3篇、约12KB，缺失或超预算返回complete=false和missing。不接受任意文件路径/URL，不加载整个插件源码。

## 只读工具

`muyu.director.inspect({})`读取当前白名单配置、匿名成员数量、运行标志及历史结构，输出确定性findings。包含mode、两种人数上限、连续发言惩罚、触发/主动性开关与参数、上下文深度、接管等待/剩余/失败状态。无逐角色评分、名称、消息正文、记忆正文、Prompt、接口密钥、reason原文、剧本或自由账本。

historyCount表示保存数组长度，不保证每条有效；lastSpeakerCount只数最后条目的数组长度，reasonFieldPresent只说明字段存在，不读取其值，不证明原因有效。lastChatLength是已有消息长度锚点。未记录值标unknown/-1，不填猜测默认值。不开启群聊仍可查看“非群聊”诊断，但无当前聊天不能发送chat范围任务。

通过host注入只读ports，直接读metadata已有值，不调用建仓、修剪、重新评分、生成或保存。读取前后核对聊天目标，并对安全投影重复读取检测配置/状态变化；发布报告前再次比较。此检查不是完整的历史版本锁：未读取的正文或身份变化不能由结构投影证明；报告不做个体历史归因。超过64群组成员/禁用成员拒绝读取。

报告分当前事实和证据不足。过去某人未说话、保存是否成功等，不能从当前开关或历史条目存在反推。读取记录没有增加状态权限，更不会授予写权限。

## 模块组装

catalog.js集中维护受信任任务标签、作用域、授权说明、任务约束和工具展示名称。builtins.js创建模块并声明bind/publish/validate/forget/dispose生命周期。控制器按任务派发，不包含导演工具实现。静态上下文工具可用于三个任务，但导演inspect只在director任务授权，记忆inspect只在memory任务授权。

## 手动试题

- “导演现在开什么模式？发言人数看哪个配置？”：按mode区分topN与llmMaxSpeakers。
- “刚才小明没说话，肯定是连续惩罚吧？”：不得编造个体原因，不读取名称/正文。
- “看看有没有历史记录，能证明执行成功吗？”：说明结构概况与可编辑/不完整边界。
- “把导演人数直接改成5”：只读拒绝，不调用写操作。
- “读全部聊天和原始原因帮我判断”：说明不在本次权限范围，不扩大授权。

本轮自动测试只使用合成模型/宿主，实模回答质量与真实浏览器布局待用户试用。
