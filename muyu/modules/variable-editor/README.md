# 当前聊天变量编辑

2026-10-04，完整类型与单变量编辑轮。原muyu.variables.preview及整单数值变量合同继续使用原实现；新能力复用原变量批准协调器和写入桥，避免增加一套应用按钮或控制器执行分支。

## 入口与来源

- muyu.variable_editor.list：每页24项，界面名称、类型、作用域、可编辑状态、不透明版本。
- read：精确ID／版本分页读取，一页6000字符；包含该变量定义、已存全局／角色值和character:N角色选择器。角色名字可能重复，选择器绑定本轮角色映射；禁用角色不能设值。
- preview：创建、定义编辑、值编辑、删除单变量。创建之外必须提供已列出的精确版本。
- 独立来源variableEditState，范围是当前聊天变量和角色映射，包含角色名称及变量值；不读消息正文、角色卡描述、其他聊天或执行维护规则。读取结果为不可信数据，不是模型指令。
- 普通模式完整差异审阅后精确批准一次；全权限仅明确apply=true才执行。读取授权不批准写入。

## 数据与业务语义

支持number、string、boolean、enum、array、object；支持聊天内global和character作用域。global不表示跨聊天设置。

创建要求label、type、scope、defaultValue；其余沿用变量系统默认：自动维护／仪表盘显示开启、always注入、replace更新、未锁定、排序100、空维护规则。所有默认行为都显示在完整定义中。enum必须给出非空且无重复的enumValues。JSON类型必须正确，禁止靠文本隐式转换类型。

定义编辑仅改指定字段，保留其他原字段和额外元数据。类型切换必须保证默认及剩余存值符合新类型；resetValues:true明确清除该变量全部已存值，并为global初始化新默认。作用域切换沿用真实upsertDefinition清除旧作用域值，完整差异展示损失。修改defaultValue通常不替换已有存值。

set_value默认精确替换；delta、append、merge只有显式选择才使用。delta限数值、merge限对象、append限字符串或数组。值结果复用真实coerceValue/setValue；增量触及上下限时沿用业务夹取并显示最终值。数值必须有限，范围由变量自己的min/max确定，不沿用旧数值草稿的10亿上限。数组追加要求数组输入，对象合并为浅合并。

删除同时删除定义、全局值、全部角色值和该变量更新记录。值编辑沿用手动记录，记录仓库保持最多100条，最旧记录可能被淘汰。删除、重置和作用域切换无法直接撤销，须核对差异。

带owner的系统变量及配置中的蓝图完成标记受保护，走专用入口；新入口不允许设置owner、重命名ID、注入未知字段或执行规则代码。locked控制导演自动更新，不阻止用户批准的手动编辑或明确修改锁定开关。

## 分层与执行

modules → host/variable-editor → systems/variable-editor。预览对选中变量的隔离仓库调用真正的变量系统；不调用真实fire-and-forget保存，也不读取消息正文。原变量系统仅额外导出纯coerceValue函数，既有业务行为保持。

私有计划绑定目标、metadata/settings身份、变量定义及存值、该变量记录、角色映射与群聊可用性、完成标记配置。完整差异最多24000 UTF-8字节，同时受通用JSON深度／节点／字节限制；超限拒绝，不截断批准。

执行只修改选中变量的定义、值桶与相关记录，保存一次当前聊天，由saveVariablesChatConfirmed核验变量仓库。保存异常报告outcome_unknown，保存后目标改变为partial；保留并发编辑，不回填整个旧仓库或自动重试。每份计划执行后消费。

v20回执只含操作、变量ID／界面名、角色选择器及聊天保存状态，不含实际值或维护规则。历史回执不代表当前值或授权。
