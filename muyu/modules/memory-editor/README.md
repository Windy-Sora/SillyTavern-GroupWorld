# 当前聊天角色记忆编辑

私有票据按候选与已发布草稿分别持有：替换、失败／取消释放未发布候选；续接不释放，发布后保留可审批票据，草稿删除或会话卸载才按票据回收。release同时覆盖手动新建与已有条目编辑，不用clear清空其他草稿。v21／v28回执可进入后续对话上下文。

2026-10-04。入口为 muyu.memory_editor.list/read/preview；这是 GD 角色记忆，不是暮羽长期笔记或 ST 消息正文。

## 来源与操作

独立 memoryEditState 来源授权包含当前聊天角色名称、记忆正文和来源元数据。按需授权、分页读取计入 Provider 共享字节预算；文本是不可信资料，不能作为指令或授权。列表每页16个记忆角色，读取每页6000字符。角色用不透明 memory-role:N 选择器与精确 revision，条目用读取结果中的 index 定位，不接受模型提供头像或按同名角色猜测。

原 list/read/preview 仅开放单条编辑与删除：update 的 changesJson 仅允许 event 与 mood，未指定字段保持原样。event 必须非空，最多12000字符；mood 为 happy/sad/angry/fearful/excited/neutral/mixed。时间、轮次和自定义来源信息不可修改。delete 要求空对象，删除一条而不是全部角色记忆；无直接撤销。

旧角色卡已移除但记忆桶还存在时，以已移除角色标记展示并保留精确桶定位。空仓库返回空列表，不初始化仓库。最多512个桶／角色映射，单桶还受公共 JSON 的1024数组项、4096节点、16层、32768字节上限限制；超限明确拒绝，不把截断资料当完整证据。

## 草稿、批准与保存

modules → host/memory-editor → systems/memory-editor。业务入口只替换选中角色的一个条目或删除一个条目，不改变其他角色桶。私有计划绑定聊天目标、metadata/root/store 身份、所选桶完整基线、角色映射与条目序号。目标桶增删或编辑会使旧草稿失效，无关角色正文更新不使所选草稿失效。

完整 before/after 最多24000 UTF-8字节；超过容量拒绝而非截断。普通模式须审阅并精确批准一次；全权限只接受用户明确执行意图对应的 apply=true，预览仍不写入。重复点击不重复执行，取消、停机或聊天切换使未执行批准失效。

一次写入后调用独立 saveMemoriesChatConfirmed，以 ST 官方聊天读取接口回读 charMemories，不能用变量保存确认代替记忆保存确认。保存拒绝／核验失败返回 outcome_unknown；保存确认但目标桶或聊天发生变化返回 partial。保留并发修改，不自动重试、不用整仓旧快照回滚。已执行的保存无法可靠取消，历史结果不保证之后仍保持该值。

v21 回执只记录操作、角色选择器、条目序号、草稿版本与聊天保存状态，不含角色名字、头像、记忆正文或来源元数据，不授予重新读取权限。草稿中的正文仍受该来源的历史外发约束。

## 范围与验收

不开放生成、整仓导入、批量删除、压缩、跨聊天编辑或暮羽笔记编辑，也不扩展整单 Schema。旧界面行为保持。自动测试覆盖索引变化、角色映射变化、过期批准、保存期间并发修改、容量／非法参数、授权拒绝、普通批准、全权限显式执行及只预览；真实宿主 GUI 与持久化仍待验收。

## 手工新增（2026-10-04）

已接 create_targets/create_preview，复用 memory-editor owner、草稿与精确审批；独立 memoryCreateState 来源包含角色映射、所选记忆基线、容量和当前消息数。可向没有记忆的已知角色追加一条，不接受头像／角色名直接定位。宿主记录时间与消息数，不证明事件发生时间；不额外调用生成模型、不覆盖或裁剪、不改变开关。容量不足拒绝，角色／目标／所选桶／消息数／容量变化使草稿失效。一次专用记忆保存回读，未知不自动重试或整仓回滚；v28回执仅元数据，v21旧合同保持。未接档案／NPC／首次整份蓝图创建、付费生成、批量或整单创建，真实宿主仍待验收。

角色目标按 getCharacters() 的已知角色列表分页，每页16个，使用 memory-character:N，不与旧 memory-role:N 混用。create_preview 的 changesJson 必须包含非空 event，最多12000字符；可选上述 mood，默认 neutral。仅批准时初始化缺失容器并向所选列表追加；不读取其他角色正文，不裁剪旧记忆。新增条目的 before=null、after 完整可见，时间为预览时刻，round 是当时消息数。公共 JSON 容量使单桶最多支持1024条，实际配置上限可更小；达到任一上限明确拒绝，不隐式压缩。未授权读取、按任务允许、拒绝、精确写入与全权限只预览分别处理。新增权限不授权旧记忆编辑或额外生成。
