# 暮羽会话历史按需读取

仅访问当前暮羽会话在本任务发送时的原始记录快照，不是 SillyTavern 聊天、其他暮羽存档或文件系统搜索。记录不因摘要或检索而修改，摘要本身不作为检索语料。

## 职责与权限

- `index.js` 注册 `muyu.history.list/read/search`，复用运行读取额度，负责预算扣除和生命周期清理。
- `search.js` 保留会话历史契约，复用 `../../retrieval/literal.js` 的无状态、同步、有界字面检索；不拥有授权、存储、模型调用或网络。历史默认每条只返回一个命中，Provider 检索允许同条多个命中，两者权限和数据入口仍独立。
- 控制器的 `historyAccess` 是唯一数据入口：检查当前会话、目标、原文指纹、只读状态和历史外发授权。每次调用重新检查，不把历史工具注册为新的宿主资料权限。
- “本次不带历史”、授权导致的历史排除、切换存档／聊天、撤权和导入只读记录不能由搜索绕过。历史引用仍沿用已有外发策略，不授予重新读取酒馆资料、写入或代码执行权限。
- 历史内容是不可置信的参考数据。旧批准文字、工具引用、回执和旧回答不证明当前宿主状态，也不能当执行指令。

## 搜索与回读

`search` 参数：`query`（非空，最多 128 UTF-16 单元）、`offset`（消息序号）、`start`（本条原文 UTF-16 偏移）；可选 `fingerprint` 和 `caseSensitive`。默认只忽略 ASCII 英文字母大小写，中文等其余字符精确匹配，保持原文偏移；不使用正则、分词、Embedding 或语义排名。

首次请求从 `offset=0,start=0` 开始。每次最多检查 32 条消息、65536 个 UTF-16 起点，返回最多 8 条命中、每条消息最多一个命中。扫描边界使用最多 query 长度减一的前瞻，以匹配跨边界关键词。短摘录最多 240 UTF-16 单元，保留完整 Emoji 边界；包含消息序号、角色、指纹、摘录范围、命中范围与原文长度。

返回 `nextOffset/nextStart/nextFingerprint` 时，用同一关键字继续扫描。`complete=true` 只表示已检查从本次指定起点到记录末尾的范围，不代表所有同义词、所有命中或其他会话都已检索。空的部分页不是“不存在”。非零 start 必须带原文指纹；旧指纹或无效字符边界被拒绝。需要同一消息的另一个命中时，可从该命中的 matchEnd 继续，并携带该消息 fingerprint。

找到候选后，用现有 `read` 的 `index/fingerprint/start` 读取最多 4000 字符的原文页，再按 `nextOffset` 继续读。摘录只负责定位；旧值和最新修订应核对后续内容，不能把第一条命中当最终约定。证据不足就说明缺口，不猜测摘要遗漏部分。

## 预算与边界

三个工具共用本运行的历史读取额度，按输出的 JSON 序列化 UTF-8 字节扣除（包含摘录、指纹、游标和元数据）。额度来自运行配置的 providerBytes，但与实时 Provider 正文读取计数独立，不能当两者总额度。授权／澄清续接转移已用计数，结束、取消或销毁时清理。

预算只能容纳一部分命中时，游标退回第一条未发送命中的位置，不跳过证据。完全不足时返回 `BUDGET_EXCEEDED`、空结果和原游标，不继续推进；模型应停止而不是循环重试。搜索过程的本地扫描有独立上限，结果仍通过 32 KiB 闭合工具 DTO；不因大上下文预算放开工具输出。

本轮不新增存档字段、GUI 开关、常驻历史全文索引或依赖包。真实模型是否选到合适关键词，以及用户转述／同义表达的召回质量，仍需实际对话验收；离线测试不保证语义召回。
