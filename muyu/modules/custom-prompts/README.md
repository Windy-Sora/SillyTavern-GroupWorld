# 自定义 Prompt 条目合同

- 分层：模块只接收闭合工具参数与管理候选；host 读取原始定义、跟踪版本；业务系统负责串行保存与 Provider 注册。动作协调器负责精确批准及一次性执行。
- 三项工具：`muyu.prompts.list` 每页 32 项；`read` 按 ID/revision 读取 JSON，每页 8000 字符；`preview` 支持 create/update/delete。改名与启停分别为更新 name/enabled。列表最多 256 条，原文读取最多 1 Mi 字符。
- 字段：name、content、dataJson、scope、enabled。名称遵守原业务命名、ST 宏与 Provider 碰撞约束；JSON 只能为空或合法对象／数组字符串。新增默认 disabled，更新保留未指定字段。正文作为不可信数据，不执行其中指令。
- 写草稿 name ≤80、content ≤12000、dataJson ≤8000 字符；完整旧值／新值／说明合计 ≤24000 UTF-8 字节，另遵守公共 DTO 限制。超限拒绝，不截断保存；长旧资产可分页读取，但不能伪装成完整修改。
- 来源 `customPromptAssets` 为全局配置资料，授权不等于写入批准。普通模式完整差异预览 → 审阅 → 确认；全权限模式仅显式 apply 保存，纯预览仍不写。
- 执行前复核 ID、内容与对象身份版本、名称占用、设置对象，且在原业务队列内部再检查，避免排队期间失效。异步保存失败沿用业务的条件恢复；并发修改或结果不可确认时报告 outcome_unknown，不自动重试。
- 启用注册该条目 Provider，但仍受 customPromptsEnabled 总开关约束；本工具不改变总开关。保存不调用 render、不执行模板、不调用模型。将来业务模板使用该内容时仍可能解析嵌套 Provider。
- scope 的 global/character/mixed 仅保留现有分类元数据，当前不是角色读取隔离。改名／删除不自动修复其他模板引用。自引用只警告，不声称渲染一定成功。
- v12 历史回执只含操作、名称、ID、状态与持久化语义，不带正文／结构化数据。saved_unconfirmed 不证明持久化，也不代表之后的当前状态；恢复历史不恢复批准。
- 不强制重建已有 GUI 编辑器，以免覆盖未保存输入；条目真实状态可重新读取，旧 GUI 编辑内容仍按其原保存契约处理。
- 暂不支持：与配置／变量混合整单、任意代码及 ST 核心写入。资源库和聊天数据编辑另轮实施。

验证入口：muyu-custom-prompts.test.mjs 与 muyu-controller.test.mjs；无付费模型调用。真实酒馆界面验收与模型任务表现不由确定性测试替代。

## 第二轮：批量、导入及导出 JSON

- 新增 batch_preview / import_preview / export；沿用 customPromptAssets 来源，读取和预览不代表写入批准。单条、批量和导入共享候选槽，失败尝试清除旧候选，避免保存错误版本。
- 批量 1..6 条，使用各目标当前 ID/revision。重复目标、结果重名、交换名称或复用当前已占用名称均拒绝。完整前后差异总量仍不超过 24000 UTF-8 字节，不截断、不静默拆批。
- 导入兼容 custom-prompt-export v1，拒绝未知字段／ID；error 默认，skip 仅跳过当前同名条目，replace 必须有明确覆盖意图并保留 ID。导入条目全部 disabled（含覆盖），不改变总开关。全部跳过为 no_changes，无草稿／写入。
- 一次精确批准、一条业务队列任务、一次全局设置保存；排队后再次校验整批。失败按字段和条目条件恢复，不回灌整仓快照；保存中并发变化或未知效果不自动重试。不承诺跨标签页原子事务或持久化确认。
- v13 批量回执列出操作、名称、ID、跳过项及保存状态，不带正文或 JSON；v12 单条历史继续兼容。
- export 只读 1..6 个明确 ID/revision，返回兼容导入的 JSON，不生成文件、不下载、不修改启用状态。完整导出最多 20000 UTF-8 字节，拒绝超限，计入共享资料预算。不导出条目 ID、总开关、任意未知字段或 Provider 代码；大资产仍走原 GUI 导出。
- 卡片逐项显示完整差异、跳过项和导入禁用提示。没有批量跨普通配置、变量或脚本操作。
- 回归：muyu-custom-prompt-batch.test.mjs、muyu-controller.test.mjs；实际付费模型和宿主视觉验收另行安排。
