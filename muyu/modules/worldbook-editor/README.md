# ST 世界书条目编辑

第三轮开放已有条目的备注、正文、主／次关键词、停用和常驻状态；第四轮增加创建／删除条目、创建空书和复制书。`list → read book:N → read entry:N:M → preview`；目录给选择器，书版本绑定整书基线。工具按需发现，统一来源为 `stWorldBookEntries`，读取授权不批准修改。

第五轮增加独立host/worldbook-controls端口：bindings读取→绑定revision→set_global_binding／set_chat_binding。分别替换全局激活数组／当前聊天单本绑定，复用stWorldBooks授权，不更改GD选择策略、不证明注入。delete_book需正文＋绑定两个来源，再精确批准完整书；已知全局、聊天、已加载角色及Persona引用必须为0，未加载聊天引用未知。当前只接全局／当前聊天绑定，角色／Persona编辑留待角色卡独立保存边界，整书重命名未实现。

删除走官方deleteWorldInfo，检查返回true及刷新后书不存在；原生接口可能刷新编辑器，GUI和Skill提前提醒保存／放弃草稿。无法穷举全部历史引用或提供服务器事务／恢复保证。绑定读取、已知引用和聊天归属单独核验，旧草稿遇到切换聊天、绑定变化、整书变化拒绝执行。设置／聊天保存均未确认，未知不重试或回滚。删除前建议自行备份。

宿主端口负责异步加载、正向字段验证、私有票据和执行前整书比较；业务模块负责候选与生命周期；actions 负责精确批准和结果；GUI 展示共享范围、完整差异及历史结果。关键词数组整项替换；未指定字段、未知元数据和其他条目保留。新增条目通过官方createWorldInfoEntry只对私有克隆生成UID及模板；删除展示完整旧条目。复制展示完整源书并保留未知元数据。创建／复制名称采用严格字符白名单和标准化冲突检查，保存前updateWorldInfoList刷新目录，拒绝覆盖；仍无跨客户端服务器CAS保证。新书不绑定或激活，不切换编辑器。整书删除／重命名和绑定留待后续轮次。

保存使用官方 `saveWorldInfo(name,data,true)`。当前 ST 实现先更新缓存，不检查 HTTP 成功状态；返回值及重读缓存均不证明持久化，结果最多 `applied_unconfirmed`。异常或保存后数据变化返回 `outcome_unknown`，不自动重试或整书回滚。整书比较是乐观核验，不是服务器 CAS／磁盘版本保证。

不会重载 ST 编辑器或清掉其草稿；应用前提醒用户先保存／放弃原编辑草稿，之后人工刷新核对。读写保留宏原文，不执行宏、不扫描激活、不调用生成。生成期间拒绝操作。书最多512本、单书1024条／1MiB字符，预览完整差异最多24000 UTF-8字节，超限拒绝，不截断批准内容。
