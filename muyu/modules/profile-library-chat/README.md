# 当前聊天与角色档案库

## 边界

本模块是档案库资产管理之外的独立聊天操作入口。工具为 `muyu.library_chat.capture_preview` 和 `muyu.library_chat.apply_preview`；不生成档案、不调用模型、不编辑消息正文，仅支持当前群聊。

两个工具均需要全局 `profileLibraryAssets` 和聊天级 `profileLibraryChat` 资料来源。读取批准不授权写入。普通模式审核完整差异后精确批准；全权限仅显式 `apply=true` 执行。草稿绑定当前聊天，不因库位于全局而改成全局写入目标。

## 从本聊天保存新包

只复制群聊启用成员的 ready 档案，并包含当时有效的档案生成 Prompt、Schema 和渲染模板。创建新库条目，不覆盖同名包，不写聊天、不立即应用模板。提示后续自动加载可能使用新增包。读取原始 metadata，不调用会初始化／迁移聊天数据的 getProfiles。

## 应用到本聊天

指定库 ID 与版本；按角色内容指纹，其次头像与名称匹配。仅名称匹配必须显式指定。默认保留所有已有档案，包括未完成和错误状态；覆盖必须显式指定。草稿展示匹配依据、完整旧新值、跳过项与未匹配成员。只写列明角色，保留其他档案及手工编辑标记。无可用匹配不写入，也不单独导入模板。

默认不导入模板。显式导入会替换全局档案生成 Prompt、Schema、渲染模板，影响全部聊天，必须在草稿提示。先等待当前聊天确认保存，再写全局设置；不是跨存储原子事务。

## 并发与保存结果

预览、审批、串行队列实际执行前复核聊天／metadata／设置对象、成员、档案、模板及库版本。生成、群聊回合和自动加载忙碌时不执行。切聊天或基线改变要求重新预览；关闭档案功能本身不禁止管理已有档案。

聊天保存失败后不尝试全局写入；保存等待期间切聊天、修改目标档案或模板时停止后续模板写入。已经发生的内存赋值／保存不盲目回滚，也不自动重试；保留并发编辑。全局保存后复核目标和模板，分别报告 confirmed、unconfirmed、unknown 或 not_started。

v15 回执只记录操作、库名／ID、计划档案数和两域保存状态，不带角色正文、身份清单或模板；历史不代表当前状态或权限。pending 草稿不在会话恢复后恢复批准。完整草稿上限 24000 UTF-8 字节，不截断；大包使用原 GUI，暂不支持批次或混合整单。

## 实现与验证

模块负责工具与候选；host 负责精确快照；actions 负责一次审批；profile-library-system 共用串行队列，profile-library-chat 负责聊天及可选模板保存。GUI 不强制重建其他编辑器，避免覆盖未保存草稿。

覆盖单元、真实控制器的普通／拒绝／全权限流程、并发保存和 UI 审批。真实 SillyTavern GUI、宿主持久化和付费模型仍需单独验收。
