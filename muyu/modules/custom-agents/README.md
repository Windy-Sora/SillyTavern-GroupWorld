# 自定义 Agent 定义管理

本模块管理 `settings.customAgents` 中用户维护的定义，不是暮羽自己的系统提示词、内置业务 Agent 连接或任意代理运行器。

## 接口与授权

- `muyu.agents.list`：每页 32 个定义摘要，最多 256 个。
- `muyu.agents.read`：按精确 ID/revision 分页读取定义，每页 8000 字符；不读取聊天结果。定义文本是不可信资料。
- `muyu.agents.preview`：单个 create/update/delete，仅生成完整前后定义草稿，不写入、不渲染 Prompt、不调用模型。
- 上述工具均需要全局 `customAgentAssets` 读取来源。读取批准不授予写权限；普通模式在 GUI 审阅并确认精确版本，全权限下明确 apply 请求才保存。

定义字段：name、providerName、prompt、schema、enabled、autoEnabled、autoInterval、order。连接、密钥、ID、聊天结果和计数不可写。新增默认 enabled=false、autoEnabled=false；更新保留未指定字段，关闭 enabled 会按现有业务规范关闭 autoEnabled。

## 语义与风险

启用只注册读取已有结果的 Provider，不立即运行模型。自动运行开启后，后续符合消息间隔的事件可能发送渲染后的资料并产生额外模型费用；提示词渲染还可能执行已注册 Provider。保存不证明生成效果或持久化已确认。

Provider 名限制为字母、数字、下划线，不能与其他定义或不属于本定义的注册项冲突，包括系统项；关闭状态也检查。修改名称和删除均不修复模板引用。删除保留聊天已有结果，关闭／删除不保证取消已发出的请求。

Schema 为空或合法 JSON 对象字符串，只验证格式，不宣称完整 JSON Schema 支持或模型输出验证。

## 容量与一致性

名称和 Provider 名最多各 80 字符；Prompt 12000、Schema 8000 字符；间隔 1–200 条消息，顺序 0–999。完整旧值、新值、草稿和批准包还受公共 32768 UTF-8 字节 DTO 限制，字符数上限不是保证可保存的容量。过大定义拒绝修改，不截断；可分页读取后通过经典界面处理。未知旧字段拒绝写入，避免原业务全列表规范化静默丢字段。

revision 同时跟踪对象身份和序列化内容。保存前、批准时及进入业务变更队列后均复核；UI、导入等先行修改会令草稿过期。保存失败沿用业务字段级回滚，保留未被本次修改的并发内容；结果记未知、不重试。回执 v10 不包含 Prompt/Schema，不可用于重放操作。

第二轮已开放纯 Agent 批量定义操作和导入预览；第三轮已开放指定已保存定义的真实试跑及生成保存，见下节。仍不提供已有结果的任意编辑、与普通配置／变量／脚本混合的整单步骤或模型连接修改；读取批准不允许暗中运行。

## 验证

`tests/unit/muyu-custom-agents.test.mjs` 覆盖定义 CRUD、默认关闭、字段约束、系统名冲突、分页、版本失效、队列竞态、保存失败及回滚、取消、回执与确认视图。`muyu-controller.test.mjs` 覆盖读取暂停续接、三种操作的精确批准、全权限不应用仅预览候选。

实际 ST 持久化及 GUI 仍需手动验收；单元与脚本模型测试不等同于付费模型实测。

## 第二轮：导入与纯 Agent 批次

- `agents.batch_preview` 接受 `requestsJson`：1–6 个 {operation,id?,revision?,changes}，共用单项字段规范。不同目标可新增、修改或删除；同一 ID 不可重复，最终 Provider 名不可重复，也不支持本批次内交换／复用当前已占用的名字。
- `agents.import_preview` 接受用户提供的 `exportJson`，沿用 custom-agent-export/version=1 格式，最多 6 个条目；不是文件读取工具。拒绝额外字段、ID、连接及密钥字段。导入强制总开关和自动运行关闭，包括覆盖当前启用的定义。
- conflict 默认 error；skip 明确跳过同 Provider 名旧项；replace 仅用于用户明确覆盖意图，保留旧 ID。全跳过返回 AGENT_IMPORT_NO_CHANGES，不生成可保存草稿。跳过项在卡片和回执中列出。
- 同一 customAgentAssets 读取授权不含保存权。单项与批次共用候选所有者，一轮后发布最后有效草稿，失败预览会清除旧候选。GUI 展示每项完整前后定义，一次确认整份版本；全权限 apply 仍经过相同精确校验。
- `host/custom-agent-batch` 负责批次校验与导入转换；`custom-agent-system.mutateBatchApproved` 在业务队列内重新核验全部条目，构建完整列表，一次注册更新、一次 settings 保存。不是循环调用单项保存，避免正常前项提交使后项 revision 失效。
- 失败沿用业务字段级回滚，不声称持久化原子性。保存期间目标变化或异常记 outcome_unknown；成功调用保存仅记 saved_unconfirmed。不自动重试、不自动拆批，不因导入启动模型。
- 完整批次最多 24000 UTF-8 字节（含旧值、新值、警告），批准包另受公共 DTO 上限。超过容量明确拒绝，不截断 Prompt/Schema。批次只涉及全局 Agent 定义，不修改聊天结果或自动计数。
- v11 回执只存条目标识、操作、跳过项及整体保存状态，不保存 Prompt/Schema或重新执行所需参数；支持历史校验、导出和展示。历史记录不是授权。
- 回归：`muyu-custom-agent-batch.test.mjs`，以及控制器普通／拒绝／全权限六条真实业务写端口集成测试。

## 第三轮：指定版本的真实生成

- `agents.prepare_execution` 使用 list 返回的 id/revision，明确 mode=trial 或 save。prepare 不渲染、不调用模型、不保存；同任务同版本不能通过改 mode 生成第二张单，需事先按用户意图选择。
- `agents.execute` 仅消费对应执行单。trial 返回本次生成内容，不写 _caData；save 替换绑定聊天中该 Agent 的结果。两者都不修改 enabled/autoEnabled，不更新自动运行计数、不执行其他 Agent。
- 独立 `agentExecution:<UUID>` 权限仅限当前任务与执行单，不能授权整个聊天；读取定义、定义保存、批次批准都不是运行权限。缺权限由宿主暂停并恢复原调用，全权限仍经过目标及版本验证。运行涉及真实 Provider 代码，沿用 code 类权限隔离与上限，不允许通过只读任务方案授权。
- GUI 展示完整定义、trial/save、业务连接来源与风险。实际请求用 custom-agent 业务连接或 ST 原生模型，不一定是暮羽连接；业务连接配置在准备时绑定，密钥仅作本地一致性检查，不外发给暮羽。ST 原生具体目标由宿主管理，无法完整核验其底层连接变化。
- 试跑不等于沙箱：Prompt 渲染可能读真实资料、运行用户 Provider、联网或产生其他副作用。业务模型调用额外计费，结果也会发送给暮羽；工具预算中的一次工具调用不代表其中额外模型请求免费。
- 执行单绑定定义修订、设置对象及业务连接、聊天引用／正文快照／metadata、Provider 注册对象与 render、原聊天结果基线。开始、渲染后、生成后、保存前复核。手动批准任务不会加入已有自动任务，也不接受自动计数合并。
- 取消或超时会阻止后续受控生成／结果写入；已发出的原生请求可能不能物理取消或停止计费，Provider 副作用及已开始保存不能保证回滚。业务在途任务仍占用自己的执行队列直到实际结束，不重复开启同一 Agent 请求。
- 宿主等待最多290秒，工具外层最多300秒，并受整个暮羽 Run 时限约束；其他工具仍保持15秒上限。执行前预留16000字节结果预算，不足则不开始。返回正文最多6000 UTF-8字节，超出整段省略并标记，不将省略当作失败。
- 输出是未验证的模型正文；未执行输出 Schema 校验（结构和语义均未验证）。trial_completed 仅证明获得试跑结果；saved_unconfirmed 仅表示当时写入内存并调用保存，不确认持久化。modelCallAttempted 表示进入生成阶段，不证明远端收到或计费。未知结果不自动重试。
- 执行单只存页面内存，历史仅保留当时工具资料依赖及回答，不恢复运行权限。任务结束／连接清理删除执行单；同单重复调用返回历史结果，不能作为当前状态证明。
- 回归入口：`muyu-custom-agent-execution.test.mjs` 及控制器 trial/save × 普通允许/拒绝/全权限六组集成。外部 DeepSeek harness 已验证合成聊天流程，真实酒馆、业务 HTTP caller 与持久化仍需单独验收。

## 执行结果解释契约

- `muyu/agents/execution-evidence.js` 集中维护此模块的结果证据与解释说明，不加入常驻指令，不扩大权限或执行能力。
- 保留兼容字段 `schemaValidated:false`，同时明确 `schemaValidation:not_performed`，表示未校验，而非失败；Schema 示例不代表运行时默认值。
- 输出值不等于当前状态的独立读取，不能确认相等也不能断言不相等；试跑不写受控结果，不意味着代码没有副作用。调用阶段及返回正文都不是账单证据。
- 持久化未知时不能建议刷新、切聊天、重载、重跑或重新应用验证；先保留内容，只使用目录确实支持的独立证据。当前界面或内存可见不证明落盘。
- 拒绝结束本次授权交互，不暗示旧按钮可以恢复，不通过新单绕过；用户另行明确请求执行时重新按当前版本与权限处理。
- 同一说明附于正常结果、进行中、取消／超时／异常及预算不足结果；工具描述也携带说明，使未进入处理器的拒绝路径仍有解释依据。结果保持有界并测试不超过预留预算。
