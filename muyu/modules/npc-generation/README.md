# NPC业务生成

2026-10-04 第二轮：NPC状态读取、精确准备、一次执行工具与权限、结果预算和双语授权卡已接通。通过真实 NPC Agent、Prompt/Provider 和 NPC 业务模型执行，不用暮羽模型直接伪造已保存 NPC。

## 工具与授权

| 工具 | 效果 | 必需来源 |
| --- | --- | --- |
| `muyu.npc_generation.state` | 只读数量、容量、选项与版本；不初始化仓库 | `source:npcGenerationState` |
| `muyu.npc_generation.prepare` | 纯准备，绑定模式、请求数量及当前上下文 | `source:npcGenerationState` |
| `muyu.npc_generation.execute` | 一次付费业务生成及可选追加保存 | `source:npcExecution:UUID` |

普通模式缺少权限时，运行时只为此已登记 external 工具的精确来源交接；用户批准后续接原工具调用，不增加模型请求。执行许可仅本任务、此单一次，不支持聊天／连接常驻。读取许可、诊断、配置草稿或只读方案均不能代替执行许可。全权限模式不弹卡，但仍核验目标、单据、容量、业务设置、模型／Provider 实现及结果预算。

执行前预留16000 UTF-8字节，不足返回 not_started / RESULT_BUDGET_EXCEEDED，不调用业务模型或写入。工具结果没有可重新应用的产物 owner，不从历史恢复单据／授权。存档仅保留对话和来源依赖；导入不能重跑历史生成。旧只读任务模式不提供此组工具。

## 用户语义

- “试试／先预览／不要保存”使用 trial：真实生成，不初始化或写入 NPC 仓库。
- “生成并保存”可用 save：只追加当前聊天的唯一新记录。请求数1–200，默认当前批量选项；实际最多为请求数和剩余容量的较小值。全酒馆角色、存量 NPC 和本批次名称均去首尾空白、忽略大小写检查重名。
- 不覆盖已有 NPC、不裁剪、不开启功能、不操作资源库，不创建或导入 SillyTavern 角色卡。角色卡导入权限不在本模块。
- 使用 NPC 独立业务连接或酒馆原生连接，额外产生模型费用，不保证与暮羽同一连接。真实 Prompt/Provider 可读取资料、执行代码、联网及产生副作用，trial不是沙箱。
- 取消／超时未排空仍 busy，未知保存不自动重试或整仓回滚；partial 与 outcome_unknown 不伪装成功。applied_confirmed只证明执行时的确认保存，不是当前值或内容事实证明。no_result 表示没有接纳新记录；outputOmitted只省略长结果 DTO，不截短已保存正文。

GUI显示试生成／追加保存、请求数／实际最多、已有数／上限及“不导入角色卡”；技术执行单在 details 中供核对。新增通知不走整面板重建，避免替换编辑草稿。

## 生命周期与验证

模块只在宿主提供受控 npcGeneration 端口时装配。生产 busy 包含导演／其他业务生成和档案库加载，不包含自身 NPC 物理锁，以免内部校验自锁。Run绑定、同任务续接、释放任务与销毁清理沿用公共模块生命周期；执行结果只能是历史资料。
