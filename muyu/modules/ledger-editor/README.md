# 当前聊天导演账本编辑

2026-10-04。muyu.ledger_editor.list/read/preview 支持当前聊天的单条账本编辑与清空，不是自动化记录、消息编辑或脚本执行器。

## 来源与读取

独立 ledgerEditState 来源含角色名字、账本正文和自定义公开字段；正文是不可信历史资料，不是指令、授权或真实执行证明。列表按存储顺序（旧到新）每页16条，ledger:N为零基数组位置，round仅显示序号；读取精确revision，正文每页6000字符。结果计入共享资料字节预算。

不初始化不存在的聊天仓库。最多512条，公共JSON的32768字节／4096节点／16层限制仍有效；异常仓库或复用同一条目对象拒绝。所有以下划线开头的内部字段只留在宿主基线，不发给模型或草稿，包括消息裁剪锚点。

## 可编辑范围

update 的 changesJson 只支持：

- reason：理由，字符串最多12000字符，可为空。
- speakers：发言人名字数组，最多128项，每项非空白字符串且最多256字符，可为空数组。
- scripts：角色名到剧本提示文本的对象，名字键非空白且最多256字符，文本最多12000字符。
- loreAssignments：角色名到世界书条目名字数组的对象，名字及数组使用以上限制。

数组／对象是完整字段替换，不隐式合并。未指定字段保留；speakers修改会同步已有names显示别名，并在完整差异中显示，不创建缺失别名。字段可以按契约补入清空的记录，但不创建新轮次或锚点。名字是存储文本，不保证对应当前角色或真实已激活世界书。

clear 要求 changesJson={}，清空该条所有公开字段（含自定义字段），保留数组位置、对象身份和内部消息元数据。不物理删除、归档或提供直接撤销。完整 before/after 不含内部字段，草稿明确锚点不变。

账本参与导演历史提示词与上一轮失败恢复。修改发言人／剧本可影响后续恢复，不证明过去真正发言，也不立即生成、修改消息或执行代码。正在生成／回合／接管时拒绝；最新条目写入后沿用原onLatestEntryEdited通知使选人缓存失效。

本轮不支持整仓覆盖、批量清空、新增轮次、整单步骤、自动重新生成或其他聊天写入。

## 审批、并发与保存

modules → host/ledger-editor → systems/ledger-editor，沿用通用动作协调器。私有计划绑定聊天、metadata/root/list身份、所有条目引用与顺序、选中条目的完整字段（含内部锚点）。追加、裁剪、重排、条目替换、选中内容或锚点变化使旧批准失效。无关条目的原地正文更新保留。

完整草稿最多24000 UTF-8字节，超限拒绝不截断；最多64私有计划、512版本缓存。普通模式精确批准一次；全权限仅用户明确执行意图对应apply=true才执行，只预览不写。

仅修改选中记录，复用官方ST聊天保存及专用saveLedgerChatConfirmed回读directorHistory；不调用旧updateEntry再次保存。面板通知只更新提示，不重建账本JSON编辑器，未保存草稿保留；用户手动刷新查看。保存异常／核验失败为outcome_unknown，保存确认但目标或基线随后变化为partial。未知结果不重试、不整仓回滚，不保证撤销已经开始的保存。

v25回执只有操作类型、选择器、草稿版本、时间及聊天保存结果，不含角色、理由、剧本、世界书分配或内部锚点。回执是历史结果，不证明当前配置或授权；草稿历史仍受ledgerEditState外发权限限制。

自动测试不联网、不调用付费模型；真实宿主GUI布局、导演后续恢复与持久化待手动验收。
