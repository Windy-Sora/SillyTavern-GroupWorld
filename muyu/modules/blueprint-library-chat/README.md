- muyu.blueprint_library_chat.capture_preview：当前聊天蓝图存为新全局包，名称必填；includeProgress默认false，显式true才复制已有进度。

## 预览与进度语义

预览不调用真实getState/buildExportFile或真实导入器，以免懒初始化、轨道切换或隐式保存。systems/blueprint-library-chat.js在隔离metadata、设置和只有length的聊天替身上调用真正的Story Blueprint导入器；不会请求模型、触发变量系统或保存真实数据。

应用完整展示旧状态与隔离计算后的新状态：

- 不导入进度：清除旧蓝图所有模式／层级轨道与legacyDoneSignals，当前配置轨道从零开始。
- 导入进度：复用原导入器，将各轨道整理为对应步骤的连续前缀，消息位置限于当前聊天长度，清空完成通知键。当前推进模式／层级不改变；包内activeProgressKey不覆盖全局配置。保留的legacyDoneSignals仍是归档，不当作当前轨道完成证据。
- 现有兼容的布尔完成变量重置false，防止旧信号推进新树；不创建缺失变量、不改定义、不开启功能。锁定、类型／作用域冲突、外部owner、重复定义或孤立值拒绝。
- 导入会沿用原业务更新lastGeneratedAt、清除lastError/continuePending。该时间不证明生成模型曾被调用。

包内进度不是当前聊天实际完成的证明。用户须核对完整差异；不得因为批准蓝图库资源修改而自动应用聊天。

## 执行与保存

host保留最多64份私有精确计划，公开草稿ticket不代表授权。完整差异最多24000 UTF-8字节，并沿用通用JSON复杂度限制；超限不截断后批准，可用原GUI。

复核metadata与settings身份、蓝图、指定完成标记、消息数量、配置模式层级、资产版本及忙碌状态；与旧GUI库操作共用业务队列，排队后再次核对。导入计算只发生在预览，执行使用批准的完整after，不重新计算差异。

存包只保存全局设置，正常仍为saved_unconfirmed；应用只做一次聊天保存，由独立saveBlueprintLibraryChatConfirmed同时回读蓝图和变量仓库。确认不向模型发送整个变量仓库。写入只替换蓝图和指定完成值，保留其他聊天内容。

保存异常为outcome_unknown，保存返回后目标／内容变化为partial；可能保留已写内存，不整仓回滚、不自动重试。v19回执只含包名、数量、操作与两个保存域状态，不含节点正文、变量定义或进度。回执是历史证据，不是当前状态或批准。
