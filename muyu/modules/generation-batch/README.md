# 整单业务生成

2026-10-04第二轮：`muyu.generation_batch.prepare`与`execute`已接入统一助手、经典GUI和原调用授权续接。宿主必须提供受控generationBatch端口，否则不注册两工具。旧诊断／聊天任务模式不开放。

## 读取、准备和执行

公开步骤 Schema 使用闭合 oneOf 与宿主逐类合同一致：memory/profile 必须带 character 且禁止 count；npc 可带 count 且禁止 character。纯准备阶段 INVALID_GENERATION_BATCH／DUPLICATE_GENERATION_BATCH_STEP 返回可纠正 not_started（零已完成步骤）；不扩展到执行／保存未知结果，后者仍停止而不自动重试。尝试数和输出数不是账单凭据。

先使用已有记忆／档案角色目录、NPC状态取得修订号；prepare仅要求选中领域的目录许可，不申请无关资料。1–8步，每步kind、mode、revision，记忆／档案另含character，NPC可含count；不接受模型提供目标聊天。对象与模式被冻结在宿主私有执行单内。

执行只要求`source:generationBatchExecution:UUID`精确许可，task-only、不可常驻，也不授予子单的memoryExecution／profileExecution／npcExecution。读权限、只读方案、旧单步批准都不能升级。全权限跳过提示但不跳过当前性与预算检查。批准时再次检查宿主执行单；runtime仅对该登记的external工具和同UUID缺失来源暂停，并续接原工具调用，不额外请求模型。

GUI逐行显示操作、角色／数量、试跑或保存、最多业务模型调用数与非原子事务说明，源码详情默认折叠；名称按文本渲染，不执行HTML。取消／过期不重放。

## 预算与生命周期

execute必须声明maxModelCalls（1–8），不足以覆盖整单maximumModelCalls时零执行。每个整单最多8次额外业务模型尝试，**独立于暮羽模型调用预算，不代表整轮所有其他工具的业务调用总上限**。整个整单先预留24000 UTF-8字节结果预算，不逐步扣费后才发现不足；准备描述也计入资料预算。外层工具受当前Run剩余时间限制，底座整体期限290秒不逐步重置。

同一task／target／executionId缓存同一个Promise及结果，重复调用不再次预扣或执行。预算不足可以在无副作用时重新调用；已开始或结果未知不自动重试。跨授权续接只transfer同目标同任务绑定；任务结束、切换／撤销与dispose清理执行单和内存结果，不持久化执行闭包／批准。

不原子回滚：仅已确认的本单前一步更新后续基线，未知／部分保存、并发变化、取消或超时停止。trial不保存，但真实渲染不是沙箱；memory保存可裁剪所选角色旧记忆，profile仅新建缺失标准档案，NPC仅追加、不创建／导入ST角色卡。蓝图生成／续写继续跳过，设置／库／代码资产和启用功能不在此单。每步历史结果不证明当前状态或事实。长正文省略不删除保存内容。

历史仅保存资料依赖及对话，不恢复执行单或权限；导入历史剥离执行依赖并重新要求资料外发确认。工具返回逐步结果，不新增可持久化、可重放的整单执行产物。

验证：新增20项模块／权限与历史、10项真实业务控制器、4项双语GUI测试，相关491项通过；全量2698项：2697通过、1跳过、0失败，17/17历史BUG契约通过。初次测试暴露Schema不支持minItems、长工具超时需显式登记，均沿原验证规则修正；控制器断言已使用真实profile嵌套格式。未调用付费模型，真实ST及付费模型验收待进行。
