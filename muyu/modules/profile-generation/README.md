# 单角色档案业务生成

2026-10-04 第二轮：暮羽工具、独立执行许可、预算和GUI已接通；业务底座见[合同](../../../systems/PROFILE-GENERATION.md)。仅标准单角色试生成／缺失保存，自定义Schema、覆盖已有档案、批量／整单生成继续单列。

## 工具与最小权限

- `muyu.profile_generation.targets`：读取profileGenerationTargets，16/page、最多512角色。只外发名称、已有状态、新建可用性、opaque selector和版本；不返回角色正文、头像、Prompt或连接密钥，不初始化仓库。目录不会为每个角色复制长聊天。
- `prepare`：要求目录提供的character／revision及mode=trial或save；准备不渲染、不调用模型、不修改数据。用户要求试跑／预览时必须trial。save只新建缺失档案，不覆盖任何已有记录，包括null、pending、failed、手工ready；不修改共享Schema、归档或资源库，不开启功能。
- `execute`：external效果，唯一来源为source:profileExecution:UUID。普通模式暂停原调用，批准后续接同一调用，无额外模型轮询。仅本任务同目标指定单一次，禁止持续授权；全权限直接放行已支持效果，仍核验目标／版本／预算。读取、只读方案、手工草稿许可均不授予付费生成权。拒绝后不能换来源或新单绕过。

生成使用原档案Prompt／Provider及档案业务模型或ST原生连接，不保证与暮羽同一连接。真实渲染可能读取资料、执行代码、联网或产生副作用，trial不是沙箱；审批卡用中英文展示角色、模式、已有档案保护、费用与取消局限。仅标准四字段Schema，其他Schema在渲染／付费前拒绝，不能宣称完整自定义Schema校验或事实核验。

## 预算、结果与生命周期

执行前预留16000 UTF-8字节结果预算，不足则not_started / RESULT_BUDGET_EXCEEDED，零付费／写入。目录和准备按实际输出字节扣除；额外业务模型费用不混称为暮羽模型Token用量。注册最大执行时间300秒，宿主默认290秒；用户任务超时和取消仍有效。至多一次业务模型尝试、零重试；同ID返回缓存历史结果。

trial不保存；save仅创建指定缺失记录，用宿主角色hash及时间标为非手工ready。长结果超过6000字节只从工具DTO省略，不改变已保存正文；outputOmitted不表示失败。applied_confirmed描述当时确认保存，不证明当前值或角色事实；partial表示确认保存但当前性已变化；outcome_unknown不得自动重试或整仓回滚。modelCallAttempted只说明尝试，不证明送达／计费。

取消／超时阻止晚到受控写入，不保证原生计费、Provider副作用或在途保存被撤销；物理请求未排空仍busy。生产端口同时检查导演、其他业务生成及档案库自动加载，不把自身物理锁纳入回调busy判断，避免自锁。保存不调用旧全量档案刷新，以保留草稿及共享Schema元数据。

仅宿主有受控端口时装配，旧只读任务模式不开放。Run迁移仅限同任务同目标；未绑定模块的迁移为空操作。任务结束释放执行单，dispose清空。历史仅保存对话和来源依赖，不恢复执行闭包／授权；导入记录仍是数据。历史外发许可不授予重新读取或生成权限，执行来源不进入只读方案许可及重读来源列表。

## 核心接线理由与验收

runtime新增的业务分支只匹配这个已登记external工具与唯一精确执行来源，使PERMISSION_REQUIRED沿原调用续接。没有把任意external效果升级为可申请权限；新工具仍经过能力合同、闭合Schema、Broker、任务绑定和宿主当前性核验。未增加独立产物owner：结果为有界工具数据，不是可重新应用的配置草稿。
