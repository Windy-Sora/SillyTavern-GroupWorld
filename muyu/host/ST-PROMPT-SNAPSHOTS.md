# 酒馆提示词构建快照

## 证据范围

通过 `getContext().eventSource/eventTypes` 监听官方 `CHAT_COMPLETION_PROMPT_READY` 的 `{chat,dryRun}` 与 `GENERATE_AFTER_COMBINE_PROMPTS` 的 `{prompt,dryRun}`。同步复制监听时的文字投影，不修改 payload；不监听任意网络请求，不读取 `GENERATE_AFTER_DATA` 的完整请求对象，不主动生成、dry-run、执行过滤函数、宏或 Provider。

捕获时同时投影 `getContext().extensionPrompts` 的文字、位置、深度、角色、scan 和是否有 filter。这是**当时注册的注入项**，不是实际采用、排序、过滤通过或最终注入证明。不读取任意扩展设置。

消息与注册项分别复制，不保证官方事件消息已合并或未合并注入。某段未出现在消息文字中只能记为“该投影未见”，不能推断缺席原因、正常布局或注入失效。

构建事件不是最终发送、服务器接收或生成成功证明；其他事件订阅者可能继续修改内容。没有可靠请求关联 ID，生产者保持 `unknown`，目标只标 `observed-current-chat`。不把 GD、暮羽、RP 或第三方请求强行归类，也不按时间邻近拼接世界书激活事件。没有快照时明确未捕获，不代表实际 Prompt／注入为空。

## 数据与权限

默认关闭。开关在**暮羽悬浮球齿轮 → 资料与权限 → 酒馆提示词构建快照**，插件配置页不增加入口。开启采集不授予模型读取权限，全权限也不自动打开采集开关。

开启只采集之后的新构建，不能追溯此前未采集的请求。来源目录完整读取后若 `available=false`，协议返回 `readHint.recovery=stop` 和不可重试说明；停止正文读取，不猜选择器、另读聊天凑证据或主动生成。此停止提示不阻止之后确有新事件时，用户重新发起读取。

- `stPromptOverview`：独立概况来源，只含快照 ID、时间、阶段、dryRun、角色／索引、字符数、位置与截断信息；不含消息正文、消息名称或注册项名称。
- `stPromptText`：独立正文来源。先读本来源目录，再按 `message:N` / `injection:N` 及对应 revision 分页；沿用 Provider 的 UTF-8 读取预算、2000 字符输出页和版本失效协议。概况授权、预设授权和消息授权均不自动授权正文。
- 正文保留不可信原文，可能包含聊天隐私或用户放进 Prompt 的秘密；正向白名单不等于自动脱敏。注册项名称只在获授权的 injection 正文返回。

仅接受字符串 content；工具调用对象、tool_call_id、消息 name、图像／音频／多模态数组、headers 和任意未知字段不采集。角色只允许已知角色值，其他为 unknown；这些缺口和截断会标明，不能将文字投影当作完整请求。

## 生命周期与容量

本页只保留最近一个事件。消息和注册项各最多128项，文字合计最多100000 UTF-16字符、每段最多16000字符，截断不拆代理对；两个类型共享总预算，后面的注册项可能没有剩余正文。概况返回原字符数和实际截断／遗漏情况，正文读取不会填补被丢弃的部分。容量是诊断缓存边界，独立于暮羽对话输入预算。

正文详情 `chars` 是原始UTF-16字符数，`retainedChars` 是本段实际保留正文的UTF-16字符数（不含JSON包装／说明）；模型不自行估算包装长度来代替正文长度。Provider分页读尽只表示已读完保留投影，不保证原文完整。

30分钟后删除；聊天、主接口、聊天补全来源或模型切换时清空；目标不匹配时也删除，不在返回旧聊天后复活。新事件、清空和失效都会改变 evidence，旧 revision 不继续读。面板重建复用同一服务；控制器 dispose 解除监听，不拦截 fetch / console。

设置中仅持久化采集开关及版本，快照不写入 `extension_settings` 或历史存储。**已授权发送的工具文字及由它产生的回答仍遵循既有对话存储设置**；关闭／清空不能撤回已外发资料，也不能删掉已经保存的回答。模型来源的正文读取仍需用户授权。

只做构建快照安全切片，未提供服务器端日志、最终传输抓包、世界书条目到 Prompt 的可靠映射或跨请求因果诊断。真实宿主／模型验收另行进行。
