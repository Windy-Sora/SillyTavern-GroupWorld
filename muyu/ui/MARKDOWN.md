# 聊天 Markdown 渲染

markdown.js是无运行依赖的安全子集渲染器，不宣称完整CommonMark兼容。

支持标题、段落、粗体、斜体、行内代码、围栏代码块、有序/无序列表、引用、分隔线、简单管道表格和显式HTTP(S)链接。消息正文用div容器承载块元素，发送给模型的原始文字不受渲染影响。

长回复采用紧凑标题、明确段落间距和轻量行内代码底色，不继承宿主的大标题尺寸。编号列表因说明段落拆开时保留源码起始编号，避免每项都显示为“1”。默认回答指令建议结论先行、短标题分组、概况用短列表；不强迫短回答使用报告格式，也不改写既有历史正文。

仅使用createElement/textContent/setAttribute，不使用innerHTML、不调用酒馆宏处理或脚本执行。原始HTML保持文字，图片语法不创建img，不自动加载远端资源。链接只接受无用户名/密码的绝对HTTP(S)地址，点击新页时使用noopener/noreferrer；javascript/data/file和相对路径保持文字。不提供HTML、LaTeX、Mermaid、语法高亮及复杂嵌套列表支持。

输入显示限制为32768字符/2000行，超限明确标记截断，行内格式递归深度最多4层。代码块与表格在消息气泡内横向滚动，链接长字符串可换行。单元测试覆盖基本格式、恶意HTML、脚本链接、图片不加载、未闭合围栏及超长输入。实际字体、长表格/代码块在320px窄栏的布局仍需实机确认。
