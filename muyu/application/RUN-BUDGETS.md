# 工作台第一阶段：运行预算与有限收尾

## 用户入口与配置

气泡窗口齿轮 → 运行与预算。保存或恢复默认均通过宿主确认保存，写入插件设置 `muyuRunConfig`；它是本地助手执行策略，不随剧情配置档导出/应用。未保存编辑不会因任务进度刷新而丢失。

| 配置 | 默认 | 范围 |
| --- | --- | --- |
| 模型调用次数 | 12 | 2–16 |
| 工具调用次数 | 48 | 1–64 |
| 单轮总超时 | 300秒 | 10–1800秒 |
| 每次模型输出Token上限 | 32768 | 256–32768 |
| Provider正文读取预算 | 2097152 UTF-8字节（2 MiB） | 6000–16777216字节 |

默认档面向 1M 上下文模型，输入预算另为 900000 估算 Token。设置初始值、宿主无配置回退和恢复默认按钮共用同一常量。未标记的旧运行默认组合（6/16/120秒/8192，正文预算24000或1000000；以及12/48/120秒/32768/2 MiB）读取时升级；自定义组合不改。明确保存预算会设置独立版本标记，以后即便重新选择旧默认组合也不升级。已保存120秒的用户可在界面调整或恢复默认。读取不触发保存；标记与配置在保存失败时一起回滚。不增加权限、不自动整理、不延长在途任务。

纠错次数（2）、单批最多64个工具、JSON/HTTP字节保护、模型思考私有缓存及物理清理限制不开放。输出Token上限不是输入上下文窗口，也不保证服务商支持该数值；更大的输出仍受协议/字节保护。没有无限预算。

配置由 `core/budget.js` 校验，`host/run-config.js` 负责确认保存与失败回滚。控制器在用户发送时复制配置，运行内核、模型请求和Provider读预算使用同一份快照。运行中保存配置只影响后续发送，不重建当前连接、不撤销授权、不修改当前Run。

## 预算原因和用量

保留原 `BUDGET_EXCEEDED` 错误码兼容调用者；新增闭合 `budget.reason`：model_calls、tool_calls、corrections、tool_batch、provider_bytes、run_time、model_output。TIMEOUT和MODEL_OUTPUT_TRUNCATED保持原错误码。

`run.usage` 提供受限数字：调用数/上限、纠错数、经过时间/总时间、Provider读取字节/上限、单次输出Token上限、服务商报告的输入/输出Token合计和有报告的调用数。过程投影不保存任意payload、正文或密钥。

窗口“本轮开销与限制”与每次请求的执行记录都显示数据；状态行补充限制原因。耗时在步骤/完成事件更新，不是连续秒表。Token仅统计服务商实际返回的合法usage；缺失/失败调用不估算为0，报告覆盖率明确显示。调用合计不是单次上下文大小，不提供费用估算或输入上下文压缩。

## 有限收尾

控制器开启 `finalizeOnLimit`；底层运行API默认关闭以兼容现有使用者。

当下一次是最后一次模型调用，或工具调用/Provider读取预算耗尽时：

1. 不再启动新工具。一个批次中未开始的调用补充 `not_started` 结果，保持调用/结果完整配对。
2. 在原预算和原截止时间内请求一次收尾，要求仅依据已有证据、说明缺失与未完成部分。
3. 模型适配器保留历史工具名称映射及必须的思考回传，但本次请求不再提供工具定义，不关闭思考。
4. 若服务仍要求调用工具，失败并停止；不执行工具、不额外申请模型调用。

收尾计入modelCalls，不是额外免费请求；成功收尾仍保留reason和finalizing标志，不把部分调查宣称为完整。取消、已超时、协议错误、纠错耗尽不触发额外收尾。所有路径仍等待真实drained释放运行槽。

Provider正文预算按实际新读取结果计算；Broker同callId结果复用不再读源。重复回传与模型思考产生的Token由服务usage另行统计，不能用资料字节预算代替完整上下文预算。

## 本阶段边界

错误过程显示经过闭合投影的安全错误码，不显示服务商原始响应。`CONTEXT_LIMIT` 指完整输入请求预算（含工具、结果及思考回传），`MODEL_OUTPUT_TRUNCATED` 才是输出截断；提高 `maxTokens` 或 `providerBytes` 不提高 `muyuContextConfig.inputTokens`。预算失败后的历史外发确认独立于预算设置，不会通过保存预算自动授予权限。

后续实现补记：历史工作台和上下文工作台已落地。`muyuContextConfig` 独立控制输入估算目标，不与 `maxTokens` 混淆。压缩预算另设 `summaryTimeMs`，默认300秒、可配置10–1800秒；自动摘要占用当前 Run 的调用/时间预算并保留10秒给后续回答；手动摘要独立最多一次调用，期限不超过压缩与单轮预算。请求检查包含必要思考回传，超限不再调用。详见 [上下文合同](../context/README.md)。下述“没有”描述仅指最初预算阶段。

没有历史侧栏/对话持久化、自定义system prompt、自动摘要、授权暂停申请、预算增加后续跑。失败后再次发送是新Run，不是检查点恢复。上述属于后续工作台阶段。

离线测试覆盖最后一次收尾、批次截断配对、收尾模型违约拒绝、超时/取消无额外调用、Provider配额、固定配置、保存失败、Token未知和思考回传；真实模型是否遵循收尾要求、宿主保存和浏览器排版仍须实机验收。
