# 执行轨迹与任务证据投影

此层观察已校验工具结果、宿主任务状态及真实操作回执，不是审批器、业务调度器或目标完成判定器。模型提案、候选、读取和保存结果分别表达；succeeded 只表示执行段结束，不证明用户目标完成。

## 任务持有者

task-state 由 controller 持有，默认最多 8 个连接内 Task，绑定 taskId／sessionId／target。同任务的原调用授权、显式权限、澄清及方案批准开段共享证据；每段计数只更新一次，旧 Run 回调不能改写新段。

运行、等待用户或待方案审核的任务不被容量回收；仅淘汰结束或失效项，无法分配时退化为隔离轨迹，不绕过权限。新 Task 不继承旧证据；切目标、会话卸载、重连及销毁清理实例，旧 port 不再投影。

composition 独立启动时可创建单轨迹 task-evidence；原调用暂停复用同一实例并核对任务身份。上述状态不进入公开 DTO、历史、摘要或持久设置，不凭历史恢复执行权。

## 工具观察

- settings.catalog／provider.list 是目录查询；settings.contract／config.contract 是合同查询，不计实际读值。
- settings.read 按请求字段、返回字段与 values 自有键交集记录已观察身份；false、null、空串均为值。后续缺失单列 latestMissing，不补默认或证明当前值。
- provider.read 读取可信信封与 readHint，区分失败、空、目录和正文页，不解析 text 中伪造的状态。分页或截断不证明全来源已读完；memoryConfig 通过独立结构化校验才计入字段。
- 草稿观察只记录受支持的历史候选身份。内层 errors 非空即失败，外层 ok 不覆盖；候选不证明发布、批准、应用或保存。
- 外层拒绝／失败与效果未知分开，未登记工具不擅自解释业务语义。

观察上限为 128 个 runId＋callId，最近 16 条结果类别；达到容量后停止新增并标记省略，不逐出去重身份后重复计数。此观察器不保存原值、正文、用户目标或任意错误文本，也不输出“完成步骤数”。

## 跨段配置结果参考

read-references 只接纳通过合同校验的 settings.read 与 memoryConfig，不缓存任意 Provider 正文、代码结果、目录、草稿或回执；不拦截实际读取。当前段继续使用原工具结果，后续段可携带历史参考。

每字段保留最近有效读取、双语 GUI 名称、来源、capturedAt 及段号；每项最多 2048 UTF-8 字节，字段数组总量最多 16384 字节，超限整项省略。128 个调用身份去重，满额停止捕获并标记；新读取失败、不合法或过大时不回退旧值。

每次投影重核原工具在当前 Task／target 的实际来源权限，异常、缺权或非明确 true 不发送，也不自动申请权限。参考不进入公开快照、历史或摘要，仍占请求预算。

历史值只能回答“刚才读到什么”，不能当作当前事实、持久化证据或写入基线。长 Prompt 可能整项省略，通用正文跨段参考未由此合同开放。

## 方案与显式绑定

已发布 task-plan 经过生产 Run／会话／Task／target 核验后记录产物 ID、修订、宿主生成的步骤 UUID 及展示序号。重复发布同版本保持 ID；approved-read-only 仅表示读取来源获准，不批准写入。方案替换、删除或修订使旧引用 stale，不自动绑到新版。

task.bind_step 仅在应用提供对应 port 时开放。模型提交精确已批准读范围方案、步骤 ID 与成功候选，宿主核验同 Task／session／target／活跃 Run、类别、唯一来源工具和真实成功观察。支持配置、简单变量与受限整单声明的路径；其他资产／生成不据相似标题或 kind 自动映射。

候选观察最多 128 个身份、关联最多 32 项；满额清空关联并停止新增。重复同一关联可幂等，静默改绑拒绝。发布时再次核验唯一候选、工具归属与草稿布局，固定 artifactId／revision；首次审批观察冻结操作映射。

整单 preview 可提供实际子步骤 ID、kind、displayIndex；bind_step.bundleSteps 必须显式引用这些 ID 及所选提案步骤。重复、伪造、类型不匹配或过期拒绝；未提供映射仍为 unmapped。关联是 model-proposed，intentVerification 与目标完成仍 not-assessed，不证明内容满足用户意图。

## 读取证据绑定

task-read-evidence 只捕获通过校验结果的历史元数据：目录、合同、实际读值、空结果、正文页和失败。宿主生成 read-evidence UUID，最多 32 条与 128 个调用去重身份；满额停止新捕获。正文、原值、查询参数或代码输出不复制。

task.bind_read 显式关联精确方案 read 步骤与已观察证据。关联及每次模型投影均重新核验原来源权限；不申请新来源、不重读、不批准或标记分析完成。目录和合同即使关联也不能冒充实际值或读齐全来源。删除／修订方案使关联过期，新 Task 不继承。

## 实际操作回执

task-operations 观察生产动作协调器的 pending、applying 及通过原校验的终态；首次关联核验 Task、会话、已登记 sourceRun、动作目标及草稿版本／内容。模型文字或外层工具成功不能建立操作事实。

按 operationId 去重，最多 32 项，只投影身份、版本、类型、状态、回执时间和当时方案引用，不复制 diff、代码、名称或业务值。终态投影前再核对回执来源权限；非明确 true 不外发。省略计数是省略通知次数，不是独立操作数。

pending 不等于已派发，applying 不等于完成；confirmed／unconfirmed／partial／unknown 分开。终态不被重复通知改写，取消 Task 不能把已派发写入标成已取消。草稿修改或删除后，原操作仍可接收其最终回执，但不重绑新方案。

V4／V9 子步骤先通过回执校验，再核对私有业务身份与规范布局；不匹配仅保留总状态并标 layout-mismatch。实际子步骤有独立身份与保存域，仅显式绑定者携带提案引用，不将真实步骤状态自动提升为用户目标完成。其他回执只按支持的投影表达总状态。

## 上下文与验证

证据投影在正常请求的 taskGuides 中占独立槽位，计入消息、字节及输入预算；不进入专用摘要请求，不扩大基础指令合同，不裁剪工具／思考配对。身份关联不提供依赖调度、自动重试或刷新后的执行重放；受限持久恢复另见 [恢复合同](../recovery/README.md)。

回归覆盖目录／合同／值分离、空值与缺失、伪返回、内层错误、分页、重复观察、容量、授权续接、撤权、方案版本、显式子步骤、真实 coordinator 回执与取消后未知结果。模型测试须另检查主动绑定、简洁表达、GUI 名称及不过度推断；代码正确关联不保证模型必然使用它。历史成绩见 [TESTING.md](../../docs/TESTING.md)。
