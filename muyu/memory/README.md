# 暮羽长期记忆 · 第一阶段（2026-10-01）

这是用户偏好、工作约定和背景笔记，不是 GD 角色记忆、会话摘要、对话存档或任务待办。没有自动学习、后台模型调用、向量检索或聊天正文的自动复制。

## 使用

配置 → 资料与历史 → 暮羽长期记忆。可以新增、搜索、编辑、刷新和二次确认删除；开关默认关闭，关闭不删除记录。手动管理不需要先开启模型使用。

开启后可以说：

- `记住：回答先给结论，细节需要时再展开。`（默认仅当前酒馆聊天）
- `请全局记住：我偏好中文回答。`（明确跨聊天，保存为账户范围）
- `我以前希望怎么回答？`（模型按相关词检索并回读）
- `忘记“我偏好中文回答”。`（需精确点名已有标题或 ID；版本不符不会删除）

首版模型写入刻意严格：请求须以“记住／记下／更新偏好／忘记／删除”等操作表达开始，保存正文必须是本任务初始用户消息的精确原话。不能保存模型概括、历史内容、工具结果或猜测；不能借澄清回答、权限续接和全权限开关扩张此边界。更新还须明确点名原标题或 ID，且不能改变已有范围；GUI 可以显式调整范围。复杂表述或改标题可用编辑器处理。

账户范围额外采用封闭肯定前缀：`全局记住`、`在所有聊天记住`、`跨聊天记住`、`账户内记住`、`globally remember` 或 `for all chats remember`（可带礼貌前缀）。正文中的“全局／account”词不构成范围授权；出现否定、仅当前聊天或冲突修正时保守拒绝账户提升，不自动重写用户原话重试。这个规则不声称能理解任意自然语言；复杂范围要求请在 GUI 手动选择。

## 分层

- `memory/contract.js`：闭合版本 DTO、可见范围和存储容量。
- `host/agent-memory.js`：账户身份、设置保存、串行写入和版本比较；不引用 GUI 或模型。
- `memory/workbench.js`：控制器拥有的草稿和列表；DOM 重建不丢草稿。
- `modules/agent-memory/index.js`：模型可见 Schema、只读分页和明确用户原话写入。
- `ui/agent-memory-view.js`：管理界面，仅派发命令，不直接读写设置。

工具、效果、双语标签仍走原有装配合同与 Broker。关闭时整组 `muyu.notes.*` 不进入模型工具列表，调用前也重新检查开关；全权限不代替启用。不存在任意文件路径、其他聊天选择器或 Provider 代码执行入口。

## 数据与持久化

`muyuAgentMemoryEnabled` 和 `muyuAgentMemoryData` 存在酒馆当前账户的插件设置中（settings.json），不是 chat_metadata，也不需要 gd-muyu-history 服务端插件。账户身份缺失失败关闭，明确单用户模式才使用单用户命名空间。

仓库版本 1，每条记录含 UUID、独立修订号、标题、正文、账户／聊天范围、宿主聊天键、创建／更新时间（Unix 毫秒）与 `manual`／`user-quote` 来源。聊天键由宿主绑定；模型不能指定别的聊天。账户范围可见于同账户的全部聊天，聊天范围只在对应聊天可见。版本不符、删除后的旧版本或错误账户数据均拒绝；持久化记录不能恢复工具授权或运行。

私有记忆及开关均排除于配置档快照、JSON／ZIP 导出、导入和应用。它们仍可能进入用户主动备份的整个酒馆设置文件，不是加密存储。简单密钥特征检测只是补充防护，不能保证识别所有敏感信息。

本地记忆与账户设置对话仓库通过 `storage/settings-queue.js` 共用设置对象的串行修改队列，避免会话保存把记忆尚未确认的工作副本写入文件；读取等待正在保存的修改。仓库发布的私有快照不可变，外部调用者获得副本；编辑器绑定聊天及设置所有者，切换后保留旧草稿但禁止保存。保存失败仅回退自身仓库投影，不覆盖其他配置或并发替换的仓库；已开始的宿主保存不能撤销，错误、目标切换或保存后快照替换均按保存结果未知处理，不自动重试。此队列不约束其他插件、旧的普通设置保存、多浏览器标签页或设备，整个 settings.json 仍可能互相覆盖，建议单页使用并保留备份。

## 检索、预算与遗忘

`muyu.notes.list` 用字面子串搜索标题／正文，最多返回 8 个元数据，按匹配结果 offset 分页；不是语义搜索。`read` 按 ID、revision 和 UTF-16 offset 回读，默认最多 4000 字符，可用 maxChars 减小页，保持代理对边界。工具整个 JSON 输出计入本任务 Provider 资料预算，并通过原运行状态展示；续接不重置已经使用的预算。不会自动把整库正文注入提示词。

list 成功结果包含 `coverage`：query、匹配总数、offset、匹配分页是否结束，以及账户＋当前聊天范围。非空 query 的 `query_matches` 只统计字面命中，不证明不存在同义／无关笔记；空 query 才是 `visible_inventory`，仍不含其他聊天的本地笔记。多页读取不是全库原子快照。计数和范围元数据同样计入整个输出预算，预算拒绝不发布 coverage。

保存动作只有宿主保存调用确认且目标／设置仍匹配才返回 `saved`；`save_unknown` 不表示确定未保存。旧记忆仅是历史参考，不能据此断言当前设置、保存结果或业务事实。

saved 增加 `writeReceipt`：实际保存范围、`recallMode=on_demand`、`automaticContextInjection=false`，以及未报告新建／未做语义查重的标记。账户范围表示跨聊天可读取，不保证每轮自动采用；saved 不证明首次新建或不存在重复。未知／失败结果不发布成功回执。模型保存确认默认只说偏好与范围，不展示内部 ID 或 revision，也不把表达偏好映射成插件配置字段。

记忆写入是专用外部效果，在工具阶段保存，而不是等待最终回答后才应用。最终模型请求失败或被取消，不会撤销已确认的记忆；可以在编辑器核对实际记录，不能把任务失败等同于确定没有写入。

同一任务的相同模型写入参数复用原结果（包含未知结果），续接保留此记录，不能通过换调用 ID 重试保存。新的明确记住请求若与同范围现有正文完全相同，复用原条目，不累积重复记忆；这不是语义合并，冲突偏好与近似内容仍需显式编辑。

删除不会抹除已经进入旧暮羽对话、对话备份或摘要的文字。首版无后台提炼任务，因此不会从旧对话自动复活被删记录；将来增加自动提炼时，必须另加来源权限继承、删除标记及去重／冲突规则，不能直接把模型摘要当用户原话保存。

容量是宿主设置文件的保护，不是上下文预算：最多 256 条、每条正文 16000 字符／64000 JSON UTF-8 字节、整库 2 MiB。超限明确拒绝，不静默截断。后续若需要更大仓库，应增加存储后端，而不是无界放大酒馆设置文件。
