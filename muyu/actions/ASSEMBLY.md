# 动作装配与生命周期

[assembly.js](assembly.js) 管理实例内动作所有者，[builtins.js](builtins.js) 显式登记协调器、产物 kind、目标范围及宿主 writer。登记不启动预览、保存或模型调用，也不授予批准。

## 所有权与调用顺序

- 装配校验 ID、kind、所有者、范围和必要钩子；缺项、重复或未知 kind 明确失败，不能默认交给整单协调器。描述副本不含 writer、批准闭包或私有数据。
- busy、list、invalidate、drain、clear 使用同一所有者集合；原回执顺序和模块专用批准／核对条件保留。
- 停止使待批准操作失效；已派发写入继续占有物理 busy，排空后才能切连接、重新装配或清空。停止不证明撤销，不重试未知或部分完成结果。
- invalidate 访问全部钩子后聚合错误。drain 即使遇同步／异步异常也等待所有者 settle。clear 先检查所有 busy，避免部分提前清除。
- GUI 仅订阅控制器；取消订阅或重建不清动作、Task 证据或会话。这些资源属于扩展实例和任务。

## 模块与回执接线

[联合模块装配](../modules/ASSEMBLY.md) 核对工具、候选、产物与动作归属，管理 Run／Task 私有资源；[GUI](../ui/LAYOUT.md) 使用可信呈现描述，保留原批准入口。

[回执协议](RECEIPTS.md) 核对动作变体、精确版本、所有者、来源政策、模型投影及 GUI 技术策略。未知 module／version 不回落配置回执；兼容旧 DTO 不恢复历史批准。

新增所有者接入公共生命周期后，仍需独立提供能力、权限、业务保存合同、产物呈现和测试；不能据此声称任意模块自动可执行。

## 验证要求

动作装配回归覆盖非法描述、未来测试模块、描述隔离、异常聚合、物理排空及真实协调器。控制器回归另覆盖普通／全权限、连接和聊天变化、面板解绑、来源撤销和历史回执。确定性测试不替代真实 ST 保存与 GUI 验收。
