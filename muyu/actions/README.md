# 草稿、批准、执行与回执

动作层负责可信应用操作的生命周期：不可变批准副本、目标／版本重核、单次消费、真实执行排空与诚实终态。能力范围见 [当前能力表](../../docs/MUYU-AGENT-STATUS.md)，接线见 [动作装配](ASSEMBLY.md) 与 [回执合同](RECEIPTS.md)。

## 准备、批准与执行

预览只建立候选及完整差异。普通模式由用户在当前草稿上审阅并批准；全权限仅按明确用户意图及工具 apply／install 等对应标志交由可信应用执行。自然语言、读取授权、测试成功和只读方案批准不能自行升级成写入权。

config-apply 及其他专用协调器持有连接内不可变操作副本，包括操作 ID、产物 ID／revision、会话、目标、基线和具体差异。按钮只提交操作 ID，不能改目标或内容。准备、批准和实际派发前均核验；进入 applying 后重复点击不再次执行。

writer 只改批准字段，保留未指定值；不补默认值或隐含开关，不恢复全设置快照覆盖并发修改。普通字段由 [配置契约](../config/README.md) 登记，旧四项记忆配置只是兼容入口，不是完整支持范围。

全局配置影响所有聊天；聊天数据、代码资产、生成和库应用各使用专用 writer。切聊天不能将旧操作归到新聊天；全局所有者也不允许从另一暮羽会话随意批准。来源、目标、连接、内容或基线失效后必须重新预览。

## 专用效果

| 操作类别 | 合同 |
| --- | --- |
| 普通配置与特殊副作用字段 | [配置契约](../config/README.md)：记忆上限裁剪、蓝图完成变量、业务开关等按专用计划处理，不能混入普通整单 |
| 变量、记忆、档案、NPC、蓝图和账本 | [模块装配](../modules/ASSEMBLY.md) 与各编辑器合同：精确条目／树／进度基线，不是任意聊天仓库覆盖 |
| Provider、脚本、自定义 Agent、Prompt、Skill | 定义保存、测试、真实执行分别核验；代码可能产生外部效果 |
| 三类资源库 | 库定义、当前聊天存包和应用分别批准；聊天与全局模板分域保存 |
| ST 世界书、角色卡与预设 | 使用官方端口及专用差异，保护编辑器草稿；乐观核验不等于跨客户端 CAS |
| 业务生成整单 | [生成合同](../modules/generation-batch/README.md)：受控步骤、独立执行许可、调用与结果预算，不混入任意编辑或脚本 |
| 可选服务工作区 | [服务合同](../services/README.md)：仅受限文档、精确预览票据与独立批准，缺少服务不可执行 |

配置档草稿保存只增加资源，不应用当前设置。批量能力只适用于各模块明确支持的范围，不从单条 CRUD 推导通用批量。

## 保存结论与中断

ST 全局设置保存返回或全局 SETTINGS_UPDATED 事件不能可靠关联为某次操作落盘证明。普通配置通常报告 applied_unconfirmed；只有可信且能关联本次操作的保存凭据才可确认。内存回读一致只证明新读取时点的值，不能证明过去保存成功。

各业务合同分别报告未开始、已更新但保存未确认、确认保存、部分完成和结果未知。蓝图开关先处理聊天完成变量再保存全局设置；记忆上限涉及全局保存和当前聊天裁剪。跨域失败可留下已执行部分，不自动恢复或重试。

changed 表示保存等待期间后续变化／对象替换／核验警告，不是本次是否改值；saveError 不推翻已发生的内存赋值。未知分支的 false 可能仅表示未取得结果。异常原文不写回执或发送模型。

停止只使未开始批准失效，不能撤销已发出的保存。重连／禁用等待物理排空；保存中限制会话管理。仅保证实例内重复批准不重复派发，不承诺跨标签互斥、服务器事务或跨刷新 Exactly Once。

[恢复工作台](../recovery/README.md) 为受支持配置／整单提供检查点、本地核对与新的批准；符合条件的普通配置可预览撤回。它不自动恢复旧批准，不对所有资产、生成、脚本或未知保存提供回滚。

## 历史回执与解释

终态形成独立只读回执，绑定原暮羽会话。草稿差异是提议，不单独证明批准或成功；artifact revision 不是当前设置版本。视图重建、复制、导出及历史重载不再次执行。

回执按会话 DTO 合同随历史保存，格式兼容由 [回执协议](RECEIPTS.md) 和 [会话合同](../sessions/README.md) 管理。历史保存失败与业务结果分开；重试保存历史不调用业务 writer。容量错误须保留可见结果并提示备份。

模型只在对应来源与历史外发规则允许、预算足够时获得有界回执投影。它通过独立 applicationContext 通道进入，不伪造用户命令、tool_call_id 或系统指令。“不带历史”按相应合同排除旧回执。

配置回执的“让暮羽解释结果”是独立只读请求，不能生成或重新应用草稿；解释失败可重试解释，不改变操作结果。“核对当前配置”读取当前内存并比较提议字段，不调用业务写入，也不能确认过去落盘。其他回执仅显示其声明的入口，未知版本不回落配置操作。

## 展示与验证

配置界面优先使用 GUI 名称，技术字段及完整原值按需展开。草稿保留原差异，回执显示实际结果；两者按精确 ID 与版本关联，不按标题或相似内容猜测。旧回调失效检查是展示保护，最终权限仍由控制器和动作层核验。

回归覆盖预览不写、伪造／重复／过期批准、基线变化、同步／异步保存错误、并发编辑、部分完成、未知结果、连接排空、检查点和面板重建。真实宿主持久化与视觉验收须另行记录。
