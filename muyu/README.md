# 暮羽 Agent

关闭长期记忆或业务总结后，仍可要求暮羽只读核验保存的笔记／当前酒馆聊天总结。还可按来源核验暮羽对话存档的清单与指定记录格式；不向模型发送旧正文，不恢复历史授权或操作。管理读取不会启用、生成、迁移或修改内容；服务插件未安装不影响其他来源。详见 [保存资料核验](modules/storage-inspection/README.md) 和 [对话存档核验](modules/archive-inspection/README.md)。

暮羽是 GroupWorld 内置的酒馆助手，使用独立聊天窗口，按需调用工具和 Skill，帮助用户理解功能、读取资料、排查问题，以及预览和执行已接入的配置或资产操作。GroupDirector／GD 为保留的兼容名称，不是额外安装依赖；适配与验收见 [MIGRATION](../docs/MIGRATION.md)。

它通过 SillyTavern 扩展接口与宿主交互，不修改酒馆核心代码。具体能力取决于当前聊天、宿主接口、用户启用项和授权；不能将工具目录或模型回答当作已经读取、执行或保存的证明。

## 使用入口

在插件设置顶部点击「召唤暮羽」，选择「打开暮羽 Agent（推荐）」，或点击暮羽悬浮球打开聊天窗口。按钮右侧的「显示暮羽悬浮球」开关控制入口显隐，不停止正在执行的任务。

聊天窗口的齿轮集中管理模型连接、权限、预算、上下文、长期记忆、Skill 和可选服务。可使用支持的酒馆当前连接，也可配置独立模型接口；未配置连接时，发送会引导到连接设置并保留输入。

直接描述需求即可，不需要先选择任务类别。普通模式下，按需处理资料授权、澄清和精确草稿确认；阅读全开与全权限模式的含义、风险及限制见权限说明。

完整操作步骤见[用户手册](../docs/USER-GUIDE.md)与[英文用户手册](../docs/USER-GUIDE_EN.md)。

## 能力与执行边界

- 资料读取按来源、目标、版本和预算核验；拒绝不能通过换工具绕过。分段读取、空结果与完整读取分别处理。
- 配置、变量、业务数据和资产操作通过已登记模块提供；是否可编辑或执行，以对应工具与领域合同为准。
- 任务方案批准只允许对应读取流程，不等于配置应用、业务生成或代码执行批准。
- 普通单份草稿和支持的整单须核对精确范围后批准；全权限也不绕过启用项、能力白名单、目标核验和预算。
- 用户 Provider 或脚本的真实执行不等于沙箱测试，可能具有副作用；不得把读取权限当作代码执行许可。
- 业务生成可能调用另一个业务模型，费用和等待时间独立于暮羽的规划调用。
- 任务失败、取消或网络中断不证明之前的写入已撤销；结果未知不自动重试，也不自动回滚已确认操作。
- 历史回答、方案与回执是当时的记录，不代表当前配置或可恢复的授权。

ST 消息编辑／删除、蓝图业务生成／续写等未开放给暮羽的操作，不因插件其他界面具有该功能而自动获得执行入口。具体边界见[能力说明](../docs/MUYU-AGENT-STATUS.md)与各模块合同。

## 上下文、记忆与存储

暮羽会话与酒馆 RP 聊天是不同的数据层。切换酒馆聊天后可继续暮羽会话，但读取和执行仍须绑定当前目标，旧任务与授权不能任意跨目标复用。

- **会话历史**：保存问答、来源依赖和受限历史结果，可管理标题、归档、删除、导入及导出；同内容只读备份重复导入不新增，修改过的备份保留为独立只读版本，不覆盖原对话；不会恢复可执行任务或历史授权。
- **上下文整理**：预算内规划携带历史，支持手动／可选自动摘要；摘要不删除原文、不扩大资料权限，也不等同于完整保留所有信息。
- **暮羽长期记忆**：保存用户偏好、工作约定和背景笔记，按需读取；不是 GD 的角色记忆、剧情状态或授权。
- **存储方式**：齿轮的“存储与记忆”提供读取来源单选、写入位置多选，可空闲切换浏览器、账户设置、世界书与服务文件；各位置独立核验和报告保存结果，冲突不覆盖、不自动迁移。世界书无需服务插件，可同一酒馆账号跨设备接续；操作检查点仍在当前浏览器。
- **世界书合卷**：新会话按可配置容量目标复用存档卷。旧v1书可在“对话历史 → 合并旧版世界书存档”手动合并，默认保留原书作静态备份；清理已合并旧书需另行二次确认。旧副本发生分叉时停止，不擅自选版本；操作前请导出备份并关闭其他设备和旧页面。
- **可选服务**：文件历史、搜索、网页正文、本地资料检索、工作区草稿及 JSON 校验须按实际服务能力与启用项使用。没有安装时不提供相应新工具。

账号设置、对话备份和服务文件不是加密保险箱。资料发往当前模型、搜索服务或网站的范围应向用户说明，敏感数据不要放在公开的前端扩展目录。

## 代码职责

| 目录／入口 | 职责 |
|---|---|
| `composition.js` | 组合运行时、模块与宿主端口 |
| `core/`、`tools/` | 工具循环、执行状态、JSON 合同与调用核验 |
| `application/` | 会话与任务协调、证据、预算、交接与控制器 |
| `host/` | SillyTavern 适配、目标捕获和具体业务端口 |
| `modules/`、`actions/` | 工具装配、候选产物、批准动作与回执 |
| `permissions/`、`interactions/` | 权限策略、请求身份和一次性用户决定 |
| `context/`、`instructions/`、`retrieval/` | 历史规划、摘要、指令与有界检索 |
| `sessions/`、`storage/`、`memory/` | 对话仓库、存储协调与用户长期记忆 |
| `skills/` | Skill 目录、资源读取、启用管理与运行时加载 |
| `self/` | 暮羽自身参数的固定只读投影，不开放自身设置写入 |
| `model/`、`web/`、`services/` | 模型、搜索与可选服务客户端 |
| `ui/` | 订阅式聊天视图和设置，不直接承担业务写入 |
| `server-plugin/` | 可单独安装的服务端代码，不存放真实用户数据 |

经典插件入口位于 `../ui/sections/muyu.js`；悬浮外壳位于 `../ui/floating/`。视图关闭或重建不应销毁正在运行的业务，业务生命周期由控制器和相应所有者管理。
