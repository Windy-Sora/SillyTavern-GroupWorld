# 50 万工作上下文：实现与后续边界

2026-10-01。面向 1M 模型的默认输入策略为 900000 **估算** Token，可设置 4096–1000000。旧完整默认组合自动升级；明确保存的新预算、自定义组合及 null 保留，详见 README。不是模型能力声明，也不是实际 tokenizer 计量；服务商可能有更小的窗口、请求限制或费用限制。

## 已实现

- 历史规划可使用输入预算的 90%，不再按 25% 和近期轮数过早截断；最终请求仍包含问题、行为指令、工具、结果和私有思考，并由适配器重新计量。
- 无容量压力不自动整理。有效摘要后的全部未覆盖原文保持连续，不足时阻塞，不借整理或裁剪绕过资料授权。
- 摘要候选按输入预算的 10% 保留连续近期原文，不再固定两轮；默认约 90000 估算 Token。按完整问答边界，包含夹在其中的失败/取消消息。短对话全部能放入该额度时使用近期轮数参考值，至少留一轮作为整理候选；受单次摘要容量限制时不裁掉超出目标额度的尾部，仍按连续性保护处理。
- 已接入当前暮羽会话原文的有界字面关键词检索，返回短摘录及位置，再复用指纹核验回读。分页、输出预算及历史外发限制保持有效；授权／澄清续接转移已用历史读取计数。不是跨会话、酒馆正文或语义检索，详见 [历史模块](../modules/history/README.md)。
- 启用自动整理后，首次请求使用适配器完整计量，在输入或传输预算 80% 处提前触发，包含工具、指令及私有开销；百分比是本地输入压力，不是模型窗口。连续三轮失败暂停自动整理，可在上下文中恢复或手动整理。授权续接与在途工具/思考轨迹不参与新压缩。
- 模型请求与 HTTP 传输统一为 8 MiB 安全上限；工作消息最多 4096，历史规划预留 256 个消息槽位。单条模型文本最多 2 MiB 序列化 UTF-8。
- 大文本使用独立的 model-message 边界；工具参数、工具结果、事件元数据继续使用原来的 32 KiB 闭合 DTO，拒绝访问器及未知消息字段。长输出拆成小事件，避免扩大观察者边界。
- 新的资料读取预算默认 2 MiB UTF-8 字节，可配置到 16 MiB；Provider 续接不增加原预算。历史回读使用本轮配置的独立预算，不再固定 16000 字节，并支持长消息偏移和 4096 条消息索引。两种读预算独立，不是一个合计额度。
- 浏览器与文件存档合同一起扩容：4096 条消息、32 MiB 单记录、256 MiB 总量。记录结构保持兼容，不删除原文；服务端独立仓库和插件内附带版本保持一致。大存档需更新附属服务端。
- 初始用户目标已作为当前输入出现且没有额外约束时，不再重复注入一份 Task goal。长输入经过 GUI、控制器、应用层和模型层的同一文本边界。

## 验证

新增确定性测试验证约 40 万估算 Token、200 轮/400 条原文消息进入运行请求；超过旧 1 MiB 的请求经过真实适配器和替身 HTTP 传输；超预算在网络访问前拒绝；长文本不能扩大工具 DTO 或执行访问器；大记录的客户端与文件后端一致。此轮没有把离线计量标成付费模型实测或模型回答质量结论。

专项新增 6 项回归，暮羽单元测试合计 576/576 通过；独立附属服务端仓库 9/9 测试通过。浏览器输入、CORS、真实 tokenizer 和服务商窗口不属于这些离线结果的证明范围。

最终全量测试 1321 项：1320 通过、1 宿主契约跳过、0 失败；静态检查 530 源文件、11 JSON、206 模块 smoke，通过 17/17 历史 BUG 契约。内核架构契约保持原样通过，安全容量常量放在纯 core/context-limits，不引入内核到上层策略的反向依赖。

## 尚未实现

这轮是大工作窗口基础设施，不是完整无限历史 RAG：没有真实 tokenizer、模型窗口自动发现、历史语义搜索、证据引用型任务检查点或分块/JSONL 存档。滚动摘要仍有损，不保证保留所有事实；现使用可配置的输出 Token 预算（默认 16384，已保存自定义值保留）和共享的 512 KiB 序列化文本安全上限，不再固定 1500/6000 字符；摘要连包装必须比原文小。DeepSeek 摘要请求关闭思考，普通 Agent 请求配置不变；通用接口不发送专有参数。自动整理默认关闭。Provider 的单页、单来源和工具调用数量仍有独立边界，不能因为扩大工作窗口就假称已经读完几十万字的聊天资料。当前暮羽会话的关键词定位与回读已接入；后续可评估真实提问的召回质量和大来源分块读取，而非继续膨胀常驻提示词。

存档读写仍是有界完整记录，原生浏览器配额、多标签页、界面大记录渲染和真实服务商窗口仍需实机验收。实际请求超限会明确失败，绝不自动换模型、增加预算、授予权限或宣称全量上下文已读取。
