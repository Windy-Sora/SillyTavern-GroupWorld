# SillyTavern Group World

中文 | [English](README_EN.md)

一个为 [SillyTavern](https://github.com/SillyTavern/SillyTavern) 打造的群聊导演与剧情管理扩展：安排谁来发言，维护角色记忆和剧情状态，也可以让内置的 **暮羽助手** 帮你查资料、排问题、调整设置。

当前版本：0.6.0 · [用户手册](docs/USER-GUIDE.md) · [安装](#安装)

## 能做什么

### 暮羽助手

暮羽是一位猫头鹰娘助手，可以陪你一起打理酒馆。点击羽毛悬浮球，打开聊天窗口，直接告诉她你想做什么。电脑、手机都能用，也不需要先进入群聊。

不清楚某个开关怎么用，想检查一套配置，或者打算做个金币系统，都可以直接说，不用先研究内部字段和模块名称。

- **帮你看懂和排查**：找按钮、解释设置，在授权后查看聊天、记忆、变量、世界书、角色卡和预设等资料，分析哪里出了问题。
- **帮你准备和执行修改**：调整已支持的配置、管理角色卡与世界书等内容；复杂需求可以先做计划、给出修改预览，再按所选权限模式执行。
- **陪你把事情做完**：独立对话历史、新对话、导入导出、上下文整理和长期笔记；内置 Skill 提供专门的操作指南，也支持管理自己的技能。

可以试着问她：

> “帮我看看现在的设置有没有互相冲突，只分析，不修改。”
>
> “把单角色记忆上限改成 10，先预览，不要应用。”
>
> “我想做一套金币系统，先帮我规划需要改哪些地方。”

暮羽 Agent 不需要先导入角色卡或世界书。喜欢原来角色卡形式的用户，也可以继续从召唤菜单导入暮羽角色卡与世界书。

### 群聊导演：让合适的角色开口

减少每轮所有角色一起抢话的情况，根据当前对话选择发言者，也可以安排发言顺序和本轮行动。

- **公式模式（Formula Director）**：通过提及、关键词、主动性和连续发言惩罚评分，选出 Top-N 个角色，不增加模型调用。
- **LLM 模式（LLM Director）**：让模型结合剧情安排角色与顺序，支持本轮剧本和单独指令。

### 记忆与剧情：把长故事接下去

角色档案、角色记忆和聊天摘要帮助保留人物与事件；NPC、世界书、变量和故事蓝图用于整理登场人物、世界设定与剧情进度。相关内容可以查看、编辑，并通过资源库复用。

### 自定义与分享

可以调整各功能提示词，用 Provider 和模板 DSL 组织自己的数据源，也可以编写脚本或自定义 Agent。配置档支持导入导出，方便保存自己的玩法或分享给别人。

## 安装

1. 在 SillyTavern 打开 **扩展 → 安装扩展**，填入仓库地址：

   ```text
   https://github.com/Windy-Sora/SillyTavern-GroupWorld
   ```

2. 安装后刷新页面，在扩展列表中确认已启用。
3. 打开 **Group World** 设置即可使用。

也可手动放入 `public/scripts/extensions/third-party/SillyTavern-GroupWorld` 后刷新。插件不需要构建，不修改 SillyTavern 核心文件。

## 开始使用

### 先和暮羽聊聊

1. 在 Group World 设置中点击 **召唤暮羽 → 打开暮羽 Agent（推荐）**，或点击羽毛悬浮球。
2. 打开窗口齿轮 → **模型连接**，选择复用受支持的酒馆当前 API，或填写独立接口。
3. 直接输入需求。初次可以先问功能、做只读检查，再尝试修改预览；想分开话题，在暮羽历史侧栏点击 **新对话**。

### 配置群聊导演

1. 打开一个群聊，在 Group World 中选择导演模式。
2. 想先简单控场，可以选公式模式，将 **Top-N** 设为 `1`，再按实际效果调整权重。
3. 想由模型安排剧情与发言顺序，切到 LLM 模式并配置模型与提示词。

也可以从配置档中选择 `group-world-default`，查看并应用一套起始设置。更多设置说明见 [用户手册](docs/USER-GUIDE.md)。

## 使用前了解一下

- **模型与费用**：暮羽、LLM 导演及其他 AI 生成功能需要可用的模型连接，可能产生费用；公式模式的选人不增加模型调用。模型和酒馆版本会影响可用能力。
- **权限与修改**：普通审批模式可先预览、确认后执行；也提供开放只读与危险的全权限模式。开启前请了解范围，修改重要内容前先备份。不是所有酒馆功能都支持操作。
- **隐私与存储**：授权读取的资料和携带的历史可能发送至模型服务。对话支持浏览器、账号设置、世界书及可选服务存储；注意备份。内部历史世界书是明文存档，应保持条目禁用，不要启用、绑定或手动改名。
- **旧版兼容**：GroupWorld 与 GroupDirector **只能启用一个**。旧 API、设置键和存档标识会保留，不需要手动改名；两者的数据也不是互相隔离的。

### 可选的暮羽服务插件

基础 Agent 不依赖附属服务。需要服务端历史、联网搜索或本地资料等附加能力时，可按需安装 [SillyTavern Muyu Services](https://github.com/Windy-Sora/SillyTavern-Muyu-Services)。这是安装在酒馆服务器上的插件，不是前端扩展，请按其 README 操作；联网搜索还需相应配置。没有安装时，不影响基础对话与导演功能。
