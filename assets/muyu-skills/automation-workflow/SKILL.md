# 自动化与发言后策略

先完整读取 references/workflow.md。自动记忆用记忆技能，脚本或自定义 Agent 定义用开发技能；此处聚焦总结、点评、发言后策略及自动化之间的配合。

先查实际配置合同与必要当前值，再解释总开关、自动开关、消息阈值和触发阶段。不开启功能来“试试看”，不将现在的参数当过去是否执行的证明。

明确会增加哪些后续模型调用，哪些只是显示／保留记录的上限。Capability 动作可能有外部副作用，阻塞选项不代表模型分析免费或被跳过。

小范围改动给最小预览，多模块用精确方案。不开口承诺新增 Capability 写入、实时监控、后台日志或即时补跑旧消息。
