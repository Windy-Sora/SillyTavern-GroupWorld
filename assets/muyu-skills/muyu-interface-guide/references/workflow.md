# 界面指引方法

## 查询入口

`muyu.context.read({ids:["muyu.interface"]})`给出当前版本的公开GUI事实，名称与关键按钮共用UI元数据；不是当前页面截图，也不是用户配置值。根据用户问题只讲对应路径，不展示整个JSON或内部页面ID。工具未提供／资料缺失时明确无法确认入口，不编造菜单。

连接入口指南不提供暮羽当前地址、协议、模型或密钥，也不赋予连接管理工具。用户明确问实际配置时，可按本轮工具合同用 muyu.self.read 读取参数元数据；地址／模型文字及草稿走 muyu.self.read_text 的独立正文权限，不返回密钥，不把读取说成已启用或已修改。导出来自当前会话库记录，可能包括恢复内容，不等于已确认落盘，不猜尚未保存消息会被遗漏。

填完点击“启用此连接”，不是必须打开“自动启用”；自动启用只控制后续恢复行为。完整接口地址按所选协议填写：DeepSeek/通用 Chat Completions 包括 /chat/completions，OpenAI Responses 包括 /responses（例如 https://api.openai.com/v1/responses）。程序不会自动补路径，切换协议不会自动改写地址、模型或密钥，不能建议只填域名或 /v1。DeepSeek 示例为 https://api.deepseek.com/chat/completions，协议可选DeepSeek；模型名按用户已有配置或获取模型菜单，不臆造当前支持型号。导出入口以指南明确位置为准，不另外编造齿轮页的导出按钮。

暮羽聊天窗口的齿轮配置包含模型连接、资料与权限、对话与显示、上下文与预算、存储与记忆、技能与工具。执行过程的紧凑／标准／详细／完整显示在“对话与显示”，只改变展示，不删记录或授权。模型连接可选“使用酒馆当前连接（推荐）”或“使用暮羽独立接口”：新用户优先使用已配置且支持的酒馆聊天补全连接，不用另填密钥；已保存的独立接口不强制迁移。酒馆模式只复用连接，不自动带入角色卡、世界书或聊天正文，模型在酒馆设置中选择；切换连接或密钥会取消旧任务、撤销旧授权，需要重新启用。首版支持 OpenAI、自定义兼容接口、OpenRouter、DeepSeek 非 reasoner 模型；原生 DeepSeek 不开启新版思考，其他来源及自定义请求体覆盖暂用独立接口。独立接口填写协议、完整接口地址、API密钥和模型。两种连接测试都只发送固定测试消息，可能有费用，不发聊天正文，不自动启用。独立接口的获取模型仅修改表单，选择后仍需启用连接。记住密钥是独立接口的可选设置，不是服务端密钥保险箱，不索要用户密钥原文。

对话导出在对话历史侧栏的当前对话操作“⋯”菜单；可导出JSON或Markdown，不因为没有模型导出工具就说没有按钮。悬浮球显隐位于经典插件设置顶部“召唤暮羽”按钮右侧的“显示暮羽悬浮球”开关，不建议用CSS或禁用整个插件替代现有开关。

长期记忆在齿轮配置→存储与记忆→暮羽长期记忆。它与GroupWorld角色记忆、会话摘要不同；开启不证明已保存任何记忆。技能与联网搜索在齿轮配置→技能与工具；技能导入只填入未保存编辑器，检查后保存，新建默认禁用；保存与启用仍是两步，不能把导入说成已经存好。

GroupWorld角色的自动记忆频率在Group World经典设置→角色记忆，使用公开指南characterMemory.controls给出的控件名称，不另加未列出的二级分区。“自动提取间隔（每 N 条新消息）”数值越大越不频繁。不能把角色记忆的开关、提取间隔或容量指向暮羽“存储与记忆”页；该页的说明明确不修改角色记忆。

## 暮羽会话、酒馆目标与存储

需要分开上下文时，在暮羽“对话历史”侧栏点击“新对话”（New conversation），通过侧栏切换已有暮羽会话；不需要为了新建暮羽会话再建一个酒馆聊天。暮羽有自己的会话记录，不是写进角色卡或酒馆角色聊天存档的附属消息。同一个酒馆聊天可以对应多段暮羽对话。

酒馆当前聊天是聊天范围工具的操作目标，不等于暮羽对话的唯一存储容器。切换酒馆聊天后，可以在同一暮羽会话继续交流；系统会提醒目标改变，较早消息可能讨论旧聊天。新一轮聊天读取／操作针对当前酒馆聊天，必要时重新读取并申请对应资料权限，不能把旧聊天资料当作新聊天的当前状态。不要把历史中的任务批准视作新目标的授权。

新对话分开的是对话记录与上下文，不是磁盘、账号或权限的强隔离。存储位置由当前账号／浏览器及选定后端决定；读取来源单选、写入位置可多选，关闭写入不禁止读取。切换酒馆聊天、插件安装目录或产品名称，不会自动创建另一套隔离存储；不能承诺不会共享备份或账号命名空间。

GroupWorld 与上游是两个实际仓库，当前使用相同兼容 API、设置与存档命名空间；不是说两个仓库所有版本永远相同。只能启用其中一个，不能双开来分离暮羽数据。代码里的原兼容标识要保留，用户资源及历史名称不做品牌替换。想分开两段对话用暮羽“新对话”，不建议双开插件或新建酒馆聊天作为存储隔离方案。

世界书存储是插件管理的明文对话副本，不是剧情注入资料；保持内部存档条目禁用，不启用、不绑定、不改名。要解释内部前缀、删除和备份后果，完整读取“世界书与酒馆资料核对”的参考。静态指南不能证明当前选择的读取源、存档完好或已经持久化。

## 结束条件

解释按钮时给出准确入口、名称和必要后果即可；不为找按钮读取聊天，不擅自修改配置，不把静态指引当页面可用或执行成功证明。中英文按用户语言／界面语言使用对应名称，入口以公开资料为准。

核对版本：2026-10-23；`muyu/ui/navigation-metadata.js`、`muyu/ui/settings-layout.js`、`muyu/ui/connection-tools.js`、`muyu/ui/history-actions.js`、`muyu/ui/skill-view.js`、`ui/sections/muyu.js`。维护路径不是模型的文件访问能力。


## 独立 OpenAI Responses 连接

齿轮→模型连接→使用暮羽独立接口→接口协议选择 OpenAI Responses。填写完整 /responses 地址、密钥和具体模型ID，再启用此连接；测试连接、获取模型、选择模型只处理表单或发固定短测试，不自动启用。Responses 推理强度默认中，可选低/中/高/更高/最高，具体支持取决于模型；无通用关闭开关，不把 DeepSeek 的思考开关当 Responses 开关。单次输出额度包含推理消耗；摘要使用低推理强度，不改变普通对话配置。独立接口可选记住密钥及自动启用；恢复连接不恢复资料授权、全权限或自动发消息。

酒馆当前连接仍走官方 Chat Completions 服务；GPT-6.1 Sol 等官方要求 Responses 工具调用的模型请用独立 Responses 接口。没有服务插件也能使用；浏览器仍须满足目标接口的网络与CORS要求，不建议绕过权限或索要密钥明文。仅使用暮羽已注册函数工具，不自动开启供应商托管联网工具。
