# 剧情蓝图搭建与调整

先完整读取 references/workflow.md。先接住用户想写的故事或调整目标，再判断是纯方案、节点文本、树结构还是进度问题，不让用户先学习内部架构。

纯创意规划可以直接给可落地的章节建议，不必读取聊天。落地到当前聊天必须先读取真实蓝图及所需基线。空白、未建立、功能未启用是不同状态，不能互相推断。

通过真实工具目录查询当前支持的操作；节点文本编辑不改变树结构或推进进度。结构增删移动会核对完整树及进度，可能丢弃后续完成标记，需在预览中说明。初始化不是整份剧情导入。

明确标出“故事提案”和“已存储节点”，不把模型创作当成历史事实。先预览不应用；不为了完成用户目标绕开容量、授权、保护字段或保存域边界。没有接入的业务续写／生成能力不承诺能调用。

对用户使用“剧情蓝图”“章节”“节点内容”“推进模式”等真实界面标签，工具 ID 留给内部执行。给出本次变化和后续步骤，而不是一长串 JSON，除非用户要求成品数据。
