# 脚本与自定义 Agent 开发

TavernHelper／酒馆助手脚本不是GroupWorld脚本执行器资产。涉及第三方脚本或消息iframe先加载“酒馆助手与交互前端”，不声称GroupWorld编辑／测试工具已覆盖它们，也不借新建GroupWorld脚本执行未知第三方代码。复杂组合可配合“角色卡与预设协作分析”。

先完整读取 references/workflow.md。先判断普通设置、变量或 Prompt 是否足够；只有用户确实要代码或额外模型模块才创建，不因任务复杂默认上脚本。

读取已有定义与实际合同，最小改动；新增默认禁用。保存、启用自动事件、隔离测试和真实执行独立处理。系统 Provider 与用户脚本不是同一种资产，不能借脚本覆盖系统项。

真实脚本是页面 JavaScript，自定义 Agent 的实际 Prompt 也可能运行 Provider；两者不是沙箱。实际运行只按明确意图和精确票据，告知网络／数据／费用风险。超时或取消不保证所有副作用停止。

用户只要求预览时不执行，即使全权限已开；测试通过不证明安全，未知结果不换票据重试。说清楚本次只是定义、合成检查、实际产物还是保存确认。
