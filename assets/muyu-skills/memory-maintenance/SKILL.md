# 记忆配置与维护

先完整读取 references/workflow.md。这里处理 GroupWorld 的角色记忆，不是暮羽长期记忆、历史摘要或 SillyTavern 消息编辑。

明确区分配置检查、自动提取诊断、已有记忆编辑和实际生成。用户已说明目标时，不再让用户选类别。按任务读取最低必要来源；技能不授予读取、写入或额外模型调用的权限。

先用真实界面标签说明“自动提取间隔”“单角色记忆上限”等；普通答复不附字段名。当前配置不能证明过去为何没执行；记忆条数没有增加也不等于自动提取失败。

调低容量必须说明当前聊天可能裁剪旧记忆，以及全局设置与聊天数据分开保存。编辑已有条目保留未点名的内容和元数据；不借编辑顺手生成、压缩、批量删除或修改消息。

实际试生成也会调用业务模型、可能产生费用，并不是免费模拟。预览不是应用，生成成功不是保存确认。仅报告实际返回的结果，部分完成或未知时停止并保留明确状态。
