# 记忆工作流与风险

## 1. 检查配置和自动提取

概念解释可先读公开说明 memory.automation、memory.coverage、memory.targets。实际诊断可用 `muyu.memory.inspect`，需 `memoryConfig` 和 `memoryDiagnostics`；它只提供脱敏统计，不提供角色姓名或记忆正文。配置读取按目录和字段合同，记忆字段使用实际要求的来源，不改申请为无关的导演配置。

自动提取需要记忆总开关与自动提取开关同时启用。间隔 `autoMemoryInterval` 按新增消息条数、即 chat.length 的变化计，不是对话轮数，也不是记忆条数。调度缺省逻辑不等于已读取用户当前值。

当前关闭、非群聊、没有可用角色等可以解释当前阻断；回合收尾、手动生成、生成类型等保护条件不能仅凭当前值解释过去。swipe／regenerate 不走通常的新增消息自动提取分支。

覆盖基线与逐角色覆盖不同。首次启用可能建立基线；删除消息可能重置或限制覆盖锚点。只读诊断不修复基线。`NO_NEW_MEMORIES` 可以推进覆盖但不增加条数，不是失败；部分角色仍待处理也不等于整批失败。仅发言角色过滤可能按导演历史或回退路径选目标，没有身份与历史证据就不猜具体是谁。

## 2. 修改配置

用户目标、参数方向和目标数值分别核对。“太频繁／少触发／降低频率”意味着增大自动提取间隔；“降低间隔”才是减小数值。没有明确目标数值时，先用一个简短问题询问希望每多少条新消息提取，不能自选5、20等数字生成草稿；“先预览”也不授权模型替用户决定数值。用户已给出数值则直接按该值预览，不重复追问。找控件时读取公开muyu.interface：Group World经典设置→角色记忆，而不是暮羽齿轮→存储与记忆；后者只管理暮羽存档与长期笔记。

先查真实目录和合同，未接入的字段不能绕过配置接口直接赋值。未指定字段保持原值，间隔修改不隐含补开开关。范围需明确：功能参数影响所有聊天，记忆内容操作只修改当前聊天。

`memoryMaxEntries` 即单角色记忆上限，当前合同范围 10..2000，须单独预览和批准，不进入整单配置执行。调低会裁剪当前聊天各角色最旧的超额记忆，也影响其他聊天之后的生成与导入；预览需展示实际预计裁剪量，不能把当前聊天 0 条外推到所有聊天。全局配置保存与当前聊天裁剪是两个保存域，可能部分完成。

`memoryKeepRecent` 是手动压缩的保留近期条数，不是容量上限。不要把修改它说成已经压缩记忆。Token 预算等是否可写，以当时目录为准。

## 3. 编辑已有记忆

按实际目录发现并选用工具组；现有 `muyu.memory_editor` 的 list／read／preview 使用 `memoryEditState`。先取返回的角色选择器、revision 和条目 index，再分页读齐需要的正文。选择器如 `memory-role:N` 是当前快照中的索引，不是永久角色 ID。

更新只改用户点名的 event／mood；保留时间、轮次和来源等其他元数据。mood 仅接受合同列出的枚举。删除针对一个条目，不隐含清库。新增已有角色的记忆用 create_targets／create_preview 及 `memoryCreateState`，不创建新角色、不自动提取、不补开功能。达到容量限制时不得偷偷裁剪或压缩来完成新增。

分页／revision 过期时重新读取同一获授权来源，重新校验草稿，不沿用旧索引盲改。不能从匿名统计推出记忆原文。编辑真实记忆也不等于修改聊天正文。

## 4. 按请求实际生成

从实际目录选择记忆生成工具。`muyu.memory_generation.targets` 返回目标及 revision；prepare 使用所选目标和 trial／save 模式；execute 使用宿主提供的执行授权／票据，不能自造或从旧聊天复制。

trial 会调用插件业务模型与实际 Prompt／Provider，可能产生费用，但不保存；save 还可能追加并按已有上限裁剪旧记忆。两者都不隐含开功能或生成其他角色。实际运行授权与普通资料读取授权不同，准备成功不等于已执行。

取消／超时不保证远端或 Provider 立即停下，也不保证没有费用。不要自动重试未知结果。输出正文被预算省略，要说明省略而不是宣称没有生成。模型产出的记忆是待核对内容，不是剧情客观事实。

## 5. 汇报与维护

用“已读取”“仅预览”“执行时更新内存”“持久化已确认／未确认”“部分完成／结果未知”精确汇报；回执是历史结果，不代表当前值。用户只要预览时，任何权限模式都不应用。

用户改口后可说“以新要求为准，旧提议不再代表你的目标”，不能说宿主已删除或作废旧草稿，除非有明确生命周期结果。预览基线只是当时读值；没有新读取时只确认本轮未应用，不能断言当前值仍是基线或不可能等于任一草稿值。

核对版本：2026-10-05；`muyu/modules/memory/knowledge.js`、`muyu/modules/memory-editor/`、`muyu/modules/memory-generation/`、`muyu/config/registry.js`。以当前工具 schema 为准；此维护索引不是文件读取能力。更新正文应提升内置清单 revision。
