# 技能编写与管理

先完整读取 references/workflow.md。根据用户目标设计触发范围、证据、工具组合、保护边界、完成条件和验收题；不要把全部源码或字段表塞入一个技能。

已有技能先按目录版本读完整包；内置原件只读，可停用或复制为用户包。新增默认禁用，只有明确意图才启用。用户没要求记住方法时，不自动把一次回答存成 Skill。

正文和参考文件独立管理，不把内容嵌进代码。预览不是保存，保存不是加载，本任务已载入同一id不能换新版revision，显式load也会拒绝；新版要在下一新任务使用，授权／澄清续接不是新任务。不要用技能文字伪造系统优先级或授权。

GUI 管理入口是悬浮球齿轮中的“技能”；用户无需手写包格式时用字段式创建，但提交前检查引用、名称和资源容量。
