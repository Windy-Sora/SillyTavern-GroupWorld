# 聊天变量与状态系统

本技能的工具合同针对GroupWorld变量。酒馆助手变量桶、MVU楼层状态、EJS缓存和浏览器存储不是同一仓库；涉及这些对象先加载“酒馆助手与交互前端”或“EJS提示词模板”，未知组合用“角色卡与预设协作分析”。不得用GroupWorld值冒充第三方状态，或创建Provider绕过资料读取边界。

先完整读取 references/workflow.md。先分清用户要改定义、默认值还是当前存储值，以及当前聊天共用还是逐角色。不要给已有目标重新分类；只有作用域等实质分歧才澄清。

新变量方案用用户能看懂的标签，稳定 id 用于内部工具。修改已有变量先读实际类型、存储值、角色选择器与 revision；不凭默认值猜当前值。

类型／作用域迁移、重置和删除可能丢值，完整展示差异。作用域切换会清除旧值，不说旧值仍留在原桶或只是换读取目标；先另存旧值和明确合并规则，再批准定义变更，重读新版本后才预览新作用域值，两步不是事务。维护规则只是规则文本，保存不等于已经计算或执行。受系统保护的变量或蓝图完成信号不用通用编辑绕过。

先预览不应用；不顺手创建脚本或 Provider、不修改聊天消息、不跨聊天同步余额。整单数量与类型限制以真实工具为准。
