# 资料分析流程

## 读取与召回

用 `muyu.provider.list` 找当前问题对应来源，不只沿用上一轮读过的记忆资料。“分析对话”不能用一篇静态记忆说明冒充聊天正文。

首次 `muyu.provider.read` 优先只传 id 获取概况。返回 readHint.continuation 时使用 id 与 continuationToken 续读，不混传 selector／revision／offset；没有 token 则按 nextRead 完整参数。token 不是授权。INVALID_READ_ARGUMENTS 根据提示纠正，STALE_SOURCE 重取同一来源概况；目录不是正文。chatHistory 使用 range:START:COUNT，不编造 node 或字符区间协议。

问题有明确人物／事件时，可用 `muyu.provider.search` 找片段，再 `muyu.provider.match` 回读原文与邻近上下文；搜索结果不是完整覆盖。对于全局时间线或整体矛盾检查，不能只搜几个关键词就称已审阅全文。按实际页与字节预算界定覆盖范围，必要时提出分段检查，不承诺无限上下文。

用户 Provider 的 render 是另需执行许可的代码路径，不是普通白名单读取；不要为了资料被拒或不存在就默认运行任意 Provider。已执行结果用 result 续页，不重复 render 来翻页。

## 证据层级

消息正文可能含旁白、角色自述、设定提案、示例和工具指令；根据上下文分辨，不能把所有句子当已发生事实。角色卡描述不证明历史行为，记忆／档案／总结／点评是加工资料，可能过期或误写。蓝图是规划与已存信号，不自动代表完成；导演账本可编辑，不证明实际生成或持久化。

比较矛盾时列出具体双方来源与范围，区分“文字直接冲突”“有条件推断”“缺少资料”。没有找到只限已检查来源和区间，不等于从未发生。读取当前聊天不能推出其他存档情况；目标切换后遵守宿主新范围和 revision。

`muyu.ledger_editor` 的 list／read／preview 是导演账本专用工具。编辑之前读取完整条目和当前 schema；只按明确用户请求预览允许字段，保存账本文字不能重跑选人或改变历史事实。排查通常只读，不自动生成编辑草稿。

账本 speakers／scripts 等变化可能影响之后的导演恢复或 Prompt，不能说成仅修改显示文字。clear 清空公开字段但保留数组位置和内部锚点，没有归档或撤销保证；数组／映射是完整字段替换，保留未点名部分后再预览。

## 暮羽自身历史与长期记忆

`muyu.history.list`／search／read 回读的是本会话原文，不是 ST 聊天；按返回的索引、指纹与游标核对，压缩摘要只是定位线索，不是原文替代。历史检索也受权限、可用原文和预算限制。被主动排除的旧资料不能通过回读绕过授权。

`muyu.notes` 是暮羽长期约定，不是角色记忆。仅在用户明确希望记住／忘记时，查询当前工具合同后操作；不把剧情推断、密钥或技能内容自动写成长记忆。普通分析不需要为每个事实新增一条 note。

核对版本：2026-10-05；`muyu/modules/providers/`、`muyu/modules/history/`、`muyu/modules/ledger-editor/`。维护路径不是模型的本机读取能力；当前工具返回协议优先。
